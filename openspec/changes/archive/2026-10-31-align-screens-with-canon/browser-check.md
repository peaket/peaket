# 브라우저 확인: align-screens-with-canon

- 날짜: 2026-10-31
- 커밋: 커밋 전 작업 트리(가지 `feature/0.6.4-screen-canon-align`, 기준 `afc8115`)
- 브라우저: **Claude in Chrome은 못 함(연결 없음)**. `list_connected_browsers`가 빈 목록이었다. OPEN[06]의 기본값대로 그 사실을 적고, 대신 Claude 데스크톱 앱의 내장 브라우저로 같은 시나리오를 봤다. Chrome이 연결된 턴에 아래 표를 다시 누른다.
- 환경: 로컬 개발 서버 셋(웹 3000, 파트너 3001, 대기실 3004), 목업 데이터(합성, 고정 값). 서버 없이 그리는 퍼블리싱이라 API 요청은 없다.
- 방법: 바뀐 화면을 같은 출처 iframe에 폭별로 열고, 바뀐 글자·배지 클래스·계산된 색, `h1` 개수, 가로 넘침(`scrollWidth`가 폭보다 큰지)을 쟀다.
