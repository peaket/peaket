# 상세 WBS 기록 — 늘어난 범위와 작업 칸에서 옮긴 완료 기록

- **독자와 용도**: 소유자가 WBS 범위가 언제·왜 늘었는지, 끝낸 작업을 언제 어떤 변경으로 했는지 되짚을 때 읽는다. 규범이 아니라 기록이다. 작업 내용·일수·상태의 정본은 `docs/wbs/wbs.md`·`docs/wbs/wbs.csv`이고, 진행 체크의 정본은 `docs/BUILD_ORDER.md`다.
- **옮긴 것**(2026-11-17, ADR-0282): ① wbs.md §6의 늘어난 범위 표 전체(옮길 때 그대로) ② wbs.md §3 작업 칸에 섞여 있던 완료 기록 문장(작업 여섯 개). wbs.md §6에는 합계와 이 파일 안내만 남겼다.
- **더하는 법**: 범위가 늘면 §1 표에 행을 더하고 wbs.md §2 합계 문장과 §6 합계를 함께 고친다. 작업을 끝낸 기록은 WBS 작업 칸에 쓰지 않고 BUILD_ORDER 체크와 커밋 본문에 남긴다(ADR-0190 결정 3, ADR-0282).
