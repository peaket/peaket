# RB-03: 대기열 진입 Degraded Mode 자동 전환 확인과 해제

- **서비스·영역**: queue-svc
- **증상 분류**: 지연
- **증상**: 대기열 진입 지연 p99가 150ms를 2분 넘게 넘거나 Redis CPU 사용률이 75%를 넘을 때
- **탐지 경로**: 경보
- **심각도**: SEV2
- **발동 신호**: 대기열 진입 지연 p99가 150ms를 2분 넘게 넘거나 Redis CPU 사용률이 75%를 넘을 때 — [관측 §5](../observability.md)
- **담당**: 서비스 담당
- **목표 시간**: 미정

## 즉시 조치

1. 진입 경로의 Degraded Mode 표시와 도착 시각 쿠키가 실제로 켜졌는지 확인한다.
2. queue-svc 파드·Redis CPU·연결 수·느린 명령을 보고, 필요하면 명령 6의 Degraded 상태를 유지한다.
3. 원인이 풀리면 Degraded를 해제하고 진입 p99·오류율이 돌아오는지 본다.

## 에스컬레이션

- 2분 안에 지연이 풀리지 않으면 서비스 담당과 온콜을 부르고, 15분을 넘기면 인시던트 선언 기준을 본다.
- 결제·좌석 여정으로 번지면 IC가 명령 1·2를 검토한다.

## 복구 확인

- 진입 p99가 기준 아래로 10분 이상 유지되고, Degraded 표시가 꺼지며, 503 `queue-recovering`이 0이다.

## 포스트모템

- 인시던트로 선언하면 [RB-17](RB-17.md)에 따라 48시간 안에 비난 없는 포스트모템을 쓴다. 선언 기준에 들지 않으면 이슈로 남긴다.
