# RB-23: 배포 되돌리기와 동결 중 긴급 변경

- **서비스·영역**: 배포·플랫폼
- **증상 분류**: 변경·배포
- **증상**: 카나리 자동 중단 경보가 나거나 배포 직후 SLO 소진·온세일 중 배포 원인이 의심될 때
- **탐지 경로**: 경보·사람·외부
- **심각도**: SEV2
- **발동 신호**: 카나리 자동 중단 경보가 나거나 배포 직후 SLO 소진·온세일 중 배포 원인이 의심될 때 — [관측 §5](../observability.md)
- **담당**: 릴리스 담당
- **목표 시간**: [배포 §8.4](../devops.md)

## 즉시 조치

1. 카나리 분석 결과와 배포 판·다이제스트를 확인하고, 자동 중단이면 안정판으로 되돌린다.
2. Git 되돌리기와 `rollbackWindow` 빠른 복귀를 쓰고, 병합 직후면 VPN 관리 경로로 `argocd app sync`를 한다.
3. 긴급 변경이면 `emergency-change` 라벨과 인시던트 번호를 달고, 단계별 시간을 기록한다.

## 에스컬레이션

- 되돌리기 결정은 릴리스 담당과 IC가 하고, 5분 안에 복귀하지 못하면 commander를 부른다.

## 복구 확인

- 안정판 100%가 돌고, SLO·카나리·오류율이 기준 아래이며, 되돌리기 시간과 원인이 기록됐다.

## 포스트모템

- 인시던트로 선언하면 [RB-17](RB-17.md)에 따라 48시간 안에 비난 없는 포스트모템을 쓴다. 선언 기준에 들지 않으면 이슈로 남긴다.
