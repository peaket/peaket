# RB-15: 비상 자동화 정지 스위치 발동 후 시스템 정상 복귀와 사후 검토 보고서

- **서비스·영역**: ops-svc
- **증상 분류**: 오류·정합성
- **증상**: 관리자가 비상 자동화 정지 스위치를 실행했을 때
- **탐지 경로**: 사람
- **심각도**: SEV2
- **발동 신호**: 관리자가 비상 자동화 정지 스위치를 실행했을 때 — [관측 §5](../observability.md)
- **담당**: 온콜
- **목표 시간**: 미정

## 즉시 조치

1. 정지 스위치를 실행한 사람·사유·영향 범위를 감사 기록에서 확인한다.
2. 자동 조치가 멈춘 동안 필요한 수동 명령을 commander 승인으로 내고, 시스템이 정상 궤도로 돌아오는지 본다.
3. 복귀 뒤 48시간 안에 사후 검토 보고서를 쓰고 7일 안에 검토한다.

## 에스컬레이션

- 영향이 판매·결제로 번지면 IC를 부르고, 자동화 재개는 commander가 승인한다.

## 복구 확인

- 자동 조치가 재개되고, 감사 기록에 실행·복귀·검토가 남았으며, 같은 정지가 반복되지 않는다.

## 포스트모템

- 인시던트로 선언하면 [RB-17](RB-17.md)에 따라 48시간 안에 비난 없는 포스트모템을 쓴다. 선언 기준에 들지 않으면 이슈로 남긴다.
