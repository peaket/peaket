# RB-19: 예매 취소 및 환불 처리 지연 대응

- **서비스·영역**: payment-svc
- **증상 분류**: 지연
- **증상**: 일괄 환불 작업이 자동 정지하거나 CS 처리함의 환급 기한이 초과·임박했을 때
- **탐지 경로**: 경보
- **심각도**: SEV2
- **발동 신호**: 일괄 환불 작업이 자동 정지하거나 CS 처리함의 환급 기한이 초과·임박했을 때 — [관측 §5](../observability.md)
- **담당**: 서비스 담당
- **목표 시간**: 미정

## 즉시 조치

1. PG 취소 실패 건과 환급 기한, 자동 정지 사유를 확인한다.
2. 같은 멱등키로 취소를 다시 보내고, 조회 API로 상태를 동기화한다.
3. 기한이 임박한 건을 CS 처리함에서 먼저 처리하고, 반복 실패는 결제사에 알린다.

## 에스컬레이션

- 기한 초과가 1건이라도 있으면 IC를 부르고, 결제사 장애면 RB-07을 함께 본다.

## 복구 확인

- 자동 정지가 풀리고, 환급 기한 초과가 0이며, PG 원장과 내부 상태가 같다.

## 포스트모템

- 인시던트로 선언하면 [RB-17](RB-17.md)에 따라 48시간 안에 비난 없는 포스트모템을 쓴다. 선언 기준에 들지 않으면 이슈로 남긴다.
