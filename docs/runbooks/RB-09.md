# RB-09: 관측 스택 장애와 제어 입력 없음 대응

- **서비스·영역**: 관측
- **증상 분류**: 관측 공백
- **증상**: 외부 Watchdog 하트비트가 끊기거나 콘솔이 자동 제어 입력 없음을 표시할 때
- **탐지 경로**: 경보
- **심각도**: SEV2
- **발동 신호**: 외부 Watchdog 하트비트가 끊기거나 콘솔이 자동 제어 입력 없음을 표시할 때 — [관측 §5](../observability.md)
- **담당**: 플랫폼 담당
- **목표 시간**: 미정

## 즉시 조치

1. 외부 합성 점검과 콘솔의 Prometheus 밖 숫자로 현재 상태를 판단한다.
2. 입장 제어가 목표를 유지하는 동안 명령 1·2로 사람이 조절하고, 관측 스택 복구를 플랫폼 담당에게 맡긴다.
3. 입력이 돌아오면 자동 조절이 재개됐는지, 경보가 다시 오는지 확인한다.

## 에스컬레이션

- 관측 공백이 15분을 넘으면 IC를 부르고, SLO 판단은 마지막 정상 값과 외부 점검만으로 한다.
- 판매 경로가 영향을 받으면 명령 3을 검토한다.

## 복구 확인

- Watchdog가 다시 오고, 자동 제어 입력이 신선하며, 콘솔·Grafana·경보가 같은 상태를 보인다.
