# RB-16: 법정 처리 기한 대응

- **서비스·영역**: 보안·법정
- **증상 분류**: 보안·법정
- **증상**: 부정거래 게시물 차단·수사기관 제공 대장 등 법정 처리 기한이 임박했을 때
- **탐지 경로**: 경보
- **심각도**: SEV2
- **발동 신호**: 부정거래 게시물 차단·수사기관 제공 대장 등 법정 처리 기한이 임박했을 때 — [관측 §5](../observability.md)
- **담당**: 보안 담당
- **목표 시간**: 미정

## 즉시 조치

1. 법정 기한과 대상 건, 담당자, 증거 보존 상태를 확인한다.
2. 차단·통보·제공 대장 처리를 기한 안에 끝내고, 불가능하면 사유와 대체 조치를 기록한다.
3. 기한 초과가 임박하면 IC와 보안 담당에 알리고, 필요하면 RB-20으로 넘긴다.

## 에스컬레이션

- 기한을 넘길 것 같으면 IC·보안 담당·CL이 함께 판단하고, 외부 신고가 필요하면 RB-20을 따른다.

## 복구 확인

- 모든 법정 건이 기한 안에 처리되고, 대장·증거·사유가 감사 기록에 남았다.

## 포스트모템

- 인시던트로 선언하면 [RB-17](RB-17.md)에 따라 48시간 안에 비난 없는 포스트모템을 쓴다. 선언 기준에 들지 않으면 이슈로 남긴다.
