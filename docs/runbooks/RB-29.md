# RB-29: 관리형 서비스 예정 유지보수와 플랫폼 버전 올리기

- **서비스·영역**: 배포·플랫폼
- **증상 분류**: 변경·배포
- **증상**: AWS Health 예정 이벤트를 받거나 EKS 표준 지원 종료가 90일 앞으로 왔을 때
- **탐지 경로**: 사람
- **심각도**: SEV3
- **발동 신호**: AWS Health 예정 이벤트를 받거나 EKS 표준 지원 종료가 90일 앞으로 왔을 때 — [관측 §5](../observability.md)
- **담당**: 플랫폼 담당
- **목표 시간**: 미정

## 즉시 조치

1. 예정 이벤트의 영향·시각·대체 구간을 확인한다.
2. 정비 시간으로 일정을 조정하고, 필요한 버전 올리기·노드 교체를 계획한다.
3. 작업 뒤 서비스·관측·백업이 정상인지 확인한다.

## 에스컬레이션

- 온세일과 겹치면 릴리스 담당·IC와 일정을 다시 정하고, 긴급하면 변경 동결 예외를 검토한다.

## 복구 확인

- 예정 이벤트가 끝나고, 버전·노드·애드온이 지원 범위 안이며, 서비스·관측·백업이 정상이다.

## 포스트모템

- 인시던트로 선언하면 [RB-17](RB-17.md)에 따라 48시간 안에 비난 없는 포스트모템을 쓴다. 선언 기준에 들지 않으면 이슈로 남긴다.
