# RB-34: 스트림 작업자 복구

- **서비스·영역**: 관측
- **증상 분류**: 관측 공백
- **증상**: 스트림 작업자 재시작·소비 밀림·삽입 재시도·적재 거절 신호가 날 때
- **탐지 경로**: 경보
- **심각도**: SEV3
- **발동 신호**: 스트림 작업자 재시작·소비 밀림·삽입 재시도·적재 거절 신호가 날 때 — [관측 §5](../observability.md)
- **담당**: 플랫폼 담당
- **목표 시간**: 미정

## 즉시 조치

1. 파드 상태·재시작·소비 밀림·삽입 재시도·거절 수로 멈춤·되풀이 실패·의존성 장애를 가른다.
2. 의존성 장애면 회복을 기다리고, 코드 문제면 이전 이미지로 롤링해 되돌린다.
3. Kafka 보관 안에서 빈 구간·거절 구간을 다시 적재하고, 실시간 원시 표를 브론즈에서 채운다.

## 에스컬레이션

- 플랫폼 담당이 맡고, 관제 실시간 표가 Degraded면 IC와 관제 담당을 부른다.

## 복구 확인

- 작업자가 재시작 없이 돌고, 소비 밀림·삽입 재시도·거절이 0이며, 마감 리포트와 실시간 표가 맞는다.

## 포스트모템

- 인시던트로 선언하면 [RB-17](RB-17.md)에 따라 48시간 안에 비난 없는 포스트모템을 쓴다. 선언 기준에 들지 않으면 이슈로 남긴다.
