# RB-07: 외부 PG사 승인 장애 대응

- **서비스·영역**: payment-svc
- **증상 분류**: 지연
- **증상**: 결제사 서킷이 열리거나 결제 확정 소요 p99가 5초를 넘을 때
- **탐지 경로**: 경보
- **심각도**: SEV2
- **발동 신호**: 결제사 서킷이 열리거나 결제 확정 소요 p99가 5초를 넘을 때 — [관측 §5](../observability.md)
- **담당**: 서비스 담당
- **목표 시간**: 미정

## 즉시 조치

1. 결제사별 서킷·승인 호출 p99·한도 초과 응답·결제 확정 소요를 확인한다.
2. 재시도 큐로 돌리고 홀드 TTL을 승인 기한까지 늘리며, 새 결제 진입 정지 단계를 본다.
3. 전환 후보를 추천하고 commander 2인 승인 뒤 결제사를 바꾼다.

## 에스컬레이션

- 전환 판단은 IC와 commander가 하고, 결제 불가가 이어지면 SEV1 기준을 본다.
- 대외 공지는 CL이 준비한다.

## 복구 확인

- 결제 확정 p99가 기준 아래로 돌아오고, 서킷이 닫히며, 새 결제 진입이 단계적으로 열린다.

## 포스트모템

- 인시던트로 선언하면 [RB-17](RB-17.md)에 따라 48시간 안에 비난 없는 포스트모템을 쓴다. 선언 기준에 들지 않으면 이슈로 남긴다.
