# RB-01: 오픈 T-30분 Pre-flight 체크리스트 점검

- **서비스·영역**: 공통·운영
- **증상 분류**: 가용성
- **증상**: 티케팅 오픈 T-30분 스케줄러가 Pre-flight 점검을 시작했을 때
- **탐지 경로**: 경보·사람·외부
- **심각도**: SEV1~SEV3
- **발동 신호**: 티케팅 오픈 T-30분 스케줄러가 Pre-flight 점검을 시작했을 때 — [관측 §5](../observability.md)
- **담당**: 온콜
- **목표 시간**: 미정

## 즉시 조치

1. `docs/infra.md` §5의 T-30분 점검표와 관제 화면 SCR-029를 연다.
2. 최소 복제본·노드 여유·인증서·백업·서명 키·동결 창을 확인하고 빠진 항목을 담당 팀에 알린다.
3. T-20분까지 복구하지 못하면 입장 일시정지(명령 2)로 시작할지 commander에게 묻고, 결과를 인시던트 기준에 맞춰 기록한다.

## 에스컬레이션

- 점검 실패가 둘 이상이거나 복구 담당이 정해지지 않으면 인시던트 지휘관(IC)을 부르고 운영 실행자(OL)가 복구를 맡는다.
- 외부 공지가 필요하면 기록·대외 공지 담당(CL)에게 넘긴다.

## 복구 확인

- 점검표의 필수 항목이 모두 통과하고, 최소 복제본과 합성 점검이 정상이며, 동결 창·인증서·백업에 미해결 경고가 없다.

## 포스트모템

- 인시던트로 선언하면 [RB-17](RB-17.md)에 따라 48시간 안에 비난 없는 포스트모템을 쓴다. 선언 기준에 들지 않으면 이슈로 남긴다.
