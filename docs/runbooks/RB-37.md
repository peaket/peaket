# RB-37: 비상 접근 계정 사용

- **서비스·영역**: 보안·법정
- **증상 분류**: 보안·법정
- **증상**: IAM Identity Center가 멈추거나 잘못 설정돼 평소 경로와 긴급 접근 역할로 들어오지 못할 때
- **탐지 경로**: 경보·사람·외부
- **심각도**: SEV1
- **발동 신호**: IAM Identity Center가 멈추거나 잘못 설정돼 평소 경로와 긴급 접근 역할로 들어오지 못할 때 — [관측 §5](../observability.md)
- **담당**: 보안 담당
- **목표 시간**: 미정

## 즉시 조치

1. 평소 로그인·긴급 접근 역할 실패를 확인하고 인시던트를 선언한다.
2. 묶인 commander가 봉인한 비밀번호·보안 키로 비상 접근 계정에 로그인하고, 교차 계정 역할로 `ops-breakglass` Job을 만든다.
3. 끝나면 비밀번호·보안 키를 교체·재봉인하고, 분기 점검 일정을 맞춘다.

## 에스컬레이션

- IC·보안 담당이 함께 지휘하고, ops-svc도 멈췄으면 RB-08과 함께 본다.

## 복구 확인

- 평소 경로가 돌아오고, 비상 계정 세션·키가 교체·봉인됐으며, 사용 기록이 감사 로그에 남았다.

## 포스트모템

- 인시던트로 선언하면 [RB-17](RB-17.md)에 따라 48시간 안에 비난 없는 포스트모템을 쓴다. 선언 기준에 들지 않으면 이슈로 남긴다.
