# RB-14: 전석 매진 처리 절차 점검

- **서비스·영역**: queue-svc
- **증상 분류**: 오류·정합성
- **증상**: 잔여 좌석 0건 매진 판정 이벤트가 났을 때
- **탐지 경로**: 경보
- **심각도**: SEV3
- **발동 신호**: 잔여 좌석 0건 매진 판정 이벤트가 났을 때 — [관측 §5](../observability.md)
- **담당**: 서비스 담당
- **목표 시간**: 미정

## 즉시 조치

1. 매진 판정과 좌석 판매 상태·비트맵을 대조한다.
2. CDN 정적 파일을 갱신하고 오리진 차단이 실제로 걸렸는지 확인한다.
3. 거짓 매진이면 판정을 되돌리고, 좌석 상태를 다시 계산한다.

## 에스컬레이션

- 거짓 매진이 확인되면 서비스 담당과 IC를 부르고, 판매 재개를 검토한다.
- 고객 문의가 늘면 CL·CS 담당에 알린다.

## 복구 확인

- 매진 표시와 실제 잔여 좌석이 같고, CDN·오리진이 같은 판을 내며, 거짓 매진이 0이다.
