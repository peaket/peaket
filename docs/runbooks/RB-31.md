# RB-31: 진단 증거 보존

- **서비스·영역**: 공통·운영
- **증상 분류**: 관측 공백
- **증상**: 자원 누수 의심 경보가 나거나 재시작 전에 파드 하나의 증거가 필요할 때
- **탐지 경로**: 경보·사람·외부
- **심각도**: SEV3
- **발동 신호**: 자원 누수 의심 경보가 나거나 재시작 전에 파드 하나의 증거가 필요할 때 — [관측 §5](../observability.md)
- **담당**: 서비스 담당
- **목표 시간**: 미정

## 즉시 조치

1. 긴급 접근으로 파드 하나에 `peaket.io/diagnose` 주석(`report`·`heap`·요청 시각)을 단다.
2. 그 파드가 준비 상태를 내리고 진단 보고서·힙 스냅샷·DB·Redis 스냅샷을 증거 저장소에 올리는지 본다.
3. 나머지 파드는 바로 다시 띄우고, 증거를 인시던트에 묶는다.

## 에스컬레이션

- 보안 사고가 의심되면 RB-20을 먼저 하고, 파드 하나로 격리가 안 되면 IC가 롤링 재시작을 정한다.

## 복구 확인

- 증거 객체와 manifest가 저장소에 있고, 새 파드가 정상이며, 같은 진단 주석이 반복되지 않는다.

## 포스트모템

- 인시던트로 선언하면 [RB-17](RB-17.md)에 따라 48시간 안에 비난 없는 포스트모템을 쓴다. 선언 기준에 들지 않으면 이슈로 남긴다.
