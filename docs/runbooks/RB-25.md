# RB-25: 배포 경로 장애

- **서비스·영역**: 배포·플랫폼
- **증상 분류**: 변경·배포
- **증상**: 승격이 연속 실패하거나 동기화·서명 검증이 실패할 때
- **탐지 경로**: 경보
- **심각도**: SEV2
- **발동 신호**: 승격이 연속 실패하거나 동기화·서명 검증이 실패할 때 — [관측 §5](../observability.md)
- **담당**: 릴리스 담당
- **목표 시간**: 미정

## 즉시 조치

1. GitHub Actions·ECR·ArgoCD·Sigstore 가운데 실패한 구간을 가른다.
2. 대체 경로로 긴급 적용하고, 사후에 GitOps 상태를 저장소와 맞춘다.
3. 같은 실패가 반복되면 파이프라인을 멈추고 원인을 고친다.

## 에스컬레이션

- 운영 승격이 막히면 릴리스 담당과 IC를 부르고, 긴급 변경은 commander 승인을 받는다.

## 복구 확인

- 승격·동기화·서명이 모두 성공하고, GitOps 상태와 저장소가 같으며, 같은 실패가 재발하지 않는다.

## 포스트모템

- 인시던트로 선언하면 [RB-17](RB-17.md)에 따라 48시간 안에 비난 없는 포스트모템을 쓴다. 선언 기준에 들지 않으면 이슈로 남긴다.
