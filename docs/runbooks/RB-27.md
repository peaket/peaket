# RB-27: 입장 정책 검증 실패로 파드가 뜨지 않음

- **서비스·영역**: 배포·플랫폼
- **증상 분류**: 변경·배포
- **증상**: 파드 생성 거부가 급증하거나 Kyverno 웹훅이 오류를 낼 때
- **탐지 경로**: 경보
- **심각도**: SEV2
- **발동 신호**: 파드 생성 거부가 급증하거나 Kyverno 웹훅이 오류를 낼 때 — [관측 §5](../observability.md)
- **담당**: 플랫폼 담당
- **목표 시간**: 미정

## 즉시 조치

1. 서명·출처·Kyverno 웹훅·검증 경로를 확인한다.
2. 정책 예외가 꼭 필요하면 commander 승인과 만료 시각을 받아 최소 범위로 적용한다.
3. 검증 경로가 돌아오면 예외를 지우고, 새 파드가 정상 생성되는지 본다.

## 에스컬레이션

- 예외 없이 파드가 뜨지 않으면 플랫폼 담당과 IC를 부르고, 핫패스 확장이 막히면 명령 2를 검토한다.

## 복구 확인

- 새 파드가 정상 생성되고, 검증 오류가 0이며, 임시 예외가 만료 전에 제거됐다.

## 포스트모템

- 인시던트로 선언하면 [RB-17](RB-17.md)에 따라 48시간 안에 비난 없는 포스트모템을 쓴다. 선언 기준에 들지 않으면 이슈로 남긴다.
