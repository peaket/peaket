# RB-04: 대기 상태 파일 S3 사본 고정 전환과 해제

- **서비스·영역**: queue-svc
- **증상 분류**: 가용성
- **증상**: 대기열 CDN 캐시 오류율이 1%를 1분 넘게 넘을 때
- **탐지 경로**: 경보
- **심각도**: SEV2
- **발동 신호**: 대기열 CDN 캐시 오류율이 1%를 1분 넘게 넘을 때 — [관측 §5](../observability.md)
- **담당**: 서비스 담당
- **목표 시간**: 미정

## 즉시 조치

1. CloudFront 원본 그룹이 요청마다 S3 사본으로 넘기는지, 대기 상태 파일 키와 캐시 규칙을 확인한다.
2. 원본이 살아 있지 않으면 명령 6으로 S3 사본 고정을 켜고, 원본 복구 뒤 해제한다.
3. 대기열 진입·대기 상태 응답의 5xx와 오래된 캐시가 줄어드는지 본다.

## 에스컬레이션

- 고정을 켠 뒤에도 오류율이 줄지 않으면 플랫폼 담당과 IC를 부른다.
- 판매 경로가 막히면 명령 3(판매 일시정지)을 검토한다.

## 복구 확인

- 캐시 오류율이 1분 동안 1% 아래이고, 대기 상태 파일이 원본에서 정상 응답하며, 오래된 사본이 남지 않았다.
