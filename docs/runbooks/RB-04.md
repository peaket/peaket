# RB-04 대기 상태 파일 S3 사본 고정 전환과 해제(명령 6)

- **발동 신호(정본 인용)**: 대기열 CDN 캐시 오류율 > 1%가 1분 이어짐(`docs/infra.md` §10 RB-04).
- **정본**: `docs/features/control-tower.md` §3 명령 6, §5 'CDN 설정 API'·'제어 상태', `docs/features/queue-admission.md` §4·§9, ADR-0078 결정 2, ADR-0365 결정 2·6.
- **전제**: 실제 CloudFront·S3·Lambda 호출과 배포 전파는 이 동결 트랙에서 `미실행`이다. 이 런북은 포트·정본 계약과 관제 콘솔 절차를 적고, 실제 배포·권한은 F-09-4가 잇는다.

## 1. 원본 오류인지, S3 사본 고정이 켜졌는지 확인

1. CloudFront 원본 그룹(queue-files)의 값이 장애 조치 코드 500·502·503·504, 연결 시간 초과 2초, 시도 1회인지 확인한다. 이 값이면 원본 오류 때 CloudFront가 요청마다 S3 사본으로 넘긴다(ADR-0078 결정 2). 이어서 명령 6의 `STATE_MIRROR_FIXED` 행이 `ACKED`인지 보고, 켜져 있으면 queue-files 배포의 `queueFilesOrigin`이 `S3_FALLBACK`인지 확인한다.
2. 원본 그룹의 장애 조치가 자동으로 도는 것과 `STATE_MIRROR_FIXED`는 다르다. 전자는 원본 오류 때만 요청마다 넘기고, 후자는 해제 명령 전까지 원본을 S3 사본으로 고정한다. 자동 전환이 정상으로 도는 중이면 고정을 켜지 않아도 된다.
3. 매진 정적 응답(`SOLD_OUT_STATIC`)이 함께 켜졌는지 본다. `queueEntryResponse`가 `SOLD_OUT_STATIC`이면 진입 응답이 정적 매진 응답이다. S3 사본 고정과 매진 정적 응답은 서로 독립이고, 하나를 켜거나 꺼도 다른 하나는 그대로다. 매진 자체의 절차는 RB-14를 본다.
4. 대기 상태 파일이 S3 사본을 읽는 중인지 `pollHintMs`와 `stateDegraded`를 함께 본다. `stateDegraded`가 `1`이면 `pollHintMs`가 그 구간 주기의 2배가 된다(RB-03).

## 2. 해제(되돌리기) 절차

1. CDN 캐시 오류율이 발동 신호 아래로 돌아왔고 원본 그룹의 500·502·503·504·2초·1회 값이 그대로인지 확인한다. 원본이 아직 아프면 고정을 풀지 않는다.
2. commander가 명령 6의 `STATE_MIRROR_FIXED` 행에 되돌리기를 요청한다. 되돌리기는 `queueFilesOrigin`을 `ORIGIN_GROUP`으로 돌리고 명령은 `REVERTED`가 된다. 재인증이 필요한 commander 1인 실행이다(ADR-0340 결정 5).
3. `SOLD_OUT_STATIC`을 함께 켰으면 그것도 따로 되돌린다. `queueEntryResponse`가 `ORIGIN`으로 돌아왔는지 확인하고, S3 사본 고정이 아직 켜져 있는지와 섞이지 않았는지 본다.
4. 되돌리기 감사 기록에 `mode`, `transition: OFF`, `scope`가 남았는지 확인한다. `STATE_MIRROR_FIXED`·`SOLD_OUT_STATIC`은 만료가 없어 해제를 잊으면 그 상태가 남는다.

## 3. 감사 기록 확인

1. 명령 6의 `COMMAND_CREATED`·`COMMAND_APPROVED`·`COMMAND_EXECUTION_STARTED`·`COMMAND_ACKED`·`COMMAND_REVERT_STARTED`·`COMMAND_REVERTED` 감사 기록에 `mode`, `transition`, `scope`가 있는지 본다. `DISPATCHED` 사건 `detail`에도 같은 값이 남는다.
2. CloudFront 설정 실행기가 실패하면 명령은 `FAILED cdn-settings-unavailable`이고 `ACKED`로 적지 않는다. 다시 하기로 같은 값을 다시 보낸다.
3. 실제 CloudFront 배포·원본 그룹·S3 사본의 설정 검사는 F-09-4 `미실행`이다. 이 런북의 확인은 포트·가짜와 관제 콘솔의 값까지다.
