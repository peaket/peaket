# RB-40: CloudFront·DNS 전체 장애

- **서비스·영역**: 게이트웨이
- **증상 분류**: 가용성
- **증상**: 외부 합성 점검 탐침 3곳 가운데 2곳 이상이 실패해 CloudFront·DNS 전체 장애가 의심될 때
- **탐지 경로**: 경보
- **심각도**: SEV1
- **발동 신호**: 외부 합성 점검 탐침 3곳 가운데 2곳 이상이 실패해 CloudFront·DNS 전체 장애가 의심될 때 — [관측 §5](../observability.md)
- **담당**: 플랫폼 담당
- **목표 시간**: 미정

## 즉시 조치

1. 클러스터 밖 상태 페이지(Upptime)와 합성 점검으로 확인하고, 클러스터 안 지표만 믿지 않는다.
2. 판매 경로가 막히면 비상 런북 CLI로 명령 3(판매 일시정지)을 내고, 관제 콘솔도 닿지 못함을 전제로 한다.
3. 회복 뒤 재개를 판단하고, 다른 CDN으로 넘기는 길은 두지 않는다.

## 에스컬레이션

- IC가 지휘하고, CL이 상태 페이지·대기실 공지를 낸다.
- DNS 변경이 필요하면 소유자 확인을 받는다.

## 복구 확인

- 합성 점검 3곳이 정상이고, 판매 재개 뒤 오류율·지연이 기준 아래이며, 공지·감사 기록이 남았다.
