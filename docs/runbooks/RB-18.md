# RB-18: 리전 전면 장애 대응

- **서비스·영역**: 공통·운영
- **증상 분류**: 가용성
- **증상**: AWS 리전 단위 전면 마비 공지와 여러 핵심 서비스 불능이 확인될 때
- **탐지 경로**: 경보·사람·외부
- **심각도**: SEV1
- **발동 신호**: AWS 리전 단위 전면 마비 공지와 여러 핵심 서비스 불능이 확인될 때 — [관측 §5](../observability.md)
- **담당**: 인시던트 지휘관(IC)
- **목표 시간**: 미정

## 즉시 조치

1. 판매를 즉시 멈추고(명령 3) 상태 페이지와 대기실 공지를 낸다.
2. 도쿄 스택의 DB·MSK·Schema Registry·게이트웨이를 Terraform으로 다시 만들고, CloudFront 원본을 도쿄로 돌린다.
3. 복원한 DB의 Outbox를 이어 보내고, 실시간 원시 표는 브론즈에서 채운 뒤 PG 정산 대사를 한다.

## 에스컬레이션

- IC가 전체를 지휘하고, DBA·플랫폼 담당·결제 담당이 각 복구를 맡는다.
- 장기화되면 CL이 대외 공지와 법정 통지를 준비한다.

## 복구 확인

- 도쿄 스택에서 핵심 흐름이 끝까지 돌고, CloudFront 원본·PG 대사·Outbox가 정상이며, 서울 복구 뒤에도 데이터가 맞는다.

## 포스트모템

- 인시던트로 선언하면 [RB-17](RB-17.md)에 따라 48시간 안에 비난 없는 포스트모템을 쓴다. 선언 기준에 들지 않으면 이슈로 남긴다.
