# S-T18 화면 낭독기 완주 확인 목록(대체 좌석 목록)

- **무엇**: 좌석 화면의 접근성 대안 목록(SeatList, CMP-022)으로 예매를 끝까지 마치는 사람 확인 목록이다(docs/features/seat-hold.md S-T18, NFR-020, FE-T18, ADR-0237).
- **누가**: 소유자(사람 확인). 이 묶음(BAT-175)은 목록과 시험 틀만 만든다. 자동 검사(axe)와 목록 값 시험은 CI가 맡는다.
- **정본**: 판정 기준은 docs/features/seat-hold.md S-T18, 화면 규칙은 docs/frontend.md §5.11·§5.2, 좌석 목록 구현은 `apps/web/src/_pages/seats/ui/SeatList.tsx`·`model/seat-list.ts`다. 이 문서는 검토 기록이고 규범이 아니다.

## 1. 환경과 횟수

| 조합 | 기기·브라우저 | 낭독기 | 상태 |
| --- | --- | --- | --- |
| A | Windows 11 + Chrome | NVDA 최신 | 미실행(소유자 몫) |
| B | Android + Chrome | TalkBack 최신 | 미실행(소유자 몫) |
| C | iPhone + Safari | VoiceOver | 미실행(기기를 구할 때까지, ADR-0237) |

- 조합마다 시나리오를 3회 [가정] 완주한다. 3회 가운데 하나라도 끊기면 그 조합은 실패다.
- VoiceOver 몫은 기기가 없어 지금은 100%로 쓰지 않는다(ADR-0237, open-items 108번).

## 2. 시나리오

1. 공연 상세에서 사전 사람 확인을 마치고 대기실로 들어간다.
2. 차례가 되어 좌석 화면으로 입장한다.
3. [목록으로 보기]를 눌러 SeatList로 간다.
4. 구역 → 열 → 좌석 순서로 펼치고, 좌석 상태·등급·가격을 듣는다.
5. 좌석 2개를 고르고, 고른 좌석과 합계를 확인한다.
6. 홀드하고, 남은 시간과 결제로 가는 길을 확인한다.
7. 결제 화면에서 주문 내용을 확인하고 결제 결과 화면까지 간다(실제 결제는 하지 않는다. 시뮬레이터를 쓴다).

## 3. 확인 항목

| # | 확인 | 통과 기준 |
| --- | --- | --- |
| 1 | 목록 진입 | [목록으로 보기]를 누르면 초점이 목록의 첫 줄(구역)로 간다. 낭독기가 "좌석 목록, 트리"와 첫 구역 이름을 읽는다 |
| 2 | 트리 구조 | 구역·열·좌석이 모두 트리 항목으로 읽히고, 수준·순서(1/3 등)가 들린다. 중첩 목록 상자(listbox)로 읽히지 않는다 |
| 3 | 펼치기 | → 또는 Enter로 구역·열을 펼치고, ←로 접고 부모로 돌아간다. 펼친 뒤 첫 자식으로 초점이 간다 |
| 4 | 좌석 이름 | 좌석마다 구역·열·번호·상태·등급·가격이 한 번에 들린다. 상태는 색이 아니라 말로 들린다 |
| 5 | 고르기 | Enter 또는 Space로 좌석을 고르고, 다시 누르면 푼다. 고른 좌석은 "선택됨"으로 들린다 |
| 6 | 고를 수 없는 좌석 | 판매됨·선택 불가 좌석은 "사용 안 함"으로 읽히고, 눌러도 아무 일이 없다 |
| 7 | 글자로 찾기 | 첫 글자를 치면 그 글자로 시작하는 줄로 간다. 입력 칸이 없어도 동작한다 |
| 8 | 초점 유지 | 가상 스크롤로 줄이 사라져도 초점이 목록 밖으로 나가지 않는다. 구역을 바꾸면 새 구역의 첫 줄로 간다 |
| 9 | 요약 | 고른 좌석·매수·합계가 낭독기로 확인된다. 홀드 뒤 남은 시간이 주기적으로 읽히지 않아 방해하지 않는다 |
| 10 | 오류·끝 | 홀드 실패·판매 종료·예매 시간 끝 안내가 경고(alert)로 읽히고, 다음에 할 일이 들린다 |
| 11 | 확대·재배치 | 400% 확대(320px)에서도 목록·요약·버튼이 잘리지 않고, 가로 스크롤 없이 Tab으로 닿는다(FE-T31과 함께 본다) |
