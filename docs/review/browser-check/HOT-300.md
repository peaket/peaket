## 실패와 확인 못 함

- Claude in Chrome: 연결이 없어 누르지 못했다(위 두 경로로 대신 봤다).
- 셸 전체의 오프라인 띠: 셸 단계가 정한다. 홈은 그 전까지 본문 위에 띠를 띄운다.
- 토큰 갱신 뒤 다시 보내기(401 → 갱신 → 다시): 가짜 API에 갱신 경로가 없어 화면에서 누르지 못했다. 같은 방식의 기존 기능 시험이 있다.
- 웹 푸시 권한 요청: 알림 단계(GAT-250)가 한다. 지금은 시트의 버튼이 신청만 보낸다.

- 도구 한계(이 날 확인):
  - 확장은 페이지가 `window.open`으로 연 팝업 창을 다루지 못한다(확장이 맡은 탭 묶음 밖이다). 팝업 길은 Playwright(Chromium)로 같은 서버를 눌렀다.
