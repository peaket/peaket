# 브라우저 확인: HOT-300 홈(SCR-001) 데이터 잇기

- 날짜: 2026-11-05
- 커밋: 이 기록과 같은 커밋(HOT-300)
- 브라우저: **Claude in Chrome 못 함(연결 없음, HOT-290·291과 같다)**. 대신 다음 두 가지로 봤다. 다음에 Chrome이 연결된 턴에 다시 누른다.
  - Claude 데스크톱 앱 안 브라우저(Chromium)로 개발 서버를 열었다.
  - 판을 고정한 Playwright로 운영 빌드를 운영 헤더(CSP)로 열었다. Chromium·WebKit·Firefox로 61개 통과했고, 엔진과 상관없는 검사는 Chromium만 돈다.
- 환경:
  - 계약 모양 가짜 API(`apps/web/scripts/mock-api.mjs`, 127.0.0.1:4010, 고정 자료 `cards.json`)
  - 소비자 웹 개발 서버(`next dev --port 3100`, `PEAKET_API_ORIGIN`·`NEXT_PUBLIC_API_ORIGIN`·`PEAKET_DEV_STATIC_ORIGIN`·`PEAKET_CSP_ORIGINS`는 가짜 API)
  - CSP 검사는 `tools/web-checks` 운영 빌드
- 범위: SCR-001(d5 §5.1 상태 표), FE-T35, ASVS v5.0.0-3.4.3

## 실패와 확인 못 함

- Claude in Chrome: 연결이 없어 누르지 못했다(위 두 경로로 대신 봤다).
- 셸 전체의 오프라인 띠: 셸 단계가 정한다. 홈은 그 전까지 본문 위에 띠를 띄운다.
- 토큰 갱신 뒤 다시 보내기(401 → 갱신 → 다시): 가짜 API에 갱신 경로가 없어 화면에서 누르지 못했다. 같은 방식의 기존 기능 시험이 있다.
- 웹 푸시 권한 요청: 알림 단계(GAT-250)가 한다. 지금은 시트의 버튼이 신청만 보낸다.
