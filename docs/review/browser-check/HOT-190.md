- 날짜: 2026-11-10
- 커밋: 이 기록과 같은 커밋(BAT-145)
- 브라우저: Chrome(Windows), Claude in Chrome 시험용 프로필
- 환경: 계약 모양 가짜 API(127.0.0.1:4012, `partnerImage=` 상태, `PEAKET_PARTNER_ORIGIN=http://localhost:3011`), 파트너 콘솔 운영 빌드(`next start`, 3011, `NEXT_PUBLIC_PARTNER_API_ORIGIN=http://127.0.0.1:4012`). 그림은 단색 PNG(포스터 900×1200, 상세 1000×700·1200×800, 작은 600×800)와 글자를 PNG 이름으로 둔 파일
