# 브라우저 확인: BSL-070 ② v0 좌석맵의 랩 판정 계측

- 날짜: 2026-11-03
- 커밋: 이 기록과 같은 커밋(BSL-070 ②)
- 브라우저: **Claude in Chrome 못 함(연결 없음)**. `list_connected_browsers`가 빈 목록이었다. 이 PC에 Playwright 패키지도 없어, PUB-010처럼 Claude 데스크톱 앱의 내장 브라우저(Chromium, LoAF 지원)로 대신 눌렀다. 다음에 Chrome이 연결된 턴에 같은 시나리오를 다시 누른다(PROGRESS 턴 규칙).
- 환경: 로컬 실행(병렬 세션 전용 이름·포트). Valkey 8.1·PostgreSQL 18 컨테이너(`lane2-valkey`·`lane2-pg`), PG 시뮬레이터(18790), v0 모놀리스(`dist/main.js`, 18080), 게이트웨이 대역(`scripts/local-gateway.mjs`, 18088), 준비 스크립트(`scripts/local-demo.mjs demo-1 user1,user2`: 4,000석, 두 계정 입장).
- 범위: docs/features/seat-hold.md §14 동작 7의 랩 판정 계측, K5, NFR-012, docs/security/asvs/v0-baseline.md 3.4.3.

| 시나리오(근거 ID) | 결과 | 본 것 | 콘솔·요청 오류 |
| --- | --- | --- | --- |
| 화면 열기: 계측 파일이 화면 스크립트보다 먼저 실린다(§14 동작 7) | 통과 | 스크립트 순서 `/v0/seatmap/assets/vitals.js` → `seatmap-page.js`, '실시간 연결됨', `window.__peaketVitals`가 있고 처음 값은 비어 있음(`inp`·`lcp`·`cls` null, `loaf` 0) | 없음 |

| CSP 위반·스크립트 오류(asvs 3.4.3) | 통과 | 오류 콘솔 없음(같은 출처 `web-vitals.js`가 `script-src 'self'` 안에서 실림) | 없음 |

- 숫자에 대한 주의: 이 확인은 계측이 값을 모으는지 보는 것이지 측정이 아니다. 데스크톱 앱 창이 숨겨져 있어 그림을 그리지 않았고, 그래서 INP의 표시 지연이 약 1초로 부풀었으며 LCP는 나오지 않았다(그리지 않은 화면에는 LCP 후보가 없다). K5 판정 값은 Before 측정(BSL-090)이 중급 모바일 프로필로 20회 [가정] 재서 낸다(docs/frontend.md §5.8).
- 캡처: 창이 숨겨져 화면 캡처가 시간 초과로 실패해 남기지 못했다. 값은 페이지의 `window.__peaketVitals`와 DOM 글로 읽었다.
- 사람 확인이 필요한 것은 없다(계측은 보이는 화면을 바꾸지 않는다).
