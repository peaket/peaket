- 날짜: 2026-11-05
- 커밋: 이 기록과 같은 커밋(HOT-344)
- 브라우저: Claude in Chrome(Chrome, Windows, 시험용 프로필)
- 환경: 계약 모양 가짜 API(127.0.0.1:4010)에 예매 제한 조회(`restriction=none|active|overdue|fraud`)와 취소표 알림 신청(`subscribe=normal|limit|busy|ended`)을 더했다. 소비자 웹 개발 서버(3000)가 대기실 경로를 대기실 개발 서버(3004)로 넘겨 같은 출처로 띄웠다. 회차는 고정 자료의 뮤지컬 별빛 정원(`0b8f1f2e-…4e04`)이다.

## 브라우저 밖 시험

- 소비자 웹 `src/entities/me/restriction.test.mjs`(SCR-002): 글·소명 링크·KST 날짜·기한 지남·제한 ID 없음, 가게(한 번 받기·실패는 제한 없음·3초 시간 초과와 늦은 답·다시 받기 세대 번호), ⑦을 덮는 때(회원·살 수 있는 때만, 받는 중 뼈대).
- 대기실 `test/restricted.test.mjs`(SCR-008): 403 뒤 팬 API 한 번, 대기표 유지, 폴링 멈춤, 기한 지남·NONE·실패·제한 ID 없음. `test/cancel-alert.test.mjs`(SCR-018): 신청 상태 아홉 경우, 응답 일곱 경우, 401 갱신. `test/roll.test.mjs`(SCR-008): 바뀐 자리만, 자릿수가 줄고 늘 때.
- 가짜 API(`scripts/mock-api.test.mjs`): 예매 제한 네 상태와 취소표 신청 201·200·DELETE·400·422·429·410이 계약 Zod를 지난다.

## 확인 못 함

- 움직임 줄이기·저전력의 숫자 굴림 끄기: 확장으로 `prefers-reduced-motion`을 바꿀 수 없다. CSS(`@media (prefers-reduced-motion: reduce)`·`.q-still`)가 `.q-digit-stack`의 효과를 끈다.
- 사전 사람 확인 카드를 제한된 팬에게 숨기기: 가짜 API에 오픈 전 선착순(로비 없는) 회차 상태를 만들지 않았다. 코드(`BookingPreverifyCard`가 제한 상태가 '없음'일 때만 그린다)로 본다.
- 이미 신청한 취소표가 판매 종료로 끝난 상태(`endReason` SALE_ENDED)로 처음 그리기: 가짜 API가 끝난 신청을 만들지 않는다(단위 시험이 본다).
