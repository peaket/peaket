# 브라우저 확인: HOT-323 가입 완료·동의(SCR-005)와 본인확인 흐름 데이터 잇기

- 날짜: 2026-11-05
- 커밋: 이 기록과 같은 커밋(HOT-323)
- 브라우저: **Claude in Chrome 못 함(연결 없음, HOT-290~321과 같다)**. 그래서 Claude 데스크톱 앱 안 브라우저(Chromium)로 개발 서버를 열었다. 다음에 Chrome이 연결된 턴에 다시 누른다.
- 환경
  - 계약 모양 가짜 API(127.0.0.1:4010, `fan=pending`): 가입 마무리·닉네임 확인·가입 취소·토큰 갱신. 쓰는 닉네임은 '지민'·'피켓'·'peaket'이다.
  - 소비자 웹 개발 서버(`next dev --port 3000`)
- 범위: SCR-005(d5 §5.5), SCR-006 부르는 화면 흐름(d5 §5.6), ADR-0203

## 실패와 확인 못 함
- Claude in Chrome: 연결 없음(위).
- 본인확인 기관 창 끝까지(성공·결과 대화상자 여러 가지): 가짜 API에 본인확인 경로가 없다. 기관 창 흐름은 `flow.test.mjs`(I-T45, 이번에 앞일·돌아갈 주소 시험을 더함)와 BOT-010의 모의 기관이 본다.
- 개발 서버 콘솔의 `/signup/consent`·`/verify/return` 'URL data during prerendering' 경고: 페이지 경로 파일에 `instant = false`를 달았다. 하지만 콘솔에 남은 메시지가 그 전 것인지 가르지 못했다(같은 묶음 이름). 운영 빌드에는 영향이 없다.
