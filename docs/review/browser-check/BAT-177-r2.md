# 브라우저 확인: BAT-177-r2 월렛 첫 화면 — 앞 서버의 정적 파일 압축

- 날짜: 2026-11-23
- 범위: SCR-017(월렛), OPEN[52] (나) 2차 바퀴, ADR-0359
- 결과: **통과(부분)**. 화면 모양은 바뀌지 않았다. 정적 파일 응답 머리와 월렛 첫 화면을 운영 빌드에서 확인했다.
- 환경: 작업 폴더 `D:/ticketpass-lane2-base-BAT-177`의 운영 빌드(.next), 앞 서버 `apps/web/server/start.mjs --port 4181 --inner-port 5181`(`PEAKET_ENV=ci`), 가짜 API `apps/web/scripts/mock-api.mjs 4010`. Claude 데스크톱 내장 브라우저.
