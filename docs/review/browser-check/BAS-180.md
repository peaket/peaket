- 커밋: 이 기록과 같은 커밋(BAS-180)
- 브라우저: **Claude in Chrome 못 함(연결 없음, `list_connected_browsers`가 빈 목록)**. 대신 ① 판을 고정한 Playwright 컨테이너(1.64.1)의 Chromium·WebKit·Firefox에서 동작 시험을 실제 클릭·키 입력으로 돌리고(`tools/web-checks/ds/behavior.spec.mjs`, 16개 × 3엔진), ② Claude 데스크톱 앱 안 브라우저로 Storybook 화면(관리 화면과 접근성 패널)을 눌러 봤다. 다음에 Chrome이 연결된 턴에 다시 누른다.
- 환경: `tools/storybook`(뿌리와 따로 둔 Storybook 작업 공간)에서 `pnpm run build`한 정적 빌드를 `tools/web-checks/lib/serve.mjs`로 로컬(127.0.0.1)에서 띄움. 서버·합성 데이터는 쓰지 않는다(부품만 본다).

## 실패와 확인 못 함
- Claude in Chrome: 연결이 없어 누르지 못했다. 다음 연결 턴에 대화상자·이유 있는 비활성 버튼 두 시나리오를 다시 누른다.
- 처음 바꾼 대화상자는 Esc로 닫은 뒤 초점이 연 버튼으로 돌아오지 않았다(세 엔진). 이 부품이 첫 초점을 옮긴 뒤에 SEED 초점 범위가 '돌아갈 곳'을 기억해서다. 동작 시험이 먼저 잡았고, 연 요소를 레이아웃 효과에서 기억해 이 부품이 되돌리게 고친 뒤 통과했다.

## Chrome 다시 확인(2026-11-05)

- 브라우저: Claude in Chrome(Chrome, Windows, 시험용 프로필). 위에서 '다음에 Chrome이 연결된 턴에 다시 누른다'고 한 것을 이 날 눌렀다.
- 환경: `tools/storybook` 정적 빌드(대화상자 부품이 마지막으로 바뀐 뒤에 만든 것)를 `lib/serve.mjs`로 127.0.0.1:4300에 띄움.

| 시나리오(근거 ID) | 결과 | 본 것 |
| --- | --- | --- |
| 대화상자 열기·가두기·닫기(CMP-019, FE-T18) | 통과 | '좌석을 놓을까요?' `aria-modal`, 처음 초점 [닫기], Tab·Shift+Tab이 [닫기]↔[놓기] 안에서만 돈다, Esc로 닫으면 초점이 [대화상자 열기]로 |
| 탭 화살표(CMP-030) | 통과 | → 다음 탭(선택·초점, 나머지 `tabindex=-1`), End는 마지막 쓸 수 있는 탭(비활성 '유의 사항'은 건너뜀), 끝에서 → 는 처음으로 |

- 도구 한계(이 날 확인):
  - 확장은 페이지가 `window.open`으로 연 팝업 창을 다루지 못한다(확장이 맡은 탭 묶음 밖이다). 팝업 길은 Playwright(Chromium)로 같은 서버를 눌렀다.
  - 확장의 콘솔 읽기는 CSP 위반을 보이지 않는다(페이지에 끼운 인라인 스크립트가 막혔는데 메시지가 없었다). 위반 수는 브라우저 시험이 센다.
  - 확장의 요청 목록은 가짜 API의 204 응답(토큰 갱신)을 503으로 보였다. 가짜 API 쪽 기록은 204였다.
  - `resize_window`는 최대화된 창을 줄이지 못했다. 화면 크기별 모양은 Playwright 기록을 그대로 둔다.
