- 인앱 User-Agent 두 시나리오: Claude in Chrome으로는 확인 못 함(User-Agent를 바꿀 수 없다, 계획 §8 머리와 같다). 위처럼 Playwright Chromium으로 대신 봤고, 정식 판정은 T10(`tools/web-checks/reflow/in-app.spec.mjs`)이 한다.
- 실패는 없다.

## 관찰(실패 아님, 감독 참고)

- `/en/events/<있는 회차>`와 `/en/…` 404 화면의 글·`lang`이 한국어다. 영어 화면 글은 이 묶음 범위가 아니다.
- 개발 서버 로그에 `/open-in-browser`·`/my/tickets`가 `searchParams`를 Suspense 밖에서 읽는다는 Next.js 개발 모드 경고("instant-shell-url-data")가 다섯 번 찍혔다. 운영 서버 로그에는 없다.
