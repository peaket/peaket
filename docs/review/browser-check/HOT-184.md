## 새 맥락 리뷰 재현(화면에서만 보이는 16건, 고치기 전 모두 실패, 고친 뒤 모두 통과)
앱 안 이동의 마지막 입력 저장, 처음부터 다시 뒤 초안을 되살리지 않음, 다른 탭 등록 뒤 멈춤과 다른 탭 입력 따라오기, 등록 중 입력 잠금, 저장소를 못 쓸 때 같은 멱등 키, 새 공연장 주소·새 아티스트 칸의 오류 연결, 공연장을 고른 뒤 초점, 한글 조합 중 Enter, 하단 막대에 가리지 않는 초점, 아티스트 20명 상한, 칸을 떠날 때 다른 이름 더하기, 시안 표시 없음, 시각 칸 연도 네 자리, 검색어를 바꾸면 옛 후보 치움.

## 실패와 확인 못 함
- 실제 게이트웨이·로그인을 거친 등록은 확인 못 함: 파트너 게이트웨이 경로(BOT-132)가 아직 없다. 서버 쪽 등록은 core-svc 시험이 본다.
- Firefox·WebKit은 이번에 누르지 않았다. 엔진 차이는 E2E 묶음이 본다(`datetime-local` 입력 포함).
