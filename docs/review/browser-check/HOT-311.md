# 브라우저 확인: HOT-311 공연 상세(SCR-002) 데이터 잇기

- 날짜: 2026-11-05
- 커밋: 이 기록과 같은 커밋(HOT-311)
- 브라우저: **Claude in Chrome 못 함(연결 없음, HOT-290·291·300과 같다)**. 대신 다음 세 가지로 봤다. 다음에 Chrome이 연결된 턴에 다시 누른다.
  - Claude 데스크톱 앱 안 브라우저(Chromium)로 개발 서버를 열었다(휴대폰·태블릿 폭과 데스크톱 1280).
  - 운영 빌드를 앞 서버(`apps/web/server/start.mjs`)로 띄워 응답 상태·캐시 머리를 직접 받았다.
  - 판을 고정한 Playwright로 운영 빌드를 운영 헤더(CSP)로 열었다. 리뷰 고침 뒤 다시 빌드해 Chromium·WebKit 62개 통과(이 PC의 Firefox는 HOT-300과 같은 실행 오류로 돌리지 못했다). 엔진과 상관없는 검사는 Chromium만 돈다.
- 환경:
  - 계약 모양 가짜 API(`apps/web/scripts/mock-api.mjs`, 127.0.0.1:4010, 고정 자료 `cards.json`의 카드 7장, 회차는 기간 하루 한 회차)
  - 소비자 웹 개발 서버(`next dev --port 3000`, `PEAKET_API_ORIGIN`·`NEXT_PUBLIC_API_ORIGIN`·`PEAKET_DEV_STATIC_ORIGIN`·`PEAKET_CSP_ORIGINS`는 가짜 API)
  - 운영 빌드: `tools/web-checks`의 `node seed-css/build.mjs web` 뒤 앞 서버 4101(안쪽 5101), 서버 쪽 원본은 가짜 API
- 범위: SCR-002(d5 §5.2 상태 표), SCR-016 띄우기, ADR-0200·0201, ASVS v5.0.0-1.2.1·3.4.3

## 실패와 확인 못 함
- Claude in Chrome: 연결 없음(위).
- 시각에 매인 상태 넷: 위 표 마지막 행. 데모 시계(d5 §10.4)가 생기면 화면에서 다시 본다.
- 회차가 많은 공연(가짜 API 뮤지컬 52회차)은 회차 칩이 히어로를 길게 채운다. CMP-066의 고르기(select) 변형(d2)이 ds에 아직 없어 구간 끝 정리 목록에 남겼다(docs/lanes/lane2.md).
