## 실패와 확인 못 함

- 앱 안 브라우저로 로컬 실제 스택을 눌렀다. 시험용 Chrome 프로필의 Claude in Chrome 연결은 쓰지 않았다.
- 템플릿 변형 값(돌출 길이 등)은 계약대로 검증만 하고 정적 템플릿 도형에는 아직 반영하지 않는다(웨이브 보고서의 남은 문제).
- 파일 대화상자를 거치는 가져오기 왕복은 이번 확인 범위가 아니다(기존 FE-T46 E2E가 본다).
- 콘솔 오류는 첫 불러오기의 예상 404 한 건뿐이었다.
