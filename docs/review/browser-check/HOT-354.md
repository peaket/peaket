## 실패와 확인 못 함

- NVDA 키보드 완주(FE-T18 수동 칸): 2026-11-09 소유자가 Windows Chrome에서 목록 열기 → 구역·열 펼치기 → 좌석 고르기 → 판매 좌석 → [좌석 홀드하기] 순서를 키보드로 모두 할 수 있다고 알렸다. 회차별 반복 수와 낭독 문구별 결과는 받지 않았다.
- VoiceOver·TalkBack: 기기가 있어야 해 아직 못 했다. 결제·양도까지의 정식 시험(조합·시나리오마다 3회)은 LCH-190에서 한다.
- 화면 캡처: 좌석맵이 뜬 탭에서 Chrome 캡처가 시간 초과로 실패해 글과 속성으로 봤다.
