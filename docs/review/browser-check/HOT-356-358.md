## 브라우저 밖 시험

- 홀드 실행부(`apps/web/src/_pages/seats/model/hold-lifecycle.test.mjs`): 새로고침·404·일시 장애 재시도 후 안내·연장 409 다시 읽기·해제·놓은 좌석·결제 중 409
- 결제 시도·결제창(`apps/web/src/_pages/checkout/model/payment-attempt.test.mjs`): 응답 대응표, 멱등 키, 가짜 SDK로 토스·포트원 창, 데모 창
- 좌석맵 엔진(`packages/seatmap/test/hover.test.ts`): 놓은 좌석 고르기 막기와 풀림
- 운영 빌드(`next build`, 데모 값 없이): 시뮬레이터 코드가 든 조각 0개, 토스·포트원 조각은 결제 화면의 SRI 목록에만 있고 어느 경로의 첫 JS(`build-manifest`)에도 없음

## 확인 못 함

- 실제 토스·포트원 결제창: 키와 실제 결제사 서버를 쓰지 않았다(소유자 지시). 두 SDK 구현은 가짜 SDK로만 시험했다.
- 결제 화면 CSP의 `frame-src`·`connect-src`·`form-action`: 실제 결제창을 띄워 모아야 정할 수 있다(docs/frontend.md, 스테이징 몫).
- Firefox·WebKit: 이 묶음에서는 Chrome만 봤다.
