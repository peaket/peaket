## 실패와 확인 못 함

- **실제 409 견적·두 번째 확인**: 재인증 창을 실제 OIDC 공급자 없이 통과할 수 없어 화면에서 끝까지 누르지 못했다. 자동 시험 I-T26 ②-4가 409 본문 해석, 첫 누름에 확인 값을 싣지 않음, 두 번째 누름에 `confirmCancelUnusedTickets: true`를 실음, 견적 카드의 낭독 차례를 본다. 다음에 Chrome 확장이 연결된 턴에 실제 재인증 대역으로 이 시나리오만 다시 누른다.
- **Chrome 확장 연결 없음**: 이 턴은 내장 브라우저로 대신했다. 실제 사용자 프로필·확장 환경의 차이는 다음 연결 턴에 다시 본다.
