## 2. `/_q/` 업로드 목록

`node scripts/upload-manifest.mjs dist`가 만든 6개 키(셸 4·JS 1·CSS 1)를 4106에서 모두 받았다(200). 캐시 정책은 업로드 목록이 정한 값(셸 `max-age=0, must-revalidate`, `assets/*` 1년 immutable)이고, 로컬 정적 서버는 확인용으로 `no-store`를 준다. 실제 S3 메타데이터 적용은 HOT-012·BAT-185 몫이다.

## 5. 대기실 세 엔진 검사

`tools/web-checks/playwright.queue-room.config.mjs` 전체를 Chromium·WebKit·Firefox로 돌려 **36개 통과**했다(T=0 두 호출의 사전 요청 0, `AbortSignal.any` 없는 페이지, 폴링 간격, 여러 탭 리더·방송·차례 도착). 로케일 셸은 이 검사의 한국어 셸 경로와 같은 빌드 산출물을 쓴다.
