## 실패와 확인 못 함

- **입력 칸에서 바로 Enter를 누르면 아무 일도 일어나지 않는다.** 폼의 `onSubmit`이 기본 동작만 막는다. 이번 단계 전부터 그랬고(HOT-050), 정본에 Enter 동작이 적혀 있지 않아 실패로 치지 않았다. 구간 끝 정리 목록에 넣었다.
- '결과 파일을 실제로 읽었는데 해시가 없음' 안내는 가짜 API에서 만들 수 없어(묶음 파일이 없음) 화면에서 보지 못했다. 웹 단위 시험이 본다.
- 처음부터 끝까지 위조한 응답은 브라우저가 BLS 서명을 검증하지 않으므로 알아낼 수 없다(ADR-0239 결정 3, 화면에 적혀 있음).
