# 브라우저 확인: BOT-041 설정의 로그인 수단 연결·해제

- 날짜: 2026-11-04
- 커밋: 이 기록과 같은 커밋(BOT-041)
- 브라우저: **Claude in Chrome 못 함(연결 없음)**. BOT-010과 같은 까닭으로 Playwright(1.58.2, Chromium 156 headless shell)로 실제 클릭을 해 대신 눌렀다(docs/review/browser-check/BOT-010.md). 다음에 Chrome이 연결된 턴에 다시 누른다.
- 환경: BOT-040과 같은 로컬 스택. identity DB에 마이그레이션 0012(account_provider.last_login_at)를 적용했다. 모의 OIDC 제공자는 BOT-040의 감싸개(시나리오마다 sub·이메일을 바꾸는 조종 포트, 저장소 밖)로 띄웠다.
- 범위: SCR-040 ①②③(docs/design/d5 §5.22), SCR-017 탈퇴의 재인증 창, docs/features/identity.md §2.1 '설정의 로그인 수단 연결·해제의 첫 구현', I-T33, I-T34.
- 다시 누름: 새 맥락 리뷰를 고친 뒤(추가·해제의 세션 생존 확인, 같은 종류 연결 막기, 추가 실패 돌아오기, 목록 실패 안내, 고르기 문구) 다시 빌드한 스택에서 새 시험 사람으로 다섯 시나리오를 다시 눌렀다. 아래 표는 다시 누른 결과다.
