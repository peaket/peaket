# 브라우저 확인: HOT-345 ① 대기실 좌석 자원 미리 받기

- 날짜: 2026-11-05
- 커밋: 이 기록과 같은 커밋(HOT-345 ①)
- 브라우저: Claude in Chrome(Chrome, Windows, 시험용 프로필)
- 환경: 계약 모양 가짜 API(127.0.0.1:4010)가 좌석맵 자리 파일(8석, immutable)을 낸다. 소비자 웹 개발 서버(3000)가 대기실 경로와 좌석맵 경로를 넘겨 같은 출처로 띄웠다(대기실 개발 서버 3004도 같은 경로를 가짜 API로 넘긴다). 회차는 뮤지컬 별빛 정원(`0b8f1f2e-…4e04`), 앞 140명·속도 2.
- 범위: SCR-008 '차례와 입장'의 좌석 자원 미리 받기(docs/frontend.md §5.1), ADR-0216

## 새 맥락 리뷰 뒤 다시 본 것

- 차례 뒤에는 받지 않기·판 번호는 정수만·페이지마다 한 번으로 고친 뒤 같은 조건(앞 125명·속도 2)에서 다시 열었다. 앞 116명(약 58초)에서 좌석맵 200을 한 번 받았다.

## 브라우저 밖 시험

- `apps/web/queue-room/test/preload.test.mjs`(SCR-008): 좌석맵 경로 검사(다른 출처·다른 회차·`..`·쿼리·확장자·`javascript:`), 자산 목록 v1(`/_next/static/` 아래 .js·.css만), 60초 안 리더만·같은 경로 한 번·판이 바뀌면 다시, 숨긴 탭·경로 없음·검사에 걸린 경로는 받지 않음.
- `test/live-net-store.test.mjs`(FE-T15 단위 부분): `AbortSignal.any`가 없을 때 요청이 끝나면 화면 신호의 듣기를 지우고, 화면을 떠나면 `AbortError`로 끝난다.
- 가짜 API(`scripts/mock-api.test.mjs`): 좌석맵 자리 파일이 계약 Zod를 모르는 칸 없이 지나고 immutable이며, 없는 판·회차는 404.

## 확인 못 함

- `priority: "low"`가 실제로 낮은 우선순위로 나갔는지: 확장 도구로는 요청 우선순위를 볼 수 없다(Chromium 개발자 도구 프로토콜로만 보인다). HOT-347의 세 엔진 검사 틀에서 본다.
- 숨긴 탭에서 받지 않음: 확장 탭은 배경이어도 보이는 상태다(단위 시험이 본다).
