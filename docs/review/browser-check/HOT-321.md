# 브라우저 확인: HOT-321 로그인 화면·셸 로그인 표시·공연 상세 개인 상태 데이터 잇기

- 날짜: 2026-11-05
- 커밋: 이 기록과 같은 커밋(HOT-321)
- 브라우저: **Claude in Chrome 못 함(연결 없음, HOT-290~313과 같다)**. 그래서 Claude 데스크톱 앱 안 브라우저(Chromium)로 개발 서버를 열었다. 다음에 Chrome이 연결된 턴에 다시 누른다.
- 환경: 계약 모양 가짜 API(127.0.0.1:4010, 팬 계정 요약 `GET /v1/identity/me`, `/__mock/state?fan=member|unverified|pending|guest`), 소비자 웹 개발 서버(`next dev --port 3000`, 팬 API는 가짜 API)
- 범위: SCR-004(d5 §5.4), 셸 머리(CMP-065), SCR-002 ⑦ '비로그인'·'본인확인 필요'·③(d5 §5.2), ADR-0202, FE-T12

## 실패와 확인 못 함
- 진행 중: 위 표. 실제 보내기를 막고 누른 확인은 이 결함을 볼 수 없었다. 폼 보내기 확인은 브라우저 시험으로 옮겼다.
- 오픈 뒤 회차의 개인 상태에 '오픈 알림 받기'가 함께 보이던 것: 이 확인에서 찾아 고쳤다(위 표 '상세 비로그인').
- Claude in Chrome: 연결 없음(위).
- 로그아웃: 개발 서버에서 로그인 경로(`app/(request)/login`·`logout`·`reauth`)가 contracts proto 생성물의 `.js` 가져오기를 풀지 못한다. 운영 빌드는 아래 기록대로다. 갈래 기록 '구간 끝 정리 목록'에 남겼다.
- 본인확인 기관 창: 위 표.
