# 브라우저 확인: BOT-036 탈퇴 화면을 재인증과 실제 API에 잇기

- 날짜: 2026-11-04
- 커밋: 이 기록과 같은 커밋(BOT-036)
- 브라우저: **Claude in Chrome 못 함(연결 없음)**. BOT-010과 같은 까닭으로 Playwright(1.58.2, Chromium 156 headless shell)로 실제 클릭을 해 대신 눌렀다(docs/review/browser-check/BOT-010.md). 다음에 Chrome이 연결된 턴에 다시 누른다.
- 환경: BOT-010과 같은 로컬 스택(갈래 3 전용 포트, apps/README.md '휴대폰 본인확인을 로컬에서 돌려 보기'). PostgreSQL 18 컨테이너의 DB를 새로 만들고 마이그레이션 0000~0010을 적용했다. 제공자는 모의 OIDC(재인증 prompt·auth_time 흉내), 본인확인은 모의 기관이다. 앱 서버에 로컬 시험용 서버 액션 암호화 키를 넣었다.
- 범위: SCR-017 탈퇴 단계(docs/design/d5 §5.17), docs/features/identity.md §8 '탈퇴 화면 연결', I-T16, I-T68 ⑨, I-T27(다시 가입).
- 다시 누름: 새 맥락 리뷰를 고친 뒤(떠나기 전 토큰 갱신, 이유별 실패 문구, 409 안내를 alert로, 완료 화면 초점) 새 시험 사람으로 네 시나리오를 다시 눌렀다. 아래 표는 다시 누른 결과다.

| 시나리오(근거 ID) | 결과 | 본 것 | 콘솔·요청 오류 | 캡처 |
| --- | --- | --- | --- | --- |
| 탈퇴(I-T16) | 통과 | 카카오 로그인·본인확인 → 계정 설정 ( 회원 탈퇴 › ) → 재인증 창이 로그인 수단 목록의 첫 제공자 [카카오로 다시 로그인하고 계속]을 보임 → 모의 제공자 재인증 뒤 `/my/settings`로 돌아와 탈퇴 확인 창이 열림(목업의 티켓·환급 줄 없음, '탈퇴 뒤 바로 다시 가입할 수 있습니다' 있음) → [탈퇴합니다] → "탈퇴했습니다 · 언제든 다시 가입할 수 있습니다". DB: 계정 `DELETED`·이메일 비움, 살아 있는 세션 0, `identity_verification` 0, 로그인 수단 연결 0, 세션 종료 사건(사유 `DELETE`) | 없음 | 없음 |
| 대조값 보관 안내 뒤 탈퇴(I-T68 ⑨) | 통과 | 네이버 계정에 RESTRICTED 보관 행을 넣고 탈퇴 → 첫 [탈퇴합니다]는 409라 "이용 제한이 끝날 때까지 본인확인 대조값을 남깁니다. 다시 가입해도 제한이 끝나는 2027년 1월 3일까지 예매할 수 없습니다." 안내가 보이고 '바로 다시 가입' 줄이 숨음(계정은 아직 ACTIVE). 안내는 `role="alert"`이고 [탈퇴합니다]의 `aria-describedby`가 그 안내를 가리킴 → 다시 누르면 같은 재인증 토큰으로 탈퇴하고 초점이 완료 제목(h1)으로 감. DB: 계정 `DELETED`, 연계정보 0, 보관 행 RESTRICTED 남음 | `DELETE /v1/identity/account` 409(일부러 냄) | 없음 |
| 다시 가입(I-T27) | 통과 | 같은 카카오 계정으로 다시 로그인하면 새 계정(ACTIVE)이다 | 없음 | 없음 |
| 재인증이 지난 탈퇴(I-T16, identity §7.1 ②) | 통과 | 새 계정으로 재인증 뒤 탈퇴 요청만 가로채 403 `reauth-required`를 돌려줌 → 재인증 창이 다시 열리고 "다시 로그인한 지 5분이 지났습니다. 다시 로그인해 주세요"를 보임. 계정은 ACTIVE 그대로 | 없음(가로챈 403은 브라우저 안에서 만든 응답) | 없음 |

- 다루지 않은 것: 재인증 실패 종류(오래된 인증·계정 불일치)는 모의 제공자 모드를 바꿔야 해 화면으로 누르지 않았다. 흐름 시험(`apps/web/src/features/account-withdraw/flow.test.mjs`)이 실패 종류와 그 문구를 본다. 떠나기 전 토큰 갱신이 실패해 로그인으로 가는 길도 흐름 시험(갱신 401)으로만 본다. 다른 기기 로그아웃은 아직 목업이다.
- 캡처: 남기지 않았다. 값은 페이지 글과 DB로 읽었다.
