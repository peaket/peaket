## 확인 중 고친 것

- **신고 429/404/실패 배너**: 확인 모달에 머물러 배너가 보이지 않던 문제를 고쳤다. 실패하면 신고 모달로 돌아가 배너를 보인다.
- **등록·폐기 대화상자 초점**: 직접 만든 겹침 대신 `Overlay`를 써서 초점 가둠·Esc·바깥 누름 닫기를 맞췄다.
- **배선 시험**: API 호출 이름만 보던 시험을 실제 호출 모양까지 보게 고쳐 변이 30/30을 만들었다.

## 남은 것

- 후기 사진 올리기는 DS가 `File`을 넘기지 않아 이번에도 본문·별점만 보낸다.
- 운영자 조치 컴포넌트는 운영자 화면에 붙이는 후속이 필요하다. 이번 확인은 개발 빌드의 `?moderator=1`로 했다.
- 기기 키 등록일·파트너 상호는 API에 없어 `—`/파트너 조회로 보완했다.
- 실제 core-svc·ticket-svc·ops-svc와 결제·좌석 저장소를 쓰는 확인은 아직이다. 이번은 가짜 API 확인이다.
