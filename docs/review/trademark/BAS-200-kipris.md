# BAS-200 KIPRIS 상표 검색 기록

- **무엇**: 서비스명 `PEAKET`·`피켓`과 심벌의 상용 출시 전 상표 등록 가능성을 KIPRIS(특허청 지식재산정보 검색)로 확인하는 절차와 현재 상태다(docs/design/d1-brief.md §3, POL-027, ADR-0036, wbs 0.6.3).
- **정본**: 판정 기준은 POL-027(추정·확인 필요·해석·간주 표기)과 d1 §3다. 이 문서는 검토 기록이고, 상표 등록 가능성의 최종 판단은 특허청 심사와 변호사 검토 몫이다.
- **현재 상태(2026-11-13)**: **미실행(사람 확인)**. KIPRIS 상표 검색은 로그인·대화형 화면으로만 결과를 내고, 저장소에는 KIPRIS Open API 서비스 키가 없다. 공개 검색 주소에 `query=PEAKET`을 넣어도 서버가 그린 결과가 아니라 화면 스크립트가 채우는 껍데기만 왔다(2026-11-13 확인). 그래서 이 묶음은 검색 목록과 절차만 만들고, 결과를 지어내지 않는다.

## 1. 검색 대상

| 구분 | 값 | 비고 |
| --- | --- | --- |
| 영문 표기 | `PEAKET` | 공식 로고·도메인 표기(d1 §3) |
| 한국어 표기 | `피켓` | 한국어 UI 문맥 표기(d1 §3) |
| 결합 표기 | `PEAKET 피켓` | 이용약관·법정 고지의 결합 표기 |
| 심벌 | 티켓 절취선 위로 솟은 산봉우리 | 도형 상표는 문자 상표와 따로 본다 |
| 유사 표기 | `PICKET`, `PEAKET`, `피켓`, `피케팅` | 표장 유사 판단은 전문가 몫이다 |

## 2. 검색할 상품·서비스 분류(국제분류)

| 류 | 대상 | 이 서비스에서의 쓰임 |
| --- | --- | --- |

| 35 | 광고·사업 관리·판매 대행 | 공연·굿즈 판매 중개, 파트너 콘솔 |

- 실제 출원 류는 변호사와 정한다. 위 넷은 검색 범위를 정하기 위한 후보이고, 최종 출원 범위가 아니다.

## 3. 검색 절차(소유자 또는 대리인)

1. KIPRIS(https://www.kipris.or.kr)에 접속해 `지식재산정보 검색 → 상표`를 연다.
2. `상표명칭(TN)`에 `PEAKET`을 넣고, 행정상태 `전체`, 검색유형 `국내`로 검색한다. 같은 검색을 `피켓`, `PEAKET 피켓`, `PICKET`으로 되풀이한다.
3. 결과가 있으면 출원번호·등록번호·권리자·지정상품·유사군·행정상태를 적는다. 특히 09·35·41·42류의 유사군 코드를 본다.
4. 도형 상표는 `유형 → 도형상표`에서 심벌 이미지로 검색한다(문자 검색과 별개).
5. 결과 화면을 PDF로 내려받아 이 문서의 표에 붙인다. 화면 캡처만 두지 않는다.
6. 결과가 없더라도 "등록 가능"이 아니라 "선행 등록 상표를 찾지 못했다"로 적는다. 최종 판단은 특허청 심사와 변호사 검토다.

## 5. 출시 전에 할 일

- 소유자 또는 대리인이 위 절차를 한 번 돌리고 결과 PDF를 이 폴더에 둔다.
- 선행 상표가 있으면 지정상품을 피하거나 표장을 바꿀지 변호사와 정한다. 서비스명을 바꾸면 d1 §3·로고 자산·도메인 표기가 함께 바뀐다.
- 결과가 나오기 전에는 POL-027의 `추정` 표기를 유지하고, "등록 가능"이라고 쓰지 않는다.
