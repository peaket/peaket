### SEC-06 — fail-open 패턴은 남아 있으나 전체 조립에서는 시작이 막힌다

- `services/core-svc/src/modules/catalog/inbound/internal-sale-config.controller.ts:49` — `if (!this.expected) return true;`
- 같은 파일 `:51` — `!==` 비교(상수 시간 아님). 플랫폼 공용 가드는 `timingSafeEqual`을 쓴다(`packages/platform/src/auth.ts:91-96`).

- `packages/platform/src/service.ts:178` — `internalTokenRequired = env !== 'local' && env !== 'ci'`.

- 배포 이미지는 `packages/platform/template/Dockerfile`과 `services/bundle/Dockerfile`이 `ENV NODE_ENV=production`을 걸므로, **이미지 안에서는 `NODE_ENV` 절반이 막아 준다**. 그러나 `PEAKET_ENV` 절반은 죽은 검사이고, 이미지 밖 prod 실행이나 `NODE_ENV`가 없는 실행에서는 fake가 켜진다.
- `services/core-svc/src/modules/notify/notify.module.ts:32`는 `process.env`를 직접 넘긴다. 새 시험은 `NotificationSender`를 직접 만들어 모듈 배선을 보지 않는다. `createService({env})`에 다른 env 객체를 넘기는 경로에서는 가드가 그 env를 보지 않는다.

## 9. 권고(우선순위)

1. **SEC-07부터 고친다.** `assertNotifyFakeAllowed`/`assertCompensationFakeAllowed`가 `'prod'`와 미설정(prod 기본)을 보게 하고, 시험을 `PEAKET_ENV:'prod'`·미설정으로 바꾼다. 모듈/`start({env})` 배선 시험을 더한다. `notify.module.ts`의 `process.env` 직접 사용도 env 주입으로 바꾼다.
2. **A2-17 실제 원천을 고친다.** `DrizzleAttendeeReader`가 필터링 뒤에도 `limit`건을 보장하도록 주문 서브쿼리/집계로 바꾸고, `HttpAttendeeSource`가 `nextCursor`를 전달하게 한다. core는 `nextCursor`가 있으면 짧은 페이지에서도 계속 읽는다. 짧은 페이지·필터링·HTTP nextCursor 시험을 더한다. 가능하면 스트리밍 CSV로 간다.
3. **A2-19를 한 트랜잭션으로 묶고 조회 감사를 넣는다.** `insert`+`audit`을 같은 `db.transaction`에서 수행하고, audit 실패 시 export 행도 롤백되는 시험을 더한다. `listAttendees`의 접속기록(조회)을 남기고 시험한다.
4. **A2-03 HTTP 어댑터 시험을 보강한다.** 비어 있지 않은 `seats` 응답으로 `tier` 매핑을 확인하고, `x-peaket-internal-token` 헤더를 단언한다.
5. **OPS-08 정규식을 고친다.** create 규칙 전체를 다음 `- apiGroups`/문서 구분자까지 캡처하거나 YAML/helm 렌더 결과를 파싱한다. `verbs` 뒤 `resourceNames` 변이를 시험에 넣는다.
6. **차트 시험을 CI에 배선한다.** `node --test deploy/charts/peaket-service/test/*.test.mjs` 단계를 추가한다.
7. **TEST-06에 `act`·`exp`·`iss`·`sub` 부정 경로를 더한다.**
8. **과잉 결합을 줄인다.** 커서는 “호출된 커서/다음 호출 존재”로, 보존은 “2년 이상”으로 단언한다.

## 10. 결론

R-625의 시험은 “수정 전 실패”와 “주요 변이 9개 사망”을 만족해 회귀 시험으로서 실질적 가치가 있다. 그러나 SEC-07의 정본 값 불일치라는 거짓 통과가 있고, A2-17·A2-19의 핵심 잔여 결함과 A2-03 HTTP 어댑터·OPS-08 create 규칙의 시험 공백이 남아 있다. 따라서 **현 상태로 R-625를 완료로 닫을 수 없고, 위 1~3번을 고친 뒤 재검**해야 한다.
