# 웨이브 6 감사 범위와 커버리지

감사 대상은 `v0.2.0`(`6bcea3c7`, 2026-11-04)부터 `develop`(`fabbabac`, R-594, 2026-11-15)까지다. `BUILD_ORDER.md`의 배치 행과 `git log --first-parent`를 대조해 구현 배치를 빠짐없이 열거했고, 각 배치를 최소 하나의 독립 감사에 매핑했다. 구현에 참여하지 않은 에이전트만 감사·검증했으며, 영역 감사 7개(A1–C2), 관점 감사 4개(CONS·OPS·SEC·TEST), 변이 감사 5개(M1–M5), 커버리지 감사 2개(COV·COV2)를 수행했다.

## 5. 남은 공백

1. **BAT-052 realtime-gw**: 선행 서비스가 없어 보류. 감사 대상 구현이 없다.
2. **BAT-197 trust 표시·라벨 화면**: 미착수. COV2가 미착수로 정정했다.
3. **K7 공식 목표**: `BAT-033` 측정 창의 K7 공식 목표는 여전히 known gap이다. 감사는 코드·시험을 대상으로 했고 목표 수치를 재측정하지 않았다.
4. **운영 배포 형상**: trust-svc가 아직 `deploy/workloads`에 없어 COV2-01의 실제 노출 범위는 제한적이다. 배포 전 mTLS·L7 허용 목록이 필요하다.
5. **브라우저 확인**: 백엔드 감사는 API·시험으로 확인했고, 화면이 바뀌는 기능은 ADR-0256 묶음 절차의 브라우저 확인을 별도로 수행한다.
