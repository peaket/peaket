# BAT-445 확인 목록: 스캐너 관리형 태블릿 배치·휴대폰 배치·실기 점검

- **무엇**: GAT-200(스캐너 관리형 태블릿 배치, SCR-053 휴대폰 배치, 태블릿 실기 점검)의 확인 목록이다. 기기 실기 확인은 소유자 몫이라 여기서는 절차와 통과 기준만 만든다.
- **정본**: [docs/features/offline-gate.md](../../features/offline-gate.md) §6.1·§6.2·§9, [docs/frontend.md](../../frontend.md) §3.8·§5.5, [docs/design/d5-screen-blueprint.md](../../design/d5-screen-blueprint.md) SCR-053.
- **자동 시험**: `apps/scanner/test/scan-queue.test.ts`(GAT-150), `apps/console-host`의 SCR-053 보드(휴대폰 배치). 실기 항목은 이 문서의 체크로 남긴다.

## 1. 관리형 태블릿 배치(운영)

| 항목 | 절차 | 통과 기준 |
| --- | --- | --- |
| 기기 등록 | 운영자가 SCR-053에서 기기를 만들고 파트너에 배정한 뒤 1회용 등록 코드를 발급한다 | 등록 코드가 10분 [가정] 안에 한 번만 쓰이고, 기기 키가 `ACTIVE`가 된다 |
| 관리 앱 | Android Enterprise(또는 같은 관리 도구)로 스캐너 PWA를 키오스크/전용 앱으로 배치한다 | 홈·주소창 없이 `scanner.peaket.example`만 열리고, 다른 앱으로 나가지 않는다 |
| 카메라 | 관리 정책으로 카메라 권한을 미리 허용한다 | 첫 실행에서 권한 대화상자가 뜨지 않고 뷰파인더가 바로 뜬다 |
| 화면 | 화면 꺼짐 방지(Wake Lock)와 고정 밝기를 켠다 | 10분 이상 조작이 없어도 화면이 꺼지지 않는다 |
| PWA | 서비스 워커가 셸·목록을 미리 받는다 | 비행기 모드에서 앱을 다시 열어도 셸과 마지막 목록이 뜬다 |
| 시계 | 근무 준비에서 서버 시각과 단말 시계를 견준다 | 오차가 기준 안이면 준비 완료, 넘으면 스캔을 시작하지 않는다 |
| 기기 배치 | 파트너(SCR-037)나 현장 책임자(SCR-052)가 구역·입장/퇴장 모드를 정한다 | 배치가 없으면 스캔 화면으로 넘어가지 않는다. 퇴장 모드는 재입장 허용 회차에만 된다 |

## 2. SCR-053 휴대폰 배치(화면)

- 휴대폰 보드는 **조회와 즉시 폐기만** 한다. 기기 등록, 이름·배정 변경, 다시 등록, 퇴역 처리는 태블릿·데스크톱에서 한다.
- 확인할 것:
  - 상단 안내 띠에 "기기 등록은 태블릿이나 데스크톱에서 합니다 / 휴대폰에서는 볼 수만 있습니다"가 보인다.
  - 기기 목록은 카드로 보이고, 상태·파트너·마지막 연락·등록일이 읽힌다.
  - 분실·도난 기기는 휴대폰에서도 '즉시 폐기하기'로 폐기 확인 대화상자를 열어 세션을 끝낼 수 있다. 보기 전용 역할은 `useRo`가 버튼을 막고, 실제 권한 집행은 서버(`operator`·`commander`)가 맡는다.
  - 빈 화면 상태에서 기기 추가를 권하지 않고, 큰 화면에서 등록하라는 안내를 보인다.
  - 휴대폰 보드에는 구역·모드 같은 기기 배치를 바꾸는 조작이 없다.
- 자동 시험: `apps/console-host`의 보드 시험은 SCR-053-m의 문구와 상태 목록, 즉시 폐기 문구, 배치 조작 부재를 확인한다(O-T27·O-T31).

## 3. 태블릿 실기 점검(소유자 몫)

| # | 점검 | 통과 기준 |
| --- | --- | --- |
| 1 | 카메라 초점·노출 | 밝은 조명·역광·기울인 QR에서 1초 안에 디코딩된다 |
| 2 | 화면 회전 | 세로·가로를 바꿔도 뷰파인더와 판정 패널이 겹치지 않는다 |
| 3 | 전원 차단 | 통과 화면이 뜬 직후 전원을 뽑아도 그 스캔 기록이 다시 열었을 때 큐에 남아 있다 |
| 4 | 네트워크 끊김 | 비행기 모드에서 판정·큐 적재가 계속되고, 온라인 복귀 뒤 묶음 업로드가 끝난다 |
| 5 | 기기 폐기 | SCR-053에서 폐기하면 다음 요청부터 403이고 스태프 세션도 끝난다 |
| 6 | 배치 없음 | 배치를 지우면 스캔 화면이 막히고 책임자에게 요청하는 안내가 뜬다 |
| 7 | 앱 판 | 낮은 판이면 근무 준비에서 막고, 새 판을 적용하는 절차를 안내한다 |

- 결과는 이 표 아래에 날짜·기기·앱 판·담당을 적는다. 실기 결과가 없으면 '미실행(소유자)'으로 둔다.
- 실기에서 찾은 결함은 재현 시험을 먼저 만들고 이 문서에 적는다.
