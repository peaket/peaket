## 1. 범위와 선행 확인

**선행 확인**: 처리방침·약관의 화면 틀(SCR-057, `apps/web/src/entities/policy-doc/model.ts`)은 이미 있었지만 본문 대부분이 `placeholder`였다. `docs/security/data-classification.md`에 처리방침 초안·국외 이전 목록·수탁자 목록·법률 확인 30~37번이, `docs/security/internal-management-plan.md`에 사람 칸과 접속기록 점검 절차가 있었다. 선행이 막혀 있지 않아 BAT-590을 그대로 진행했다.

**한 것**:
1. **처리방침 10절**(LCH-180): 목적·항목·보유 기간, 파기, 처리 위탁(수탁자 목록), 정보주체 권리, 자동화된 결정, 쿠키 목록, 개인정보 보호책임자, 국외 이전, 가명정보, 부정 예매 조사.
2. **이용약관 10조**(LCH-185): 정렬 방식, 1인 1순번, 매수 한도, 취소·환불(공제표), 양도, 금지행위, 통신판매중개자 고지, 분쟁 해결, 부정 예매 취소·이용 제한(사유·사전 통지·소명·전액 환급·양도 잠금 14일·이의 30일).
3. **분쟁·판매 조건·게시물 운영정책**: 분쟁 해결 기준, 판매 조건 공통, 게시물 노출 제한·신고·권리 침해 삭제·이의.
4. **법률 검토 목록**: `docs/review/legal/BAT-590-legal-review.md`에 POL-027 확인 필요와 법률 확인 30~37번을 제출 전 상태로 정리했다.
5. **내부 관리계획 연결**: §8 사람 칸·대표자 승인은 운영 전 지정으로 남기고, 문서 상태에 이 묶음의 확인 목록을 가리켰다.

**막힌 몫(후속·소유자)**:
- **내부 관리계획 §8 사람 칸·대표자 승인·시행일**: 실제 이름·직책·연락처와 승인은 소유자 몫이다.
- **사업자 정보**: 대표자·사업자등록번호·통신판매업 신고번호·주소·고객센터는 등록 뒤 채운다.
- **변호사 검토 제출**: 법률 검토 목록의 30~37번과 남은 확인 필요 항목은 소유자가 제출한다.
- **본인확인기관·알림 발송 대행·Sentry 도입**: 수탁자 목록의 미정 값을 계약·판정 때 채운다.
