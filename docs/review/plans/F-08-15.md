# 기능 계획: F-08-15(보내기 비교·Sentry 판정·M4 블로그 2편 — 보내지 않고 판정하는 법)

- **진행**: 계획·시험(이번 턴) 끝, **리뷰 대기**(2026-11-28). 실제 전송·외부 계정 생성·측정은 **미실행**이고 모든 판정은 `미측정` 또는 `판정 못 함`이다. 이번 세션은 Docker·kind·k6·브라우저를 쓰지 않았다.
- **무엇**: BUILD_ORDER '기능 단위 계획' F-08-15(갈래 4, 등급 B, OPS-520·OPS-530, WBS 2.50일, 측정 창 3)의 작업 목록이다. 검토 기록이고 규범이 아니다. 정본과 다르면 정본이 이긴다.
- **쉬운 말**: 관측 도구를 바꿀지 정하려면 ① 후보에 자료를 **보내 봐야만** 아는 것(장기 조회, 이상 탐지 힌트)이 있다. 이 기능은 그 보내기를 **예산·비용·지연·운영 부담**으로 계산해 비교하는 계약을 만든다. ② 오류 수집 도구를 **Sentry 클라우드·Sentry 직접 설치·GlitchTip 직접 설치** 가운데 무엇으로 할지 정하는 기준(무료 등급 API 범위, 오류 피크, 가림)을 세운다. ③ M4 기술 블로그 **2편의 목차**를 만든다. **실제로 보내지 않고, 계정을 만들지 않고, 통과를 만들어 내지 않는다.**
- **바탕**: 작업 폴더 `D:/ticketpass-freeze-F-08-15`, 가지 `freeze/lane4-F-08-15`, 출발 `origin/freeze/lane4-F-08-13` = `19f4fc40b`(F-08-13 리뷰 반영 포함). 동결 트랙이라 `develop`·`release/1.0.0`·`main`에 합치지 않는다(ADR-0386 결정 4).
- **차례**: B등급이지만 이번 동결 트랙 지시로 **계획 → 시험(정적·계산 계약·블로그 목차) → 리뷰(새 세션) → 반영 → 구현/문서 → 기록**으로 돈다. 이번 세션은 계획·시험·기준 트리 실패 확인까지만 하고 **리뷰 준비**에서 멈춘다.
- **한 줄 결론**: 보내기 비교는 **`미측정`**, Sentry vs GlitchTip은 **`판정 못 함`**, M4 2편은 **목차 초안**이다. 외부 계정이 없어 R1(콘솔 갱신/조회 한도)과 오류 피크를 잴 수 없고, 무료 등급·GlitchTip API 범위도 계정 없이 확인할 수 없다. 그래서 기본값은 **지금 구성(직접 운영) 유지**이고, 이것을 `통과`로 적지 않는다. F-08-5 `무효·미측정`, F-08-9 `판정 못 함(무효·부분)`, F-08-10 `미측정`, F-08-12 `미측정`, F-08-13 `설계만·판정 못 함`, F-08-14 `미측정`은 인용만 한다. `30k/s`·`30,000건/초`·`100만`·K1/K2/K7 0의 새 수치를 주장하지 않는다.

## 2. 감독에게(정할 것과 이 계획의 답)

1. **범위는 OPS-520(보내기 비교·Sentry 판정)과 OPS-530(M4 2편 목차)이다.** OPS-500·OPS-510(K8·K9 측정, 관측 백엔드 비교 계산)은 F-08-14 몫이라 넣지 않는다. **2026-11-28 감독 확인.**
2. **창은 3g 하나로 하고 3g-1~3g-3으로 나눈다.** 3g-1 보내기 비교(1.5시간), 3g-2 Sentry vs GlitchTip(1.5시간), 3g-3 M4 목차·보고(1시간)다. 합계 **4시간 = 0.5일**이고, 다른 역할 2.0일(계획 0.5·시험 0.5·리뷰 0.25·구현 0.5·기록 0.25)과 합계 **2.50일(20시간)**이다. 35시간 상한은 쓰지 않는다. **2026-11-28 감독 확인.**
3. **보내지 않는다.** 외부 계정(Datadog 체험·AMP·AMG·Sentry·GlitchTip)을 만들지 않고, 실제 전송·조회·비용 청구를 하지 않는다. 보내기 비교는 **문서 인용·계산 계약**으로만 한다(2026-10-31 소유자 결정). **2026-11-28 감독 확인.**
4. **Sentry·GlitchTip을 설치하지 않는다.** PC에 GlitchTip·Sentry를 띄우지 않고, `PEAKET_SENTRY_DSN`을 채우지 않는다. 무료 등급 API 범위와 GlitchTip API 지원은 **계정 없이 확인할 수 없으므로** `미확인`·`판정 못 함`이다. **2026-11-28 감독 확인.**
5. **비용은 `[추정]`·`미계산`으로만 적는다.** AMP 가격표로 계산한 값은 `[추정]`이고, Datadog·직접 설치·GlitchTip의 연간 비용은 입력(서버 수·지표 수·로그·추적 양·운영 시간)이 없어 `미계산`이다. 계산한 값도 실측이 아니다. **2026-11-28 감독 확인.**
6. **M4는 목차·초안 뼈대만 만든다.** 2편은 `docs/blog/` 아래 `m4-control-gameday.md`·`m4-scaling-cost.md`이고 `status:'draft'`, `publish:'owner'`다. 게시하지 않는다. **2026-11-28 감독 확인.**
7. **F-08-14 의존은 §10에 따로 둔다.** 입력 계약(활성 시계열·초당 샘플·로그 GB/일·요청 기록 GB/일·서버 수·화면 사용자 수·K9 결과·연간 비용)을 한 객체로 모으고, F-08-14 최종본이 생기면 §10만 rebase한다. **2026-11-28 감독 확인.**
8. **장부는 0항목이다.** BUILD_ORDER F-08-15 행의 장부 범위가 `-`('장부 없음: 시험·측정으로 본다')이고, `node tools/ci/ledger.mjs --batch F-08-15 --require`는 '검사할 항목 없음'으로 통과한다. `docs/review/ledger-notes.md`를 고치지 않는다. **2026-11-28 감독 확인.**
9. **경계를 지킨다.** F-08-14(K8·K9·관측 백엔드 비교 계산), F-08-6(33종 전체·`gameday.mjs`·SLO/KPI ADR), F-08-13(모의 진행·복원 연습), F-08-12(14종 실행), F-08-10(V-T18·M2), F-08-9(V-T27·V-T28·P-T1·SR-T13·NFR-028), F-08-8(K1·K2·K7), F-08-5(NFR-027·V-T10), F-08-2(100만 외삽)을 침범하지 않는다. **2026-11-28 감독 확인.**

### 3.3 수용 기준·완료의 정의·실패 시나리오

**완료의 정의(동결 로컬 트랙의 자체 완료)** — 아래를 모두 만족할 때 이 기능을 끝낸다. v1 출시 완료와는 별개다.

1. 계획·시험·리뷰·반영·구현·문서·기록 커밋이 이 가지에 있다.
2. 보내기 비교가 **보내는 방식·샘플 예산·비용 계산식·지연·운영 부담·판정 규칙 R1~R3**를 담고, 실제 전송이 `미실행`이며 판정이 `미측정` 또는 `판정 못 함`이다. AMP 계산값은 `[추정]`, Datadog·직접 설치·GlitchTip 비용은 `미계산`이다.
3. Sentry vs GlitchTip이 **후보 셋·판정 기준 ①~⑤·무료 등급과 API 범위·오류 피크·2차 마스킹**을 담고, 판정이 `판정 못 함`이다. `PEAKET_SENTRY_DSN`은 비어 있고 SDK는 꺼져 있다.
4. M4 2편이 `docs/blog/`에 있고, 각각 무엇을 설명하나·설계·측정 근거·한계·게시 전 확인 절과 `status:'draft'`·`publish:'owner'`를 갖는다. 근거는 F-08-14 `미측정`·F-08-13 `설계만·판정 못 함`이고, 게시하지 않았다.
5. 보고서가 §1~§7, 선행 인용 6개(F-08-5·F-08-9·F-08-10·F-08-12·F-08-13·F-08-14), 한계, 장부·게이트, 주장하지 않는 것을 담는다.

- **범위**: 없음(`-`). 장부가 뽑는 항목은 **0개**다(2026-11-28 확인: `항목 0개, 묶음 등급 B`). `node tools/ci/ledger.mjs --batch F-08-15 --require`는 '검사할 항목 없음'으로 통과한다.

- **F-08-14(주 입력)**: K8·K9 결과, 관측 백엔드 비교 계산의 로컬 수치(활성 시계열 수·초당 수집 샘플·로그 GB/일·요청 기록 GB/일·서버 수·화면 사용자 수), `backend_cost.csv`·manifest의 R2 순위. **없으면 `미측정`·`미계산`**이다.
- **F-08-13(참고)**: 모의 진행·복원 연습 결과. M4 ①의 한계 절에 `설계만·판정 못 함`으로 인용한다.
- **F-08-6(경계)**: Game Day 33종 전체·K8 종합 판정. M4 ①은 10종·K8 개념만 설명하고 33종을 다시 판정하지 않는다.
- 의존의 상세 계약과 rebase 절차는 §10에 따로 둔다.

### 6.3 보내기 비교(OPS-520 ①)

**무엇을 보내야만 알 수 있나** — 정본은 둘만 보낸다고 정했다.

1. **Datadog Watchdog·이상 탐지 힌트 비교**(14일 체험): 같은 시간대에 우리 규칙과 Datadog이 각각 무엇을 먼저 표시하는지. 사람을 부르지 않는다.
2. **AMP·AMG의 장기 조회 동작**: 쿼리 기간 95일, `QueryMetrics` 초당 300건. 콘솔 갱신(5초 [가정])을 Datadog 조회 한도 안에서 맞출 수 있는지(R1)도 여기서 본다.

**보내는 방식(계약)**

| 후보 | 보내는 길 | 보낼 것 | 이 기능에서 |
| --- | --- | --- | --- |
| AMP | Prometheus `remote_write` + `write_relabel_configs` | `agg5m` 대상 일부와 서비스 하나의 SLI 히스토그램 [가정] | 보내지 않는다. 예산·비용만 계산한다 |
| AMG | AMP 데이터 소스를 Grafana에서 조회 | 보내지 않고 조회만 | 보내지 않는다. 장기 조회는 `미측정` |
| Datadog | OTel Collector `datadogexporter` | 같은 자료의 평가용 사본 | 보내지 않는다. 체험·계정 없음 |
| 직접 운영(현재) | 클러스터 Prometheus·Mimir·Loki·Tempo | — | 기본값. 비용 입력이 없어 `미계산` |

**샘플 예산식(정본 `docs/perf-ledger.md` §11.4)**

```text
보낼 샘플 = 고른 시계열 수 × (86,400 ÷ 긁기 간격(초)) × 보낼 날수
```

- `86,400`은 하루의 초 수다. 긁기 간격은 5초(`slo-fast`)·15초(그 밖) 가운데 고른다.
- 합이 **40,000,000**(AMP 무료 등급) 이하이면 그대로 보낼 수 있다. 넘으면 `write_relabel_configs`로 시계열을 골라 줄이지 않고는 보내지 않는다.
- 예(정본): 2,000개를 15초마다 3일 보내면 2,000 × 5,760 × 3 = **34,560,000**이다. `[추정]`.
- 활성 시계열 100,000개 [가정]를 15초마다 그대로 보내면 두 시간이 안 돼 무료 등급을 넘고, 하루면 약 48달러다. 그래서 줄인다(정본).

**비용식(정본 `docs/perf-ledger.md` §11.3, 조회 날짜 2026-10-14)**

```text
수집 월 요금 = max(0, 월 샘플 − 40,000,000) ÷ 10,000,000 × 0.90달러
저장 월 요금 = max(0, 저장 GB − 10) × 0.03달러
조회 월 요금 = max(0, 월 조회 샘플 − 200,000,000,000) ÷ 1,000,000,000 × 0.10달러
연 요금 = (수집 + 저장 + 조회) × 12
```

- 표시는 **`[추정]`**이다. 실측이 아니다. 가격표의 1천만 샘플당 단가를 샘플 수에 비례해 환산하고 올림하지 않는다(추천 적용, 2026-11-28).
- 20억 샘플을 넘는 구간(1천만 샘플당 0.35달러)은 이 기능에서 계산하지 않는다. 그 입력이 오면 `미계산`으로 남기고 F-08-14에 넘긴다.
- Datadog 연간 비용은 서버·APM·지표·로그 입력이 필요해 **`미계산`**이다. 직접 설치·GlitchTip도 서버 단가·운영 시간이 없어 **`미계산`**이다.
- 운영 부담은 `docs/perf-ledger/ops-hours.csv`의 설치·판 올림·용량·장애·점검 시간으로만 적는다. 새 줄을 만들지 않고, 표본이 없으면 `미계산`이다.

**지연(계약)**

- **보내기 지연**: Prometheus `remote_write`는 긁기와 분리된 큐로 보내므로 긁기 응답을 기다리게 하지 않는다는 것이 설계다. 실제 큐 적체·재시도·유실은 **`미측정`**이다.
- **조회 지연**: 장기 조회(95일) 응답 시간은 보내야만 알 수 있다. **`미측정`**이다.
- **콘솔 갱신(R1)**: 5초 [가정] 갱신을 Datadog 조회 한도 안에서 맞출 수 있는지는 체험 계정이 필요하다. **`미측정`**이다.

**판정 규칙(정본 ADR-0067 결정 5, 측정 전에 고정)**

- **R1**: 콘솔 갱신을 Datadog 조회 한도 안에서 맞출 수 없으면 창고는 직접 운영한다. Datadog을 쓰더라도 엔지니어 분석용으로만 쓴다.
- **R2**: 직접 운영의 연간 총비용(관측 노드 풀·저장소·전송 비용 + 운영 시간 × 시간 단가)이 Datadog 연간 추정 비용보다 크면, Datadog 전환을 새 ADR로 검토한다.
- **R3**: Datadog으로 보내는 데이터에 개인정보(가명정보 포함)가 남으면 개인정보 보호법 §28의8 요건을 먼저 갖춘다. 갖출 수 없으면 전환하지 않는다.
- **10% 유지 규칙**: 비용 차이가 10% [가정] 안이면 지금 구성을 유지한다(ADR-0068 결정 5). 1.5배 운영 시간에서도 1위여야 직접 운영을 고른다(정본 §11.5).
- **이 기능의 판정**: R1·R2·R3 가운데 하나라도 증거가 없으면 **`판정 못 함`**이고, 기본값은 **지금 구성(직접 운영) 유지**다. 이것을 `통과`로 적지 않는다. 계정·전송이 없으므로 이번 창의 판정은 `미측정`(시도하지 않음)·`판정 못 함`(문서 대조만)이다.

### 6.4 Sentry vs GlitchTip(OPS-520 ②)

**후보 셋(정본 `docs/observability.md` §11)**

| 후보 | 정본 사실 | 이 기능에서 |
| --- | --- | --- |
| Sentry 클라우드 | 오류 자료가 미국·EU에 보관된다. 콘솔 요약 연결은 Team 이상이다. 무료 Developer는 사용자 1명·월 오류 5천 건·화면 녹화 50개·이메일 알림 | 계정을 만들지 않는다. 무료 등급 API 범위는 `미확인` |
| Sentry 직접 설치 | 단일 서버 Docker Compose(메모리 16GB + 스왑 16GB 이상), 규모 확장 안내 없음 | 설치하지 않는다. 비용·가용성은 `미계산`·`판정 못 함` |
| GlitchTip 직접 설치 | Sentry 클라이언트 SDK를 그대로 받는다. PostgreSQL 14 이상과 서비스 하나, 웹·작업자를 나눠 늘릴 수 있다. 권장 메모리 512MB, Valkey 7 이상 선택, Helm 차트, MIT | 설치하지 않는다. 두 질의 API 지원은 `미확인` |

**판정 기준(정본 §11.4)**

1. **국외 이전 요건**(ADR-0067 R3): 클라우드면 §28의8 요건과 처리방침 고지가 필요하다. 직접 설치면 국내 보관이다.
2. **온세일 오류 피크(클라이언트 표본 뒤)를 받는가**: 피크를 재지 않았으면 `미측정`이고, 어떤 후보도 ②를 통과했다고 적을 수 없다.
3. **가용성**: 단일 서버라 온세일 중 멈출 수 있는가, 멈추면 무엇을 잃는가. 오류 사건은 3등급이라 받는 곳이 멈추는 것은 허용한다. 그동안 사건과 콘솔 '새 오류 종류' 요약을 잃고, 처리량 급감 경보(RB-33)는 Prometheus에서 오므로 남는다. SDK는 보내지 못한 사건을 버리고 앱을 기다리게 하지 않는다. 수집 0이 5분 [가정] 넘으면 SEV3다.
4. **콘솔 요약 API**(배포 뒤 새 오류 종류 수, 많이 난 오류 상위 5개): Sentry 클라우드 무료 등급은 API·외부 연동이 Team 기능이라 **무료에서는 미확인**이고, GlitchTip이 두 질의를 지원하는지도 **미확인**이다. ops-svc가 Sentry 호환 웹 API를 1분 [가정]마다 pull한다(ADR-0356 결정 6).
5. **연간 총비용**: 클라우드는 Team 이상 요금과 오류 피크 추가 이벤트 요금, 직접 설치·GlitchTip은 서버 비용과 운영 시간을 넣는다. 입력이 없으면 `미계산`이다.

- **고르는 법**: ①~②와 ④를 통과한 안 가운데 ⑤가 가장 낮은 안을 고른다. 비용 차이가 10% [가정] 안이면 ③이 나은 안(멈추는 한 점이 없는 안)을 고른다.
- **이 기능의 판정**: ②·④가 `미측정`·`미확인`이므로 **`판정 못 함`**이다. 기본값은 **계정 없음·DSN 빔·SDK 꺼짐**(현재 상태)이다.

**가림 계약(정본 `docs/observability.md` §11, ADR-0356 결정 4)**

- **1차 가림**: 사용자 IP 수집 끔(`dataCollection.userInfo:false`), 요청 본문 끔(`httpBodies: []`), 쿠키·헤더·쿼리 문자열 거름, 화면 녹화·성능 추적 끔.
- **2차 마스킹**: `beforeSend`가 로그와 같은 `redactDeep`을 쓰고, 정규식 원천은 `packages/platform/src/pii-patterns.json` 하나다. 이 기능은 원천을 옮겨 적거나 새 정규식을 만들지 않는다.
- **사용자 식별값**: `accountRef` 가명만 보낸다. 원문 계정·이메일·전화·카드·계좌는 보내지 않는다.
- **받는 곳**: 환경 변수 `PEAKET_SENTRY_DSN`이 비면 끈다. `local`·`ci` 밖에서는 `https://`만 받는다. 조직·DSN은 관측 백엔드 판정 뒤 소유자 몫이다.

### 6.6 기록·증거·판정

- **기록 폴더**: `.cache/peaket-f0815/<날짜>-<회>/`에 `send-budget.json`(샘플·비용 계산 입력과 결과, `[추정]` 표시), `sentry-criteria.json`(후보별 ①~⑤와 `미확인`·`미측정` 사유), `manifest.json`(창·입력·의존·판정·외부 전송 없음)을 남긴다. 실제 전송이 없으므로 `faults.ndjson`·`generator.json`·`host.json`은 만들지 않는다.
- **장부 폴더**: 실제 측정이 없으므로 `docs/perf-ledger/runs/`에 넣지 않는다. 보고서의 `실측(PC)` 줄은 만들지 않는다.
- **판정값**: `통과`·`미달`·`판정 못 함`·`무효`·`미측정`. 보내지 않음·계정 없음·피크 없음은 `미측정`, 문서 대조만 함은 `판정 못 함`, 허위 전송·비용 실측 주장은 `무효`다. `통과`는 실제 전송·실행 산출물·R1~R3 증거·오류 피크·API 확인·비용 입력·소유자 승인이 모두 있을 때만이다. 이 기능은 그 조건을 채우지 않는다.
- **비용 표시**: 계산값은 `[추정]`, 입력이 없으면 `미계산`, 문서 가격은 `문서 인용`(조회 날짜). `실측`·`청구서`로 쓰지 않는다.
- **개인정보**: 보고서·초안·계산 입력에 개인 식별자·연락처·사설 IP를 쓰지 않는다. `containsPii`가 전화번호·이메일·사설 IP를 거부한다.
- **금지 수치**: `30k/s`·`30,000건/초`·`100만`·`K1`·`K2`·`K7`을 주장하지 않는다. 선행 인용은 F-08-5 `무효·미측정`, F-08-9 `판정 못 함(무효·부분)`, F-08-10 `미측정`, F-08-12 `미측정`, F-08-13 `설계만·판정 못 함`, F-08-14 `미측정`뿐이다.

### 6.7 중단 규칙

**STOP-01~10** — 하나라도 걸리면 창을 멈추고 감독에게 알린다. 수치를 만들지 않는다.

1. **STOP-01** 외부 계정을 만들거나 자료를 보내려 한다(Datadog·AMP·AMG·Sentry·GlitchTip).
2. **STOP-02** `PEAKET_SENTRY_DSN`을 채우거나 Sentry SDK를 켜려 한다.
3. **STOP-03** 보내지 않았는데 전송·실행 ID를 적는다.
4. **STOP-04** 계산값을 실측·청구서로 적는다.
5. **STOP-05** 오류 피크·API 범위를 확인 없이 통과로 적는다.
6. **STOP-06** 2차 마스킹 원천을 옮겨 적거나 새 정규식을 만든다.
