## 2. 정한 값(ADR-0264 결정 43~45)

- 템플릿 정적 JSON이 정본이고 DB TEMPLATE 행은 사본이다. `templateId`는 파일에 고정한 UUID, 개략도는 파트너 정적 파일 `<img>`.
- 목표 좌석 수는 구역 `defaultCapacity` 비율, 내림 뒤 소수부 큰 구역부터 1석. 구역 수보다 작으면 422.
- 이미 좌석이 있으면 `replace: true` 없이는 409 `seatmap-replace-required`(`existingSeatCount`). 다른 테넌트 404, 승인 이력 실무자 403, 잠김 409는 저장 경로와 같다.
- 경고는 저장을 막지 않고 가져오기·저장·화면이 같은 함수를 쓴다.
