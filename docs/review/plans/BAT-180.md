## 1. 범위와 선행 확인

**선행 확인**: `LogoWordmark`와 `kit.css`의 `.logo-mark`가 이미 있다(d1 §3). 그래서 워드마크를 새로 만들지 않고, 같은 도형의 **원본 SVG·파비콘·PWA 아이콘·설치 파일**을 채웠다. KIPRIS는 공개 대화형 검색과 Open API 키가 필요해 이 묶음에서 결과를 지어내지 않고 절차·검색어·미실행 상태를 기록했다. 엣지 함수는 AWS 계정이 없어 문서 비교와 로컬 경로 함수 시험으로 했고, 셔플 100만·Turnstile 지연은 이 PC의 작은 PoC로 쟀다.

**한 것**:
1. **브랜드 자산**(BAS-200): `packages/ds/src/assets/brand/`의 심벌 원본·반전·앱 아이콘·마스커블 SVG, 소비자 웹 `app/icon.svg`·`icon.png`·`apple-icon.png`, `public/icons/` 192·512·마스커블 PNG, `manifest.webmanifest`, 스캐너 `public/` 아이콘·manifest. `RootDocument`에 manifest·appleWebApp·themeColor를 넣었다.
2. **KIPRIS 검색 기록**(BAS-200): `docs/review/trademark/BAS-200-kipris.md`에 검색어(PEAKET·피켓·PEAKET 피켓·PICKET·심벌), 류(09·35·41·42), 절차, 결과 표를 만들었다. 현재 상태는 **미실행(사람 확인)**이다.
3. **엣지 함수 문서 비교**(BAS-100): CloudFront Functions와 Lambda@Edge를 실행 위치·런타임·암호·KVS·시간·원본 트리거·로그·비용으로 비교하고, 시청자 요청·HMAC-SHA256이면 CloudFront Functions(런타임 2.0)로 충분하다고 적었다.
4. **셔플 100만**(BAS-100): `tools/poc/shuffle-1m/shuffle.mjs`가 Fisher–Yates·4,096 묶음·직렬화를 재고, 결과를 `docs/review/poc/BAS-100.md`에 적었다.
5. **Turnstile 검증 지연**(BAS-100): `tools/poc/turnstile-latency/siteverify.mjs`가 공개 시험 키로 siteverify를 재고, 결과를 같은 문서에 적었다.

**막힌 몫(후속·다른 단계로 적음)**:
- **실제 AWS 함수 배포·무료 범위 시험**: AWS 계정이 생기는 HOT-012·BAT-185.
- **KIPRIS 대화형 검색**: 소유자 또는 대리인이 KIPRIS에 로그인해 결과 PDF를 남긴다. 결과 전에는 POL-027 `추정`을 유지한다.
- **Q-T57 로비 사람 확인 부하**: 실제 사이트 키·로비 개방 몰림·검증 p99는 구간 측정 몫이다.
- **셔플 운영 파이프라인**: drand·Redis 파이프라인·S3 4,096객체 게시·CDN 전파·5초 예산은 Q-T6·queue-admission §2 몫이다.
