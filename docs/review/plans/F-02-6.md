# 기능 계획: F-02-6(명령 4 WAF 전송, 명령 6 진입·상태 조회 Degraded·S3 사본 고정·매진 정적 응답, RB-03·RB-04)

- **진행**: 계획·시험(정적·포트 계약)·기준 트리 실패 확인 끝, **리뷰 준비**(2026-11-28). 리뷰는 새 세션이 맡고, 리뷰 반영 뒤 구현·문서·기록으로 간다. 구현은 아직 시작하지 않았다.
- **무엇**: BUILD_ORDER '기능 단위 계획' F-02-6(갈래 4, 등급 B, OPS-310, WBS 2.50일, 단계 줄 `OPS-310 wbs 4.4.2 ②`의 나머지)의 작업 목록이다. 검토 기록이고 규범이 아니다. 정본과 다르면 정본이 이긴다.
- **쉬운 말**: 관제 운영자가 명령 4(ASN·IP 대역 차단)를 내면 엣지의 웹 방화벽(WAF)에 그 대역이 실제로 걸려야 한다. 또 명령 6(Degraded Mode 전환)으로 대기열 진입을 도착 시각 쿠키 방식으로 바꾸고(엣지 `mode:entry`), 대기 상태 파일의 폴링을 두 배로 늦추며(`stateDegraded`), 대기 상태 파일을 S3 사본으로 고정하고, 매진 정적 응답으로 바꿀 수 있어야 한다. 이번 동결 로컬 범위는 **바깥 AWS를 부르지 않고 포트와 가짜로 그 동작을 확인하는 데까지**다. 실제 CloudFront·WAF·S3·작은 함수 호출은 `미실행`이고 `[가정]`이다.
- **바탕**: 작업 폴더 `D:/ticketpass-freeze-F-02-6`, 가지 `freeze/lane2-F-02-6`, 출발 `origin/develop` = `75771324e`(2026-11-24). F-02-1·F-02-2는 이 기준에 이미 합쳐져 있다(`f021-control-dispatch.test.ts`, `f022-pg-switch-command.test.ts`, `ControlDispatcher`, `PgSwitchPlanner`).
- **동결 로컬 범위**: ADR-0386 결정 4·5. `develop`·`release/1.0.0`·`main`에 합치거나 체리픽하지 않는다. 출시 마이그레이션 목록·출시 환경 값(`deploy/envs/{demo,staging,prod}`)·출시 플래그에 넣지 않는다. 이 가지에서만 포트·가짜·정적 시험·런북 글을 만든다. 실제 AWS API 호출, CloudFront 배포 변경, WAF 규칙 반영, S3 사본 고정의 실제 전파 시간은 이번 턴 `미실행`·`[가정]`이다.
- **차례(동결 지시 2026-11-28)**: B등급이지만 이 동결 트랙은 **계획 → 시험(정적·포트 계약) → 리뷰(새 세션) → 반영 → 구현/문서 → 기록**으로 한다. 이번 턴은 계획·시험을 끝내고 기준 트리 실패를 확인한 뒤 리뷰 준비에서 멈춘다. 리뷰 담당은 계획·시험을 맡지 않은 새 세션이다.
- **수치 주장 금지**: 이 계획과 시험은 정본의 처리량·동시 인원 수치와 K1·K2·K7의 0을 주장하지 않는다. 인용할 수 있는 것은 F-08-5 `무효·미측정`, F-08-9 `판정 못 함(무효·부분)`, F-08-10 `미측정`뿐이다. 정본에 있는 처리량·인원 수치는 이 기능의 완료 근거가 아니다.
- **한 줄 결론**: 지금 명령 4는 `target-not-wired`로 실패하고, 명령 6의 진입·상태 조회·CDN 갈래는 매개변수 검사도 집행도 없다. 이 기능은 그 자리에 (a) WAF 포트와 가짜, (b) 엣지 `mode:entry` 쓰기 포트, (c) queue-svc `stateDegraded` 쓰기, (d) CloudFront 설정 포트와 가짜를 놓고, 감사 기록(C-T12)과 S3 사본 고정·매진 정적 응답(C-T44 ⑥)을 시험으로 고정한다. 새 마이그레이션은 쓰지 않는다.

## 2. 감독에게

올린 것에 대한 답은 아직 없다. 아래는 이 계획이 정한 추천안이며, 다르게 정하면 계획·시험을 고친다.

1. **명령 6의 새 모드 이름과 매개변수(추천 적용, 2026-11-28)** — `DEGRADED_MODE`의 `params.mode`에 넷을 더한다. `ENTRY_DEGRADED`(진입 Degraded, `{mode, expiresAt}`), `STATE_DEGRADED`(상태 조회 Degraded, `{mode, scope: EVENT|PLATFORM, eventIds?}`), `STATE_MIRROR_FIXED`(S3 사본 고정, `{mode}`), `SOLD_OUT_STATIC`(매진 정적 응답, `{mode}`). 켜는 것은 명령 6(2인 승인·재인증)이고, 끄는 것은 기존 `POST /v1/ops/commands/{id}/reversions`(commander 1인·재인증)다. `ENTRY_DEGRADED`만 `expiresAt`이 필수이고(엣지 키 `mode:entry`의 `expireAtMs`), 나머지는 해제 명령 전까지 유지한다.
2. **WAF ASN 차단의 자리(추천 적용, 2026-11-28)** — CIDR은 기존 `WafIpSets`(IPv4·IPv6 IP 집합)에 더하고, ASN은 IP 집합에 담을 수 없으므로 **쓰기 전용 작은 함수**(ADR-0234와 같은 결)가 미리 만든 WAF 규칙의 `ASNMatchStatement` 목록을 바꾸는 포트로 둔다. ops-svc 역할은 그 함수를 부를 권한만 갖고 웹 ACL 규칙을 직접 바꾸지 않는다(C-T58의 권한 범위를 넓히지 않는다). 실제 함수·IAM은 `[가정]`·`미실행`이고 구간 5에서 만든다. ASN 만료는 그 함수가 아니라 **ops-svc 정비 바퀴**가 만료된 명령의 ASN을 빼고, IP 집합과 ASN 목록이 모두 비었을 때 `AUTO_EXPIRED`로 적는다. 기존 `waf-block-expirer`는 IP 집합만 맡는다. 포트 `WafBlocks` 하나가 CIDR과 ASN을 함께 받고, 가짜는 명령 ID별 소유를 기억해 다른 살아 있는 명령이 막는 항목을 남긴다. 실제 어댑터는 `waf_block_expiry_v`와 명령 행으로 그 소유를 확인한다.
3. **`CONTROL_KIND_ENTRY_DEGRADED`(4)를 이 기능이 쓰지 않는 것(추천 적용, 2026-11-28)** — 진입 Degraded의 집행 지점은 엣지 저장소 키 `mode:entry`이고, admission-ctrl은 그 값으로 번호 규칙을 바꾸지 않는다(도착 시각 칸은 queue-svc 진입 Lua가 쿠키로 처리한다). 그래서 이 기능은 종류 4를 소비하지 않는다. 상태 조회 Degraded는 `CONTROL_KIND_STATE_DEGRADED = 10`을 새로 두어 queue-svc가 `stateDegraded`를 쓰게 한다. 종류 4의 계약 주석이 'admission-ctrl'이라고 적은 것은 초안의 어긋남으로 보고, 구현 때 주석 정리 후보로 남긴다(정리 목록).
4. **바깥 AWS는 포트·가짜까지** — CloudFront 설정 포트(`CdnEdgeSettings`), 엣지 저장소 쓰기 포트(`EntryModeStore`), WAF 포트(`WafBlocks`)의 실제 어댑터는 만들지 않거나 `미실행` 골격만 둔다. 시험은 메모리 가짜로 한다. 실제 CloudFront 배포·원본 그룹·S3 사본 고정의 동작은 F-09-4(동결)·구간 5의 몫이다.
5. **C-T44 ⑥의 범위** — 이 기능의 시험은 (a) 가짜 CloudFront 설정이 정본의 원본 그룹 값(장애 조치 코드 500·502·503·504, 연결 시간 초과 2초, 시도 1회)을 갖는지, (b) 명령 6의 S3 사본 고정이 해제 명령 전까지 유지되는지, (c) 매진 정적 응답 켜고 끄기를 본다. 실제 CloudFront 설정 검사(Terraform·배포)는 F-09-4 `미실행`이다.
6. **마이그레이션 0** — 새 표·칸이 필요 없다. 명령 4는 기존 `ops_command.expires_at`, 명령 6은 `params` JSON, queue-svc notice는 기존 Redis hash, CDN·엣지 저장소는 외부 저장소다. 마이그레이션이 꼭 필요해지면 로컬에만 두고 출시 목록에 넣지 않는다(ADR-0386 결정 5).
7. **수치 주장 없음** — 이 기능의 완료는 포트·가짜의 동작과 정적 계약으로 판정한다. 처리량·인원·K1/K2/K7 수치는 인용하지 않고, F-08-5·F-08-9·F-08-10의 상태만 인용한다.

## 3. 범위

### 3.1 하는 것

- **명령 4 WAF 전송(포트·가짜)**: `BLOCK_ASN_IP` 실행에서 CIDR을 IPv4·IPv6 IP 집합에 더하고, ASN을 쓰기 전용 함수 포트로 더한다. 성공하면 `ACKED`, 실패하면 `FAILED`(`waf-unavailable`). `ops_command.expires_at`은 접수 때 이미 적는다(ADR-0349 결정 10). 되돌리기(T13)는 그 명령의 CIDR·ASN 가운데 다른 살아 있는 명령 4가 막지 않는 것만 뺀다. ASN 만료는 정비 바퀴가 빼고, IP 집합·ASN 목록이 모두 비면 `AUTO_EXPIRED`(SYSTEM)다.
- **명령 6 진입 Degraded(엣지 `mode:entry`)**: `ENTRY_DEGRADED` 모드가 엣지 저장소 쓰기 포트로 `{"on": true, "expireAtMs": <밀리초>}`를 쓴다. 되돌리기는 `{"on": false, "expireAtMs": <지금>}`을 쓴다. `expiresAt`은 지금보다 늦고 지금 + 24시간 이하[가정]이며, 만료가 지나면 엣지 함수가 그 기능만 건너뛴다. 감사 기록에 모드·켜짐/꺼짐이 남는다.
- **명령 6 상태 조회 Degraded(`stateDegraded`)**: `STATE_DEGRADED` 모드가 제어 gRPC `CONTROL_KIND_STATE_DEGRADED`로 queue-svc에 가고, queue-svc가 `q:{event:E}:notice` 또는 `q:{event:PLATFORM}:notice`의 `stateDegraded`를 `1`/`0`으로 쓴다. 판 번호가 지금 칸보다 클 때만 쓰고, 같은 판·낮은 판은 쓰지 않는다. 대기 상태 파일은 회차·전체 범위 중 하나라도 `1`이면 그 구간 주기의 2배를 `pollHintMs`로 싣는다(기존 Q-T66 읽는 쪽).
- **명령 6 S3 사본 고정·매진 정적 응답(CloudFront 설정 포트)**: `STATE_MIRROR_FIXED`는 queue-files 배포의 원본을 S3 사본(원본 그룹의 보조 원본)으로 고정하고, `SOLD_OUT_STATIC`은 queue 배포의 진입 경로를 매진 정적 응답으로 바꾼다. 각각의 되돌리기는 원본 그룹/원본으로 되돌린다. 가짜 CloudFront 설정은 정본의 원본 그룹 값(500·502·503·504, 연결 시간 초과 2초, 시도 1회)을 처음부터 갖고, 고정은 해제 명령 전까지 유지된다.
- **감사 기록(C-T12)**: 수동 명령 6의 접수·실행·되돌리기 감사 기록에 `mode`와 `transition`(`ON`/`OFF`)을 싣고, 자동 조치(`AUTO_ACTION`)로 켠 진입 Degraded도 `COMMAND_AUTO_ACTION` 감사 기록과 `DISPATCHED` 사건에 `mode`·`transition`을 싣는다. 자동 트리거(진입 p99·Redis CPU) 자체는 이 기능 밖이고, 감사 경로만 만든다.
- **RB-03·RB-04 런북**: `docs/runbooks/`에 RB-03(진입 Degraded 자동 전환 확인과 명령 6 해제)과 RB-04(대기 상태 파일 S3 사본 고정과 해제)를 만들고 `docs/infra.md` §10 색인에서 잇는다. RB-03은 `mode:entry`·`stateDegraded`·`ENTRY_DEGRADED`·`STATE_DEGRADED`를, RB-04는 `STATE_MIRROR_FIXED`·원본 그룹 값·해제 절차를 가리킨다. 매진 정적 응답은 RB-14와의 관계를 한 줄 적는다.

## 5. 장부 범위

`node tools/ci/ledger.mjs --batch F-02-6`(기준): **항목 2개, C-T12 빈칸, C-T44 ⑥ ID만**, 등급 B 2. 이 기능이 둘 다 자동 시험으로 채운다.

| 항목 | 지금 | 채우는 시험 |
| --- | --- | --- |
| C-T12 | 빈칸 | 수동 명령 6 네 모드의 감사 기록 + `AUTO_ACTION` 진입 Degraded의 감사 기록 |

## 8. 공개 인터페이스(시험 담당이 이 모양으로 시험을 먼저 쓴다)

- **명령 6 모드 이름**: `ENTRY_DEGRADED`, `STATE_DEGRADED`, `STATE_MIRROR_FIXED`, `SOLD_OUT_STATIC`.
- **params**:
  - `ENTRY_DEGRADED`: `{ mode: 'ENTRY_DEGRADED', expiresAt: string }`. `expiresAt`은 ISO-8601, 지금보다 늦고 지금 + 24시간 이하[가정]. 모르는 칸은 422 `invalid-command`, 범위 밖은 422 `command-out-of-range`(detail `degradedExpiresAt`).
  - `STATE_DEGRADED`: `{ mode: 'STATE_DEGRADED', scope: 'EVENT'|'PLATFORM', eventIds?: string[] }`. `EVENT`면 소문자 UUID 1~100개(겹침 없음), `PLATFORM`이면 `eventIds`를 받지 않는다.
  - `STATE_MIRROR_FIXED`·`SOLD_OUT_STATIC`: `{ mode }`만. 모르는 칸은 422.
- **제어 종류**: `CONTROL_KIND_STATE_DEGRADED = 10`. `controlKindOf('DEGRADED_MODE', {mode:'STATE_DEGRADED',...})` → `'CONTROL_KIND_STATE_DEGRADED'`, `controlScopesOf` → `['PLATFORM']` 또는 회차 목록, `controlDeliveriesOf(..., 'APPLY')` → `[{service:'queue-svc', scope, kind, desiredStateJson:'{"stateDegraded":true}'}]`, `'REVERT'` → `{"stateDegraded":false}`.
- **queue-svc notice**: `QUEUE_NOTICE_FIELDS['CONTROL_KIND_STATE_DEGRADED'] = { value:'stateDegraded', rev:'stateDegradedRev', cmd:'stateDegradedCmd' }`. `noticeValueOf('CONTROL_KIND_STATE_DEGRADED', '{"on":true}')` → `{value:'1'}`, `{"on":false}` → `{value:'0'}`. 모르는 칸·틀린 꼴은 `undefined`(받는 층 INVALID_ARGUMENT, 쓰기 0).
- **포트**:
  - `WafBlocks`: `apply(commandId, {cidrs, asns, expiresAtMs}): Promise<void>`, `release(commandId): Promise<void>`, `remaining(commandId): Promise<{cidrs, asns}>`. `release`는 그 명령이 소유한 항목 가운데 다른 살아 있는 명령이 막지 않는 것만 뺀다(가짜는 명령 ID별 소유를 기억한다).
  - `EntryModeStore`: `write({on, expireAtMs}): Promise<void>`, `read(): Promise<{on, expireAtMs} | undefined>`.
  - `CdnEdgeSettings`: `read(): Promise<CdnEdgeState>`, `apply({stateMirrorFixed?: boolean; soldOutStatic?: boolean}): Promise<CdnEdgeState>`. `CdnEdgeState = { queueFilesOrigin: 'ORIGIN_GROUP'|'S3_FALLBACK'; queueEntryResponse: 'ORIGIN'|'SOLD_OUT_STATIC'; originGroup: { failoverCodes: readonly number[]; connectionTimeoutMs: number; attempts: number } }`.
- **모듈 공개 면**: `CommandsModuleExtras.edge?: { waf: WafBlocks; entryMode: EntryModeStore; cdn: CdnEdgeSettings }`, `EdgeCommandExecutor`(생성자 `{waf, entryMode, cdn, next?, nowMs?}` — `nowMs`는 되돌리기의 `on:false` 시각), `MemoryWafBlocks`·`MemoryEntryMode`·`MemoryCdnEdgeSettings`(시험 대역).
- **감사 payload**: `DEGRADED_MODE`의 감사 기록에 `mode`, `transition`(`ON`/`OFF`), `scope`(있으면)를 더한다. `AUTO_ACTION`의 `DEGRADED_MODE`도 같다.

## 12. 완료의 정의

1. 명령 4의 CIDR·ASN 차단이 WAF 포트·가짜로 `ACKED`가 되고, 실패는 `FAILED`이며, 손으로 풀기와 ASN 만료가 다른 명령의 차단을 풀지 않는다.
2. `ENTRY_DEGRADED`가 `mode:entry`에 `{"on":true,"expireAtMs":...}`를 쓰고, 되돌리기가 `{"on":false,...}`를 쓴다. `expiresAt` 경계(없음·24시간 정각·24시간 + 1ms)가 422로 갈린다.
3. `STATE_DEGRADED`가 queue-svc notice의 `stateDegraded`를 `1`/`0`으로 쓰고, 대기 상태 파일의 `pollHintMs`가 2배/원래대로 돌아간다(기존 Q-T66 읽는 쪽 회귀).
4. `STATE_MIRROR_FIXED`·`SOLD_OUT_STATIC`이 CloudFront 설정 포트·가짜를 바꾸고, S3 고정은 해제 명령 전까지 유지되며, 두 스위치는 독립이다.
5. C-T12: 수동 네 모드와 자동 진입 Degraded의 감사 기록에 `mode`·`transition`이 남는다.
6. C-T44 ⑥: 가짜 CloudFront의 원본 그룹이 500·502·503·504·연결 2초·시도 1회이고, S3 고정 유지·매진 정적 켜고 끄기가 시험으로 고정된다.
7. RB-03·RB-04가 실제 절차(확인·켜기·끄기·감사 확인)를 담고 `docs/infra.md` §10에서 이어진다.
8. `node tools/ci/ledger.mjs --batch F-02-6 --require`가 빈칸·ID만 0으로 통과한다. 실제 AWS·Docker·kind·k6·브라우저는 쓰지 않았고, 그 사실이 `## 검증`에 적혀 있다.

## 15. 자주 놓친 결함

- **판 번호 비교**: queue-svc notice는 판이 지금 칸보다 클 때만 쓴다. 같은 판·낮은 판에 `stateDegraded`를 덮지 않는지.
- **두 스위치 독립**: S3 고정과 매진 정적 응답은 서로 다른 배포·다른 원본이다. 하나를 되돌릴 때 다른 하나를 건드리지 않는지.
- **다른 명령이 막는 대역**: 손으로 풀기·ASN 만료가 다른 `ACKED` 명령 4의 차단을 풀지 않는지. `liveBlockKeys`와 같은 규칙.
- **거짓 성공**: WAF·엣지 저장소·CloudFront 포트가 실패했는데 `ACKED`가 되지 않는지. 실패는 `FAILED`이고 다시 하기가 같은 값을 다시 보낸다.
- **감사 누락**: 수동 네 모드와 자동 진입 Degraded 모두 `mode`·`transition`이 남는지. 자동은 행위자 SYSTEM, 가명 참조 없음.
- **엣지 JSON 꼴**: `mode:entry`는 `{"on": boolean, "expireAtMs": number}`이고, `on:false`여도 `expireAtMs`가 있는지(엣지 함수가 읽는 꼴).
- **notice 칸 이름**: `stateDegraded`, `stateDegradedRev`, `stateDegradedCmd`가 기존 `paused`·`banner` 칸과 겹치지 않는지.
- **문서 링크**: RB-03·RB-04가 `docs/infra.md` §10에서 이어지고, doc-check의 링크 검사를 통과하는지.
- **수치**: 시험·계획에 처리량·인원 수치를 새로 쓰지 않았는지.
