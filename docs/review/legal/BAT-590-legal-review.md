# BAT-590 법률 검토 목록(LCH-180·LCH-185)

- **무엇**: 개인정보 처리방침·이용약관·내부 관리계획을 게시하기 전에 변호사에게 제출할 쟁점 목록이다(POL-027, wbs 7.4.1, ADR-0139·0171·0173).
- **누가**: 변호사 검토 제출은 소유자 몫이다. 이 문서는 제출 목록과 현재 표시(확인됨·해석·확인 필요·간주·추정)를 정리한 검토 기록이고, 법률 자문이 아니다.
- **정본**: POL-027의 표시 규칙, `docs/security/data-classification.md`의 처리방침 초안·국외 이전 목록·법률 확인 30~37번, `docs/security/internal-management-plan.md`의 사람 칸, `docs/planning/03-policies-glossary.md`의 POL-046이 정본이다.

## 3. 게시 전에 갖출 것

1. 처리방침의 국외 이전 절에 AWS 계약 당사자 법인명·연락처, Sentry 도입 판정, 본인확인기관·알림 발송 대행 업체를 채운다.
2. 내부 관리계획 §8의 사람 칸(개인정보 보호책임자, 점검자, 조사관, 승인자)과 대표자 승인·시행일을 채운다.
3. 약관의 사업자 정보(대표자·사업자등록번호·통신판매업 신고번호·주소·고객센터)를 채운다.
4. 변호사 검토 결과를 이 문서에 붙이고, 결론이 뒤집히면 ADR로 설계를 바꾼다.
5. 부정 예매 조사 갈래는 처리방침을 게시하기 전에는 운영에서 켜지 않는다(docs/features/forensic-replay.md §6.1).
