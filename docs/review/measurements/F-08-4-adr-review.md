# F-08-4 ADR 재검토(미측정 뼈대)

- **상태**: 판단 보류. 측정 창 4를 아직 열지 않았다. 이 파일은 구현 단계의 뼈대이고, 측정 담당이 근거와 결론만 더한다.
- **정본**: `docs/adr/0012-queue-ordering-hybrid-shuffle-default.md`, `docs/adr/0118-queue-ordering-two-settings-lobby-shuffle-open-batch.md`, `docs/features/queue-admission.md` Q-T1·Q-T23. 계획은 `docs/review/plans/F-08-4.md` §7이다.

## ADR-0012

- 현재 상태 줄은 `채택` 그대로다. 결정 1의 이름 셋(FIFO·PREQUEUE_SHUFFLE·HYBRID)은 ADR-0118 결정 3·5가 두 설정(로비 셔플·오픈 직후 묶음)으로 바꿨다.
- 이 기능은 ADR-0012 결정 1을 되살리거나 상태를 바꾸지 않는다. '3개 정렬 모드의 동시 유지보수·벤치마크'는 ADR-0118이 설정별 켬·끔 비교로 바꿨다고만 적는다.

## ADR-0118

- 현재 상태 줄은 `채택` 그대로다. 두 설정·세 운영 조합·둘 다 끈 조합을 받지 않는 규칙은 그대로다.
- 되돌릴 조건 판단은 아직 없다. Q-T23의 `prequeue`(묶음 끔) 속도형 봇 성공률이 `hybrid`(묶음 켬)보다 10%p 이상 높으면 `openBatch` 고정 검토 후보이고, Q-T1의 T=0 최고 RPS 비율이 0.5를 넘으면 로비 셔플 재검토 후보다. 둘 다 측정 전이라 판단하지 않는다.
- 파트너 선택 분포(묶음 끔을 거의 고르지 않음)는 이 트랙에 data가 없다. `자료 없음`으로 둔다.

## 결론

- **결론**: 판단 보류(현행 유지). ADR-0012·ADR-0118 상태를 바꾸지 않는다.
- **ADR 변경**: 없음. `adrChanges: []`.
- **다음**: 측정 창 4에서 Q-T1·Q-T23을 잰 뒤, 봇 성공률 차이·T=0 RPS 비율·파트너 선택 자료를 보고 다시 본다. 바꿀 근거가 나오면 새 ADR 초안과 소유자 결정을 먼저 둔다.
