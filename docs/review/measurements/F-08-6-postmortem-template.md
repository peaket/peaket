# F-08-6 포스트모템 양식

- **쓰는 때**: POL-022 기준으로 선언한 인시던트가 끝난 뒤 48시간 안에 쓴다. 비난 없는 포스트모템이며 사람 이름·실수 대신 시스템·절차·관측의 실패를 적는다.
- **주 원인 유형**: 정본 9가지 가운데 하나만 고른다. 변경, 외부 의존, 내부 저장소·메시징, 용량·포화, 코드 결함, 데이터, 보안, 운영 조작, 기반. 어디에도 들지 않으면 `기타`와 사유를 쓴다.
- **P0**: 사고 하나가 28일 예산의 20%를 넘게 썼으면 P0 후속 조치를 하나 이상 둔다. 20% 정각은 넘은 쪽이 아니다.
- **후속 조치**: GitHub Issues 링크(`#123` 또는 URL)를 붙인다.
