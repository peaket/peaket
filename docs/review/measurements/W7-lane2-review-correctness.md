## 대조해서 맞았던 것(지적 아님)

- **원천 함수와 메모리 `documentOf`(BAT-165)**: 판매 상태 경계(`open_at <= at`, `starts_at − 24시간 > at`)와 메모리 `saleOf`(`now < openAt`이면 오픈 예정, `now >= 판매 종료`면 끝남)가 같다. 대표 회차의 네 무리(판매 중은 공연 시작 = 판매 종료 차례, 오픈 예정은 오픈 차례, 공연한 회차는 가장 늦은 시작, 그 밖은 가장 이른 시작, 같으면 ID)도 `representativeEvent`와 같다(매진 ③은 DB에 사본이 없어 빠짐, 계획 §10). 다음 오픈·판매 종료·기간의 KST 날짜도 같다.
- **1분 정리 창(BAT-165)**: `(since, at]`에 오픈, `starts_at − 24시간`, `starts_at`이 든 회차를 고르는 식이 원천의 세 경계와 정확히 맞는다(경계 시각 자체가 창 끝에 포함된다).
- **후보 검색의 빠짐 없음(BAT-165)**: `matchGrade`의 정확·앞부분·낱말·초성·중간 일치는 모두 '낱자에 입력 낱자가 든다' 또는 '초성에 입력 초성이 든다'를 뜻하므로, `LIKE '%…%'` 후보 집합이 등급이 있는 공연을 빠뜨리지 않는다. 사전의 이분 탐색·두 글자 조각 후보도 같은 이유로 `matchGrade`가 맞다고 할 줄을 빠뜨리지 않는다(중간 일치는 띄어쓰기 없앤 값의 음절 포함이라 첫 두 음절 조각이 반드시 있다).
- **사전 증분의 지운 표시 차례(BAT-165)**: 한 스냅숏의 줄은 지금 남은 줄이라 지운 표시를 모두 먼저 반영하고 줄을 넣으면, 판 여럿을 건너 '지움 → 다시 넣음'과 '넣음 → 지움' 모두 마지막 상태가 남는다. `search_version`을 `UPDATE`로 잡아 커밋 차례가 판 차례와 같으므로 판 사이에 빠짐이 없다.
- **가리기와 0건 목록(BAT-165)**: 전화 정규식은 0으로 시작하는 9~11자리(사이 하이픈·점·공백 하나씩)이고 앞뒤 숫자를 막아 12자리는 `[숫자]`로 간다. 로그 칸은 가린 뒤 50자로 자른다(자르다 남은 숫자가 새지 않는다). `zeroResultQueries`의 4·5번 경계, 결과가 있는 줄 빼기, 상위 50개가 search.md:286과 같다.
- **품질 사건 모듈(BAT-165)**: 60초 묶음, 위치 1~8, 결과 클릭 버킷 1~3·4~10·11~20, 바로 다시 찾음(10초 미만·검색어 다름·누르지 않음)이 search.md:279~284·ADR-0271 결정 16과 같다.
- **공연 상세 예매 버튼 차례(BAT-040)**: `bookingCta`의 차례(판매 종료·취소 > 상태 파일 ENDED > 매진 > 개인 상태 받는 중 > 로그인 > 예매 제한 > 가입 > 본인확인 > 판매 자격 없음 > 시각 상태)와 버튼 이름·오픈 알림 토글 유무가 ADR-0272 결정 2·3과 같다. `tierBadge`의 받기 전 뼈대·실패 '판매 중'·SOLD_OUT 전체 매진·`soldOutTiers` 등급 매진도 결정 1과 같다.
- **판정 시각·명단 밖 창·선예매 안내 글(BAT-040)**: `eligibilityJudgeAt`·`deniedWindow`·`deniedReason`·`presaleNotice`가 결정 3·4의 문장(조각 `startsAt ≤ 시각 < endsAt`, 첫 `GENERAL`의 시작, 가장 늦은 `destroyAt`, 명단이 없으면 괄호째 뺌)과 같다. 상태 파일 가게의 '보낸 시각부터 30초(경계 포함)'·세대 번호로 늦은 답 버리기도 결정 1과 같다.
- **월렛 워커 규칙·열 주소(BAT-170)**: 페이지 이동 캐시 두 꼴(끝 `/` 포함), `/v1/`·`/serwist/` 네트워크만, `no-store` 거르기(지시어 단위·대소문자 무시), `SKIP_WAITING` 메시지 판정, 토스트 조건(대기 워커·잠금 비어 있음·보류 화면 아님·Web Locks 없으면 안 띄움)이 frontend.md:1149 ①~⑤와 같다(⑤의 '쥔 목록'에 막 쥐려는 요청을 더 넣은 것은 더 조심스러운 쪽이라 지적하지 않았다). 열 주소 두 꼴과 그 밖 '/'는 d5:2300과 같다.
