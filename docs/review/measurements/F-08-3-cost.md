## 4. 1~3년 전망

## 6. 한계

- **추정치 한계**: 본 문서의 모든 금액은 AWS 공식 단가 목록(2026-10-28 기준, `docs/infra.md` §11)에 기반한 **[추정]** 또는 **문서 인용**이며, 실제 AWS 청구액이나 Cost Explorer·OpenCost 실측이 아니다.
- **누락 단가**: CloudFront 요청·전송, Origin Shield 요청, NLB 교차 AZ 전송, S3, gp3 볼륨, Aurora 저장·I/O·Global DB 전송, 약정 할인(Savings Plans·예약 인스턴스)은 §11 기본 비용표에 단가가 없어 `단가 없음: 미계산`이다(`INFRA11-NO-UNIT-PRICE`).
- **동결에 따른 미측정**: F-08-4(정렬 설정 비교), F-08-5(장시간 시험), F-08-6(Game Day), F-08-9(장애 주입), F-08-10(서비스 분리)이 동결되어 피크 시 실제 파드·노드 대수와 클라우드 환산 계수가 없다.
- **정본 미변경**: 이 보고서는 `docs/infra.md` §11을 고치지 않으며, 정본 개정은 동결 해제 뒤 측정과 함께 반영할 것을 제안한다.
- **주장하지 않는 것**: `30,000건/초`(`30,000 RPS`), 단일 공연 `100만` 달성·외삽 통과, `K1`·`K2`·`K7` 통과 또는 실제 청구 절감률을 주장하지 않는다.
