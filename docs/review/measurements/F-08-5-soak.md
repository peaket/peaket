# F-08-5 장시간 시험 보고서(미측정 뼈대)

- **상태**: **미측정**. 6시간 장시간 시험을 아직 돌리지 않았다. 이 파일은 구현 단계의 뼈대이고, 측정 담당이 실제 값으로 채운다.
- **정본**: `docs/verification.md` §3.6(장시간 시험)·V-T10(636행), `docs/architecture.md` §7 NFR-003·NFR-006·NFR-027, `docs/perf-ledger.md` §2.3·§7. 계획은 `docs/review/plans/F-08-5.md`다.
- **한 줄 결론**: NFR-027과 V-T10은 **미측정**이다. 30,000건/초·100만·K1/K2/K7의 새 수치를 주장하지 않는다.

## 3. 자원 지표

- GC 뒤 힙·RSS·열린 FD·활성 핸들·DB 연결 수·Redis 연결 수의 시작값·시간당 기울기·기준·판정은 측정 뒤 표로 채운다. 표시 없는 숫자를 쓰지 않는다.
- `limit_hit`이 1건 이상이면 유효 부하가 줄어든 구간이라 `부분(판정 못 함)`으로 적고, `judgeNFR027`의 `판정 못 함` 사유를 함께 쓴다.
- realtime-gw는 `ws_connections`·`ws_disconnects`·`ws_reconnects`를 함께 적는다. 2,500 연결·6시간 유지가 로컬에서 안 되면 `부분`·`미측정`이다.

## 4. NFR-027 판정

- 예열 30분을 뺀 뒤 자원 여섯의 시간당 1% 기울기, 재시작 0, p99 첫/마지막 30분 변화 10%, 오류 이항 상한을 함께 적는다.
