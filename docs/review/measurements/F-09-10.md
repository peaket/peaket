- 시험 커밋(`test(local,deploy): …`)에서 측정한 구현 전 기준:
  - `node --test tools/local/chart.test.mjs`: 시험 64, 통과 58, 실패 6, 건너뜀 0. 실패는 `CH-01`·`OPS-430 ①`·`②`·`③`·`⑧`·`⑨`이고, 옛 카나리 값(10/50/100·60/120초), ScaledObject의 min/max·fallback 부재, HPA+KEDA 동시 렌더, 트리거·단계 검증 부재가 까닭이다.
  - `node --test deploy/platform/test/platform-addons.test.mjs`: 시험 5, 통과 0, 실패 5, 건너뜀 0. 다섯 모두 `deploy/platform/{keda,argo-rollouts,karpenter}` 파일이 없다는 까닭이다.
- 구현 뒤 같은 시험의 통과 결과와 게이트 결과를 이 절에 채운다. 통과하지 않은 시험을 완료 근거로 세지 않는다.
- 리뷰 지적 반영(2026-11-27, RV0910-01~03·05~06): KEDA min/max 음성 사례, 정확한 차트 판(KEDA 2.21.1·Argo Rollouts 2.43.0), 트리거 필수 키 전수, Karpenter 노드 라벨, Application 필수 필드를 시험에 더했다. 시험 수는 차트 64·플랫폼 5 그대로이고 기준 실패도 6·5로 같다.
