# M2 ② 좌석 홀드와 변경 방송 — 초안 뼈대

- **상태**: 초안(2026-11-27, 게시 전). 마일스톤 M2, BUILD_ORDER HOT-510(F-08-10). 게시는 소유자 몫이다.
- **근거**: F-08-8(K2)의 측정 보고서·실행 ID. K4·K5는 F-08-8이 재지 않았으므로 설계·구현 근거로만 쓴다.
- **숫자 표시**: K2는 F-08-8의 `실측(PC)` 값을 인용할 자리만 둔다. K4·K5는 측정값으로 쓰지 않고 `미측정`으로 적는다.

## 1. 무엇을 설명하나

인기 좌석 하나에 여러 사람이 몰릴 때 홀드가 어떻게 한 명만 성공하는지, 좌석 상태가 바뀌면 화면에 어떤 변경분이 어떤 순서로 가는지 설명한다. 홀드 경합(K2), 변경분 연결(K4), 좌석맵 그리기(K5)를 한 글에서 다룬다.

## 2. 설계

- 홀드는 좌석 저장소의 원자 연산으로 한 명만 성공하게 한다.
- 변경분은 좌석 상태 변경을 묶어 연결된 화면에 보낸다. 연결 수와 묶음 크기의 상한은 정본 `docs/verification.md` §3.2·§3.9와 `docs/features/seat-hold.md`를 가리킨다.
- 좌석맵은 화면에서 그리는 비용이 크므로 그리기 방식과 입력 지연 목표를 따로 둔다.

## 3. 측정 근거

- K2: F-08-8의 인기 좌석 실행 ID와 결과를 인용한다. 값은 `docs/review/measurements/F-08-8-after.md`에서 확인한다.
- K4·K5: **측정값이 없다.** F-08-8은 K4·K5를 동결 선행으로 재지 않았다. 이 글에서는 설계·구현 근거로만 쓰고, 수치를 인용하지 않는다.
- 측정하지 않은 값은 `미측정`으로 적는다.

## 4. 한계

- K2의 결과를 K4·K5의 성능 근거로 일반화하지 않는다.
- 로컬 PC 한 대의 값이라 운영 규모를 직접 대신하지 않는다.
- 변경분 연결과 좌석맵 그리기는 별도 측정 캠페인이 필요하다.

## 5. 게시 전 확인

- [ ] K4·K5에 수치가 들어가지 않았는지 확인
- [ ] 소유자 게시 허락
