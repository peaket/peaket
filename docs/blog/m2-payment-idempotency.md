# M2 ③ 결제 멱등과 결과 모름 — 초안 뼈대

- **상태**: 초안(2026-11-27, 게시 전). 마일스톤 M2, BUILD_ORDER HOT-510(F-08-10). 게시는 소유자 몫이다.
- **근거**: F-08-8(K7)의 측정 보고서·실행 ID. 이 글은 새 측정을 하지 않는다.
- **숫자 표시**: F-08-8의 `실측(PC)` 값을 인용할 자리만 둔다. 확인 전 값은 `미측정`이다.

## 1. 무엇을 설명하나

결제 요청이 재전송되거나 결제사 응답을 잃어 결과를 모르는 상황에서, 같은 결제를 두 번 과금하지 않고 한 번만 확정하는 방법을 설명한다. 결제 확정 지연(K7)과 결과 모름 해소, 불변식 검사(이중 결제·승인 뒤 발권)를 함께 다룬다.

## 2. 설계

- 결제 시도마다 멱등 키를 두고, 같은 주문·같은 시도의 재전송을 한 번으로 모은다.
- 결제사 승인과 결과 조회를 나누고, 결과를 모르면 승인 여부를 다시 확인한다.
- 승인 뒤 발권은 되돌리지 않고 다시 시도한다. 환불은 회차 취소·CS 확인 뒤에만 한다.
- 이 절은 `docs/features/payment.md` §2·§13과 `docs/verification.md` §2.5·§3.10을 가리킨다. 정본 값을 옮겨 적지 않는다.

## 3. 측정 근거

- F-08-8 K7: 결제 확정 실행 ID와 결과를 인용한다. 값은 `docs/review/measurements/F-08-8-after.md`에서 확인한다.
- 불변식 검사 결과는 실행 폴더의 `invariants.csv`를 인용한다. SKIPPED 항목을 0으로 세지 않는다.
- F-08-9의 장애 주입·검색 결과는 이 글의 근거로 쓰지 않는다.
- 측정하지 않은 값은 `미측정`으로 적는다.

## 4. 한계

- 로컬 결제사 시뮬레이터를 쓴 값이라 실제 결제사와 같다고 주장하지 않는다.
- 이중 발권·일일 대사는 v1 합본 무대에 ticket-svc가 없어 `미측정`이다.
- 운영 규모의 확정 지연을 직접 대신하지 않는다.
