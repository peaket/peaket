# AsyncAPI 메시지 본문 깨짐 예외(oasdiff --err-ignore). 경로는 GET /messages/<메시지 이름>이다. 형식은 openapi-ignore.txt와 같다.
GET /messages/PaymentEvent the response property `eventId` became optional for the status `200`  # 이유: 굿즈·티켓 연동 부가 상품 결제는 회차가 없어 eventId를 null로 내고 orderKind(MERCH)를 싣는다(회차 정산서에 섞이지 않게). 소비자를 먼저 고쳤다: 하나뿐인 소비자 purchase-svc가 orderKind가 TICKET이 아닌 사건을 건너뛰고(payment_result_skipped_total{reason}) TICKET은 eventId가 없으면 모양이 틀린 사건으로 보류한다. purchase-svc 밖에는 trade.payments를 읽는 코드가 없다(invariant-checker·ops-svc 확인)(ADR-0299, BAT-600, 2026-11-18, 소유자 승인 2026-11-19)
GET /messages/SettingChanged added `subschema #8: LogSamplingValue` to the `value` response property `anyOf` list for the response status `200`  # 이유: 온세일 구간의 정상 로그 줄 표본 비율을 ops-svc 자동 조치로 보내려고 설정 변경 메시지 값 유니온에 LogSamplingValue 갈래를 더했다(BAT-215, ADR-0334 결정 1). 받는 쪽(platform 설정 읽기)을 같은 묶음에서 고쳤고, 운영 배포가 없어(클라우드 계정 없음, 2026-10-31 소유자 결정) 깨질 소비자가 없다. 소유자 승인 2026-11-23(breaking-approved)
GET /messages/SettingChanged added the new `LOG_SAMPLING` enum value to the `key` response property for the response status `200`  # 이유: 같은 변경의 설정 키 열거 추가다(BAT-215, ADR-0334 결정 1). 운영 배포가 없어(클라우드 계정 없음, 2026-10-31 소유자 결정) 깨질 소비자가 없다. 소유자 승인 2026-11-23(breaking-approved)
