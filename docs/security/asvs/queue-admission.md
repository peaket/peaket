# ASVS 추적 표: 대기열·입장 토큰과 구매 세션 소지 증명

- **대상 기능 범위**: 로비 참가 토큰, 사전 검증 토큰, 대기표, 입장 토큰, 도착 시각 쿠키(진입 Degraded Mode), 로비·묶음 셔플의 커밋과 drand 비콘, 구매 세션 소지 증명(서버 ECDH 키, 요청 인증 키, 일련번호), 입장 제어 리더의 대기열 Redis 쓰기(리더 세대 펜싱)와 입장 확정의 1인 1순번 재확인(ADR-0056), 로비 참가 취소·대기 취소 뒤 다른 기기에서 다시 참가(ADR-0060. 취소된 참가 토큰·대기표는 서명이 맞아도 거절하고, 호출자 pid의 참가만 취소하는 인가는 asvs/auth.md 8.2.2에서 판정)
- **보안 검증 기준**: OWASP ASVS 5.0.0, 목표 레벨 Level 2. 웹 프런트엔드(V3, 로비·대기 화면과 대기열 API·파일 배포, 도착 시각 쿠키), 자체 완결형 토큰(V9 전 절), 암호(V11 전 절), 통신(V12 전 절), 비밀 관리(V13.3), 클라이언트 측 데이터 보호(V14.3)의 L1·L2 항목을 전수 판정한다. Level 3은 선별 채택한 2개만 싣는다. 대기열의 자동화 방지와 업무 로직(V2)은 [봇 방어 추적 표](bot-defense.md), 로그인과 세션은 [계정·인증 추적 표](auth.md), 좌석 홀드의 이중 예약 방지는 좌석 추적 표(예정)에서 판정한다.
- **아키텍처 설계 근거**: [docs/features/queue-admission.md](../../features/queue-admission.md), [docs/features/seat-hold.md](../../features/seat-hold.md) §2, [ADR-0011](../../adr/0011-token-lifecycle-and-login-responsibilities.md), [ADR-0041](../../adr/0041-fifo-speed-bot-countermeasures.md), [ADR-0050](../../adr/0050-crypto-corrections-and-key-management.md), [ADR-0053](../../adr/0053-crypto-hardening-pseudonyms-webhooks-stores-runbook-audit.md), [ADR-0058](../../adr/0058-cdn-distributions-quotas-and-shuffle-fetch-spread.md), [docs/security/secrets-and-keys.md](../secrets-and-keys.md), [docs/infra.md](../../infra.md) §4.1, [docs/api/guidelines.md](../../api/guidelines.md) §9
- **문서 상태 및 일정**: 항목 선정 완료, 구현 직전 단계(2026-10-13 수립, ADR-0053). 요구사항 요약은 같은 장을 판정한 [현장 입장 추적 표](offline-gate.md)의 문장(OWASP ASVS `v5.0.0_release` 원문 대조, 2026-10-13)을 그대로 쓴다. Phase 2 대기열 작업 착수(wbs 2.2.1) 전에 재판정한다. 2026-10-20 3차 점검에서 '해당 없음' 값을 미적용과 사유로 통일하고, 대기열 진입 접속기록 보존 법률 행과 비콘 대기 상한·비상 셔플(RB-35)을 더했다(추천 적용 2026-10-20, ADR-0073). V3 절은 2026-10-15에 더했고 요약 문장은 OWASP ASVS 저장소 `v5.0.0` 태그의 V3 원문과 대조했으며 [공연 탐색·후기 추적 표](catalog-review.md)의 같은 요구 문장을 그대로 쓴다.

**작성 및 판독 가이드**

- **적용 여부**: 적용, 부분 적용, 미적용 중 하나로 적는다.
- **구현 위치**: 예정 위치를 적는다.
  - `queue-svc`: 참가 토큰·사전 검증 토큰·대기표 HMAC 발급·검증, 입장 토큰 ES256 발급, 셔플 시드 생성·봉인·커밋, 도착 시각 쿠키 검증, 입장 확정의 사람별 입장 키 확인
  - `admission-ctrl`: 셔플 실행(리더), drand 비콘 수신과 검증, 리더 세대 확인(펜싱) Lua
  - 엣지 함수: CloudFront Functions의 도착 시각 쿠키 서명
  - `gw-queue`·`gw-fan`: 액세스 토큰과 입장 토큰 서명 검증
  - `purchase-svc`: 입장 토큰 jti 결속, 서버 ECDH 키, 구매 세션 요청 인증 확인
  - `apps/web`: 대기실·좌석 화면(대기표·참가 토큰 보관, 구매 세션 요청 서명)
  - `CDN`: 대기열 API·대기열 파일 배포(CloudFront)의 공통 응답 헤더와 캐시 정책
- **테스트 결과**: 손으로 적지 않는다. CI 테스트의 `[ASVS v5.0.0-x.y.z]` 태그를 파싱한 리포트로 갱신한다.
- **미적용 사유 분류**: 해당 없음, Phase 이연, 위험 수용(ADR 작성 필수)으로 구분한다.
