# ASVS 추적 표: v0 베이스라인(모듈러 모놀리스)

- **독자와 용도**: v0 모놀리스(`services/v0-monolith`)를 구현하거나 검토하는 엔지니어와 보안 검토자가, ASVS 5.0.0 항목마다 적용 여부·구현 위치·시험 결과·미적용 사유를 확인할 때 참조한다. 구현 전에 이 표를 먼저 쓴다(docs/architecture.md §8.2).
- **대상 기능 범위**(wbs 1.1, 2026-11-02 작성):
  - **대기열 v0**(`queue` 모듈, wbs 1.1.1, BUILD_ORDER BSL-020): 진입, 대기 상태 조회(조회마다 `ZRANK`), 대기 취소, 1초마다 정한 수만큼 부르는 입장 루프, 입장 확정(docs/features/queue-admission.md §13).
  - **좌석 v0**(`inventory` 모듈과 v0 좌석맵 화면, wbs 1.1.2, BUILD_ORDER BSL-030): 좌석 목록, 행 잠금 홀드·해제·연장·만료, 변경분 WebSocket, 메인 스레드 Canvas 좌석맵 화면(docs/features/seat-hold.md §14). 같은 날 이 표에 좌석 행을 더했다.
  - 결제·발권 v0(wbs 1.1.3)는 그 단계에서 이 표에 행을 더한다.
  - v0는 K1~K10을 v1과 견주는 비교 기준선이다. 로컬·부하 시험에서만 돌고 운영에 배포하지 않는다(docs/architecture.md §9.3, ADR-0096). 사용자는 시험 계정뿐이고 실제 개인정보·결제를 다루지 않는다.
- **보안 검증 기준**: OWASP ASVS 5.0.0(웹 보안 기준을 만드는 비영리 단체가 낸 웹 앱 보안 검증 항목 목록), 목표 레벨 Level 2다. 대기열 v0에 걸리는 V1(주입), V2(업무 로직), V4(HTTP 응답), V8(권한), V13(설정·비밀), V14(데이터 보호), V16(로그)의 해당 행을 판정한다. 로그인·세션·토큰은 게이트웨이 몫이다(v0는 게이트웨이가 넘긴 신원 머리를 플랫폼 인증 가드로 읽는다, docs/features/identity.md §3). 화면(V3)과 WebSocket(V4.4)은 좌석 v0의 좌석맵 화면과 변경분 연결에 걸린다. 요구사항 요약은 다른 추적 표가 원문과 대조해 둔 같은 ID의 문장을 그대로 쓴다(ADR-0087 결정 30).
- **아키텍처 설계 근거**: [docs/features/queue-admission.md](../../features/queue-admission.md) §13, [docs/features/seat-hold.md](../../features/seat-hold.md) §14, [docs/architecture.md](../../architecture.md) §9.3, [ADR-0096](../../adr/0096-evidence-design-entry-capacity-split-comparison-v0-baseline.md), [ADR-0002](../../adr/0002-queue-sequence-incr-over-sorted-set.md), [docs/security/authz-matrix.md](../authz-matrix.md) §5.5.

**작성 및 판독 가이드**

- **구현 위치**: `queue`는 `services/v0-monolith/src/modules/queue`, `inventory`는 `services/v0-monolith/src/modules/inventory`(좌석맵 화면 파일 `public/` 포함), `platform`은 그 모놀리스가 쓰는 `@peaket/platform`의 공용 장치다.
- **테스트 결과**: 손으로 적지 않는다. 시험 이름의 `[ASVS v5.0.0-x.y.z]` 태그를 CI 리포트가 읽어 갱신한다(docs/architecture.md §8.2 4). 지금은 '미실행'이다.
- **미적용 사유 분류**: 해당 없음, 나중 Phase로 미룸, 위험 수용(ADR 필수).
