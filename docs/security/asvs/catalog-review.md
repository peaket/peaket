# ASVS 추적 표: 공연 탐색·관람 후기·홈 구성

- **대상 기능 범위**: 홈 피드(배너·오픈 예정·지금 판매 중·테마·공연장, 장르별 랭킹 파일)와 관제 콘솔 [홈 구성](배너·테마 저장, 배너 이미지 올리기, SCR-068), 공연 검색(페이지 번호)과 머리 검색창의 연관 검색어(SCR-003), 공연 상세(SCR-002)의 상세정보 섹션(파트너가 올린 공연 설명 글과 포스터·상세 이미지 표시, 파트너 공연 이미지 올리기 API 포함)과 안내 모달, 관람 후기(자격 확인·요약·목록·쓰기·고치기·지우기·통보 차단, SCR-016), 후기 사진(올리기, 확장자·매직 바이트·디코딩·악성 코드 검사, QR 코드·바코드 거르기, 다시 인코딩한 파생본 2종, 사진 설명), 후기 신고(사유 8종·자세한 내용·권리 침해 본인 요청과 결과 받을 곳·신고 확인 모달·횟수 제한, 신고기관 바로가기), 운영자 후기 조치(관제 콘솔 CS 처리함 SCR-045의 조치 없음·임시조치·노출 차단·해제, 신고자·글쓴이 통지, 후기 자리 공시), 좌석맵 템플릿 목록·상세 읽기와 [템플릿에서 만들기](SCR-022, V2·V8만), 찜한 공연·알림 신청 상태 조회, 본인확인 창 흐름(SCR-006)의 브라우저 출처 분리(창 메시지, 복귀 주소, 다른 호스트 이동). 후기 사진·신고·조치와 템플릿은 2026-10-19에 더했다(소유자 요청과 추천 적용, ADR-0066).
- **보안 검증 기준**: OWASP ASVS 5.0.0, 목표 레벨 Level 2. 인코딩·삽입 방지(V1), 검증과 업무 로직(V2), 웹 프런트엔드(V3), API와 웹 서비스(V4), 파일 처리(V5), 인가(V8), 데이터 보호(V14), 보안 로그와 오류 처리(V16)의 L1·L2 항목을 전수 판정한다. Level 3은 선별 채택한 7개만 싣는다. 로그인·세션·토큰과 본인확인 결과 저장은 [계정·인증 추적 표](auth.md), 좌석맵 가져오기 파일 처리와 좌석 델타 WebSocket은 이 표 범위 밖이다(좌석 기능 추적 표는 작성 예정, 00-summary §9). 좌석맵 배치본의 소유·테넌트 규칙과 [템플릿에서 만들기]는 이 표의 V2·V8에서 판정한다. 템플릿은 PEAKET이 만들어 배포 때 넣는 읽기 전용 자료라 새 추적 표를 만들지 않는다(ADR-0066). CS 처리함 자체(건 목록·기한·승인 업무)는 [양도·취소·환불 운영 추적 표](transfer-refund.md), 고객 문의는 [고객 문의 추적 표](support.md)를 따른다. 암호(V11)·보안 통신(V12)·설정(V13)·안전한 코딩(V15)은 이 기능이 새로 정하는 것이 없어 다른 추적 표(payment.md·settlement.md)와 같은 플랫폼 공통 설정을 따르고 여기서 다시 판정하지 않는다.
- **아키텍처 설계 근거**: [ADR-0063](../../adr/0063-screen-redesign-owner-feedback.md), [ADR-0066](../../adr/0066-screen-feedback-12-items.md)(후기 사진·신고·조치, 좌석맵 템플릿), [ADR-0062](../../adr/0062-open-items-delegated-decisions.md) 결정 38(공연 이미지 기준), [docs/api/openapi.yaml](../../api/openapi.yaml)(`catalog`·`reviews` 태그, `/v1/review-images`, `/v1/reviews/{reviewId}/reports`, `/v1/ops/reviews/{reviewId}/moderation`, `/v1/partner/seatmap-templates*`, `POST /v1/partner/events/{eventId}/seatmap`(템플릿에서 만들기), `/v1/ops/home-layout*`, `/v1/partner/events/{eventId}/images*`, `/v1/identity/verifications*`), [docs/api/guidelines.md](../../api/guidelines.md) §3·§9, [docs/data.md](../../data.md) §2(`review`, `review_image`, `content_report`, `takedown_action`, `venue` TEMPLATE, `home_banner`, `home_theme`), planning/03 POL-024·POL-042·POL-044, [docs/features/identity.md](../../features/identity.md) §5, [docs/features/control-tower.md](../../features/control-tower.md) §3 명령 9·10과 §10, [docs/features/analytics.md](../../features/analytics.md) §8.5, [docs/security/data-classification.md](../data-classification.md)
- **문서 상태 및 일정**: 항목 선정 완료, 구현 직전 단계(2026-10-14 수립, ADR-0063 반영). 요구사항 문구는 OWASP ASVS 저장소 `v5.0.0` 태그의 5.0/en 장 파일(V1·V2·V3·V4·V5·V8·V14·V16) 원문과 대조했다(2026-10-14). 법률 행의 조문은 국가법령정보센터 원문으로 확인했다(2026-10-14). 소비자 웹 핵심 화면(wbs 2.10.1)과 후기(wbs 7.3.1) 착수 전에 재판정한다. 2026-10-15 쿠키 이름 접두사 결정(추천 적용, docs/features/identity.md §3)으로 3.3.1을 적용으로 바꾸고 3.3.3의 근거를 고쳤다. 2026-10-19 후기 사진·후기 신고·운영자 후기 조치·[템플릿에서 만들기]를 더해 V1·V2·V3·V4·V5·V8·V14·V16과 법률 행을 다시 판정했다(ADR-0066). 판정 항목은 그대로이고 요구사항 요약은 이 표에 이미 원문과 대조해 둔 문구를 썼다. 1.3.11은 신고 결과를 계정 이메일로도 알리게 되어 적용으로 바꿨고, 선별 L3에 14.2.7(자동 파기)을 더했다. 새 법률 행의 조문은 2026-10-19 국가법령정보센터 원문으로 확인했다.

**작성 및 판독 가이드**

- **적용 여부**: 적용, 부분 적용, 미적용 중 하나로 적는다.
- **구현 위치**: 예정 위치를 적는다.
  - `web`: 소비자 웹(Next.js) 홈·상세·검색 화면, 후기 모달(사진 올리기·사진 보기, 신고·신고 확인 모달), 머리 검색창, 본인확인 복귀 화면 `/verify/return`
  - `console`·`partner`: 관제 콘솔 [홈 구성] 탭과 CS 처리함(SCR-045)의 후기 조치, 파트너 콘솔 공연 등록 이미지 올리기와 좌석맵 에디터(SCR-022)의 템플릿 고르기·템플릿에서 만들기
  - `core-svc`: catalog 모듈(홈 피드, 검색, 연관 검색어, 홈 구성 반영, 이미지 검사·다시 인코딩·파생본 게시, 좌석맵 템플릿 읽기와 템플릿에서 만들기), review 모듈(자격 확인, 금칙어, 같은 내용 숨김, 통보 차단, 후기 사진 검사·QR 거르기·파생본, 신고 접수, 신고 처리 조치 반영), notify 모듈(신고 결과·조치 통지)
  - `ops-svc`: 홈 구성 권한·감사 로그, 법정 통보 처리, 신고 건(CS 처리함)과 후기 조치의 권한·사유·감사 로그
  - `identity-svc`: 본인확인 시작·결과 경로, `ticket-svc`: 후기 자격용 결제자 티켓 조회
  - `gw-*`: API 게이트웨이, `CDN`: CloudFront 배포(공연 페이지·`api`)
- **테스트 결과**: 손으로 적지 않는다. CI 테스트의 `[ASVS v5.0.0-x.y.z]` 태그를 파싱한 리포트로 갱신한다.
- **미적용 사유 분류**: 해당 없음, Phase 이연, 위험 수용(ADR 작성 필수)으로 구분한다.
