# ASVS 추적 표: 양도·취소·환불 운영

- **대상 기능 범위**: 양도 요청·수락·거절·철회·돌려주기, 결제자만 하는 예매 취소와 환불 계좌 입력, 회차 취소 요청·귀책 판정·2인 확정·일괄 환불 작업, 주최 측 귀책 배상 지급, CS 처리함, 승인 업무(예외 환불, 계정 탈취 양도 회수), 취소·양도 남용 제한과 소명, 공연 판매 승인과 판매자 정보·중개자 고지, 공연예술통합전산망 전송
- **보안 검증 기준**: OWASP ASVS 5.0.0, 목표 레벨 Level 2. 업무 로직(V2 전 절), 웹 프런트엔드(V3 전 절, 양도·양도 받기·예매 취소·소명·계좌 입력 화면과 파트너·관제 콘솔의 회차 취소·판매 승인·승인 업무·CS 처리함 화면), 인가(V8 전 절), 자체 완결형 토큰(V9 전 절, 양도·취소에 쓰는 팬 재인증 토큰), 암호(V11 전 절, 양도·취소 때의 기기 키 폐기와 교체. ADR-0053으로 추가), 데이터 보호(V14 전 절), 안전한 코딩(V15.1~V15.3), 보안 로그와 오류 처리(V16 전 절)의 L1·L2 항목을 전수 판정한다. Level 3은 선별 채택한 3개만 싣는다. 관리 계정 로그인과 재인증, 쿠키 이름과 속성은 [계정·인증 추적 표](auth.md), 결제사 취소 API 호출과 웹훅은 [주문·결제 추적 표](payment.md), 응답 보안 헤더와 게이트웨이의 출처 검사 같은 공통 설정은 [전달 파이프라인 추적 표](delivery.md)를 따른다.
- **아키텍처 설계 근거**: [docs/features/transfer-refund.md](../../features/transfer-refund.md), [ADR-0045](../../adr/0045-intermediary-legal-status.md), [ADR-0046](../../adr/0046-cancel-transfer-refund-approvals.md), [ADR-0001](../../adr/0001-fan-social-login-single-factor.md), [docs/features/payment.md](../../features/payment.md), [docs/features/offline-gate.md](../../features/offline-gate.md), [docs/security/data-classification.md](../data-classification.md)
- **문서 상태 및 일정**: 항목 선정 완료, 구현 직전 단계(2026-10-13 수립). 요구사항 원문은 OWASP ASVS `v5.0.0_release` 원문과 대조했다(2026-10-13). V3 절은 OWASP ASVS 저장소 `v5.0.0` 태그의 V3 원문과 대조해 더했다(2026-10-15). Phase 5 양도·취소 작업 착수(wbs 5.2.1) 전에 재판정한다.

**작성 및 판독 가이드**

- **적용 여부**: 적용, 부분 적용, 미적용 중 하나로 적는다.
- **구현 위치**: 예정 위치를 적는다.
  - `ticket-svc`: 양도 요청·수락·돌려주기·회수와 키 교체
  - `purchase-svc`: 예매 취소 Saga와 일괄 환불 작업
  - `payment-svc`: 결제사 취소와 송금 포트
  - `ops-svc`: 승인 업무, CS 처리함, 감사 로그
  - `core-svc`: 판매 승인, 판매자 정보, 공연예술통합전산망 전송
  - `gw-*`: API 게이트웨이
  - `web`: 소비자 웹 양도(SCR-014)·양도 받기(SCR-041)·예매 취소(SCR-038)·소명 제출(SCR-042)·배상금 계좌 입력(SCR-043)·환불 계좌 입력(SCR-060) 화면
  - `partner`·`console`: 파트너 콘솔 판매 승인 요청(SCR-021)·회차 취소 요청(SCR-044), 관제 콘솔 CS 처리함(SCR-045)·승인 업무(SCR-046)·회차 취소 판정(SCR-047)·판매 승인(SCR-048)
- **테스트 결과**: 손으로 적지 않는다. CI 테스트의 `[ASVS v5.0.0-x.y.z]` 태그를 파싱한 리포트로 갱신한다.
- **미적용 사유 분류**: 해당 없음, Phase 이연, 위험 수용(ADR 작성 필수)으로 구분한다.
