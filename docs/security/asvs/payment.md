# ASVS 추적 표: 주문·결제

- **대상 기능 범위**: 주문 생성 뒤의 결제 흐름 전체. 결제 시도 시작과 결제사 선택(공연별 지정, 장애 시 전환, 플랫폼 기본값), 결제창 연동(토스페이먼츠 주문서형 결제, 포트원 결제창), 결제 접수와 결제사별 접수 계약, 승인·조회·취소·환불, 결제사 웹훅 수신, 일일 대사, 결제사별 동시 입장 목표 상한(ADR-0029, ADR-0036, ADR-0044).
- **보안 검증 기준**: OWASP ASVS 5.0.0, 목표 달성 레벨 Level 2. V2 전 절, V3 전 절(L1·L2가 있는 V3.2~V3.5·V3.7)과, 결제 흐름에 직접 걸리는 절(V8.2, V11.2·V11.3·V11.5, V12.2·V12.3, V13.1~V13.3, V14.1~V14.3, V15.1·V15.3, V16.2·V16.3·V16.5)의 L1·L2 항목을 전수 판정한다. Level 3은 선별 채택한 4개만 싣는다. 사용자 로그인과 세션, 쿠키 이름과 속성은 [계정·인증 추적 표](auth.md), 대기열의 자동화 방지는 [봇 방어 추적 표](bot-defense.md), 응답 보안 헤더와 게이트웨이의 출처 검사 같은 공통 설정은 [전달 파이프라인 추적 표](delivery.md)에서 판정한다. 좌석 홀드(Redis Lua)의 이중 예약 방지는 좌석 추적 표(예정)에서 판정하고, 이 표는 결제 Saga 안의 좌석 확정 행(`seat_sale`)까지 판정한다. 로그 저장소 보호(V16.4) 같은 공통 항목은 플랫폼 공통 추적 표에서 다룬다.
- **아키텍처 설계 근거**: [docs/features/payment.md](../../features/payment.md), [ADR-0015](../../adr/0015-tosspayments-two-phase-approval.md), [ADR-0029](../../adr/0029-pg-adapter-toss-default-portone-compatible.md), [ADR-0036](../../adr/0036-external-limits-estimates.md), [ADR-0044](../../adr/0044-dual-pg-selection-and-switchover.md), [docs/security/data-classification.md](../data-classification.md), [docs/security/secrets-and-keys.md](../secrets-and-keys.md).
- **문서 상태 및 일정**: 항목 선정 완료, 구현 직전 단계 (2026-10-13 수립, ADR-0044 반영). 요구사항 원문은 OWASP ASVS `v5.0.0_release` 원문과 대조했다(2026-10-13). V3 절은 OWASP ASVS 저장소 `v5.0.0` 태그의 V3 원문과 대조해 빠진 V3.2·V3.3·V3.5 행을 채웠다(2026-10-15). Phase 2 결제 작업 착수(wbs 2.7.1) 전에 재판정한다. 2026-10-20 3차 점검에서 가상계좌 번호 필드 암호화(ADR-0062)를 판정에 넣어 V11.3 세 행을 더하고 고시 제7조 제2항 행을 적용으로 바꿨으며, 주문·결제 접속기록 보존 법률 행을 더했다(추천 적용 2026-10-20, ADR-0073).

**작성 및 판독 가이드**

- **적용 여부**: 적용, 부분 적용, 미적용 중 하나로 명시한다.
- **구현 위치**: 예정 위치를 적는다. `purchase-svc`는 booking 모듈(주문, 결제 시도, Saga), `payment-svc`는 결제사 선택기·어댑터·웹훅·대사, `gw-*`는 API 게이트웨이, `web`은 소비자 웹 결제 화면(SCR-011, 결제창 복귀 상태 포함)과 결제 결과 화면(SCR-012)이다.
- **테스트 결과**: 수동 기재를 금지하며, CI 테스트 스위트의 `[ASVS v5.0.0-x.y.z]` 태그를 파싱하여 자동 생성 리포트로 갱신한다.
- **미적용 사유 분류**: 해당 없음, Phase 이연, 위험 수용(ADR 작성 필수)으로 구분한다.
