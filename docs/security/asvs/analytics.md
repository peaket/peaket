# ASVS 추적 표: 분석 저장소와 공연 리포트

- **대상 기능 범위**: Kafka 이벤트·기준 자료·운영 기록·비용·SLO 결과의 원본 적재와 가명 처리, dbt 변환(브론즈 → 실버 → 골드)과 마감(R0~R3, 동결), 지표 사전과 결정 규칙 판정, 공연 리포트 렌더링·내려받기, 결정 기록, 파트너 판매 요약 리포트, Iceberg 아카이브. 실시간 관제 화면 자체는 관제 콘솔 추적 표(예정) 대상이다.
- **보안 검증 기준**: OWASP ASVS 5.0.0, 목표 레벨 Level 2. 인코딩과 정화(V1), 업무 로직(V2), 웹 프런트엔드(V3.2·V3.3·V3.4·V3.5·V3.7. 공연 리포트·결정 기록 화면, 파트너 판매 요약 화면, 리포트 파일 내려받기), API와 웹 서비스(V4), 파일 처리(V5), 인가(V8), 암호(V11), 보안 통신(V12), 설정(V13), 데이터 보호(V14), 안전한 코딩(V15), 보안 로그와 오류 처리(V16)의 L1·L2 항목을 전수 판정한다. Level 3은 선별 채택한 4개만 싣는다. 관리 계정 로그인·세션(V6·V7)과 관리 쿠키는 [계정·인증 추적 표](auth.md)를 따른다. V3 행 중 콘솔 전체에 걸리는 응답 헤더(CSP, `frame-ancestors`, Referrer-Policy)는 docs/architecture.md §6.3 '화면별 CSP'와 [전달 파이프라인 추적 표](delivery.md)를 따른다. 비교 대시보드(Grafana)의 브라우저 설정은 관측 플랫폼 설정이라 여기서 판정하지 않는다. V9·V10·V17은 이 기능에 해당하지 않는다.
- **아키텍처 설계 근거**: [docs/features/analytics.md](../../features/analytics.md), [ADR-0052](../../adr/0052-analytics-medallion-star-schema-close-stages.md), [ADR-0042](../../adr/0042-analytics-store-and-decision-rules.md), [docs/security/data-classification.md](../data-classification.md), [docs/security/secrets-and-keys.md](../secrets-and-keys.md)
- **문서 상태 및 일정**: 항목 선정 완료, 구현 직전 단계(2026-10-13 수립, ADR-0052 반영). 요구사항 원문은 OWASP ASVS `v5.0.0_release` 원문과 대조했다(2026-10-13). V2·V4·V8·V11~V16의 요약은 정산 추적 표와 같은 문장을 쓰고, V1·V5 요약은 원문에서 새로 옮겼다. 개인정보 보호법(법률 제21445호)과 시행령(대통령령 제36671호)은 2026-09-11 시행본 원문과 대조했다. 분석 작업(wbs 4.3.2~4.3.7) 착수 전에 구현 위치를 확정한다. V3 절은 2026-10-15에 OWASP ASVS 저장소 `v5.0.0` 태그의 V3 장 원문과 대조해 더했다. 2026-10-20 ADR-0071로 Flink 실행 기반(관리 화면 잠금, 잡별 ClickHouse 사용자, 버전 고정)과 관제 실시간 잡(`ops-rt`)을 구현 위치에 더했다(docs/streaming.md).

**작성 및 판독 가이드**

- **적용 여부**: 적용, 부분 적용, 미적용 중 하나로 적는다.
- **구현 위치**: 예정 위치를 적는다.
  - `peaket-data`: Flink 원본 적재 잡(`analytics-ingest`)과 관제 실시간 잡(`ops-rt`), 심장 박동 발행기(`rt-pulse`), dbt 프로젝트(`analytics`), 마감 실행기(`close-runner`, 쿠버네티스 CronJob). Flink 실행 기반은 docs/streaming.md §2
  - `ops-svc`: 공연 리포트 렌더링과 API, 결정 기록, 가명정보 처리 기록, 관제 콘솔 GraphQL
  - `core-svc`·`ops-svc` 내보내기: 회차 기준 자료와 운영 기록을 분석 수집 버킷(S3)에 쓴다
  - ClickHouse 분석 DB: `bronze`·`silver`·`gold`·`rt`, 주체별 사용자와 역할
  - `gw-ops`·`gw-partner`: API 게이트웨이
  - `console`·`partner`: 관제 콘솔의 공연 리포트(SCR-029 ④)·결정 기록 화면, 파트너 콘솔의 판매 요약(SCR-027)
- **테스트 결과**: 손으로 적지 않는다. CI 테스트의 `[ASVS v5.0.0-x.y.z]` 태그를 파싱한 리포트로 갱신한다.
- **미적용 사유 분류**: 해당 없음, Phase 이연, 위험 수용(ADR 작성 필수)으로 구분한다.
