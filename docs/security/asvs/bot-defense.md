# ASVS 추적 표: 봇 방어

- **대상 기능 범위**: 사람 확인(Cloudflare Turnstile), trust-svc 실시간 위험 점수 산출 및 추가 검증 큐 격리, 허니팟 상호작용 감지, 신규 판정 규칙 그림자 실행(Shadow Execution), 탐지 품질 및 오탐률 실측(K6), 좌석 자동 배정 공연의 희망 조건 사전 입력과 차례 직전 직접 확인(ADR-0043).
- **보안 검증 기준**: OWASP ASVS 5.0.0, 목표 달성 레벨 Level 2. 봇 방어 도메인에 직결되는 V2.1, V2.3, V2.4, V16 통제 항목과 브라우저 쪽 통제(사람 확인 위젯, 허니팟, 행동 신호, 최초 방문 쿠키)의 V3 L1·L2 19개를 전수 판정하며, Level 3 권고 항목은 시스템에 선별 채택한 규격에 한해 수록한다. 로깅 인프라 보호(V16.2·V16.4)는 플랫폼 공통 추적 표(asvs/delivery.md)에서 다루고, 일반 입력값 검증(V2.2)은 입력을 받는 기능별 표(payment·offline-gate·transfer-refund·settlement·analytics·catalog-review·support)에서 판정하되 좌석 자동 배정의 희망 조건처럼 봇 방어 흐름에 직접 들어가는 입력은 이 표에서 함께 판정하고(V2.2.1~2.2.3, ADR-0043), 한정 자원의 이중 선점 방지(V2.3.3·2.3.4)는 좌석 추적 표(예정, 00-summary §9)와 결제 추적 표에서 판정한다.
- **아키텍처 설계 근거**: [docs/features/queue-admission.md](../../features/queue-admission.md) §7·§11, [ADR-0006](../../adr/0006-ticket-buyer-identity-verification-before-queue.md), [ADR-0012](../../adr/0012-queue-ordering-hybrid-shuffle-default.md), [ADR-0039](../../adr/0039-bot-detection-evaluation-protocol.md), [ADR-0041](../../adr/0041-fifo-speed-bot-countermeasures.md), [ADR-0043](../../adr/0043-auto-seat-preferences-before-turn.md), [docs/features/seat-hold.md](../../features/seat-hold.md) §3.
- **문서 상태 및 일정**: 항목 선정 완료, 구현 직전 단계 (2026-10-11 수립, 2026-10-12 ADR-0043 반영, 2026-10-15 V3 웹 프런트엔드 보안 절 추가. 같은 날 ADR-0065 결정 9로 최초 방문 쿠키(`__Host-peaket_fv`)·행동 신호 전송 경로·허니팟 기록 조건을 설계에 정해 3.3.1~3.3.4·3.5.1·3.5.3을 적용으로 바꿨다). Phase 3 착수 시점(WBS 3.2.1)에 최종 재판정을 진행한다. 2026-10-20 ADR-0071로 판정 피처 일부(회차별 기기 공유 수, 호스팅·프록시 대역 진입 수)를 trust-svc의 Redis 즉시 계산으로 정하고, Flink `trust-reassess`의 대기 중 재평가(그림자 시작, 격리 상한)와 행동 신호 원시 적재를 2.4.1·2.4.2·16.3.3·16.3.4와 법률 행에 더했다(docs/streaming.md §5).

**작성 및 판독 가이드**

- **적용 여부**: 적용, 부분 적용, 미적용 중 하나로 명시한다.
- **구현 대상 컴포넌트**: 전체 마이크로서비스 예정 위치를 명시한다. `trust-svc`는 위험 점수 및 추가 검증 큐, `queue-svc`는 로비 및 사전 검증, `gw-*`는 API 게이트웨이 계층, `web`·`apps/web`은 소비자 웹 화면, `CDN`은 CloudFront 배포다.
- **테스트 결과**: 수동 기재를 금지하며, CI 테스트 스위트의 `[ASVS v5.0.0-x.y.z]` 태그를 파싱하여 자동 생성 리포트로 갱신한다.
- **미적용 사유 분류**: 해당 없음, Phase 이연, 위험 수용(ADR 작성 필수)으로 구분한다.

## 비즈니스 및 운영 메모

- 그림자 실행(Shadow Execution)과 표본 수동 검토는 모델 성능 평가를 위한 실측 계측 수단이며 직접적인 차단 통제가 아니므로, ASVS 통제 항목에 인위적으로 강제 매핑하지 않고 상기 측정 요구사항으로 분리 관리한다. 개인정보 처리는 POL-006 및 data-classification의 행동 신호 규정을 엄격히 준수한다.
- 허니팟 히든 요소는 보조기기 사용자의 오작동을 방지하기 위해 브라우저 접근성 트리(Accessibility Tree)에서 완전 은폐한다(NFR-020). 스크린리더가 도달 가능한 UI 요소를 허니팟으로 오용할 경우 심각한 오탐이 발생하기 때문이다.
- 알려진 설계 한계(타인 명의 대여 및 도용 방어의 한계, 실서비스 환경에서의 탐지율 하한 추정 특성, 3단계 고도화 봇 목표치 사후 수립, 장외 거래 감지 한계, 서킷 브레이커 작동 시의 탐지율 완화)는 docs/features/queue-admission.md §7 및 planning/01 §5.2에 명문화했다. ASVS 항목을 '적용'으로 판정하더라도 해당 물리적 한계점은 명확히 인지하고 관리한다.
