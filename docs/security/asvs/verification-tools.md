# ASVS 추적 표: 검증 도구(불변식 검사기·PG 시뮬레이터)

- **독자와 용도**: 불변식 검사기와 PG 시뮬레이터를 구현하거나 검토하는 엔지니어와 보안 검토자가, ASVS 5.0.0 항목마다 적용 여부·구현 위치·시험 결과·미적용 사유를 확인할 때 참조한다. 구현 전에 이 표를 먼저 쓴다(docs/architecture.md §8.2).
- **대상 기능 범위**(wbs 1.2.3, BUILD_ORDER BSL-010, 2026-11-02 작성. 성능 장부 도구는 wbs 1.4.1, BSL-080에서 더함):
  - **불변식 검사기**(`services/invariant-checker`): 시험이 끝난 뒤 서비스 DB(purchase·payment·ticket)를 읽기 전용으로 읽고 시험 기록과 대조해 '깨지면 안 되는 약속'의 위반을 센다(docs/verification.md §2.5). 지금은 로컬·CI 시험에서만 돈다. 운영에서 1분마다 결제 원장과 주문·발권 큐를 대조하는 일(ADR-0106)은 운영 배포 단계에서 이 표를 다시 판정한다.
  - **PG 시뮬레이터**(`services/pg-simulator`): 결제사를 흉내 내는 시험용 서버다. 운영에는 배포하지 않는다(로컬·CI·데모·스테이징). 실제 카드 정보와 돈을 다루지 않는다.
  - **시뮬레이터 어댑터**(`services/payment-svc`의 결제 포트 구현): 운영 결제 경로와 같은 포트·외부 호출 클라이언트를 쓰므로 결제 쪽 판정은 [주문·결제 추적 표](payment.md)를 따른다. 이 표는 시뮬레이터에만 걸리는 키 구분을 더한다.
  - **성능 장부 도구와 야간 축소 성능 잡**(`tools/perf-ledger`, `.github/workflows/perf-nightly.yml`): 측정 결과를 공개 저장소의 장부로 모으고 비율·백분위 목표를 판정하며, 야간에 기준판과 새 판을 번갈아 재어 견준다(docs/perf-ledger.md §2.2·§7, docs/devops.md §3.3). 개인정보와 비밀을 다루지 않고 운영에 배포하지 않는다. 야간 잡은 실패 알림 단계에서만 GitHub 이슈를 쓴다.
  - **로컬 관측 최소**(`deploy/local/observability.yaml`, `tools/local/dashboards.mjs`, wbs 1.3.1, BSL-070에서 더함): 로컬 kind의 Prometheus·Grafana와 템플릿 대시보드다. 측정과 개발에서만 쓰고 운영에 배포하지 않는다. 합성 데이터의 지표만 담는다(docs/observability.md §3 '로컬 관측 최소와 템플릿 대시보드').
- **보안 검증 기준**: OWASP ASVS 5.0.0(웹 보안 기준을 만드는 비영리 단체가 낸 웹 앱 보안 검증 항목 목록), 목표 레벨 Level 2다. 두 도구에 걸리는 V1(주입), V2(업무 로직), V4(HTTP 응답), V8(권한), V13(설정·비밀), V14(데이터 보호), V16(로그)의 해당 행을 판정한다. 로그인·세션·토큰·화면·파일 올리기·암호 저장 장(V3·V5·V6·V7·V9·V10·V11·V12의 사용자 쪽)은 두 도구에 사용자가 없어 해당 없음이다. 요구사항 요약은 다른 추적 표가 원문과 대조해 둔 같은 ID의 문장을 그대로 쓴다(ADR-0087 결정 30).
- **아키텍처 설계 근거**: [docs/verification.md](../../verification.md) §2.5, [docs/features/payment.md](../../features/payment.md) §2.1, [ADR-0029](../../adr/0029-pg-adapter-toss-default-portone-compatible.md), [ADR-0057](../../adr/0057-verification-without-full-scale-infra.md), [ADR-0106](../../adr/0106-forward-recovery-after-payment-approval-ticket-issue-retry.md), [docs/security/secrets-and-keys.md](../secrets-and-keys.md).

**작성 및 판독 가이드**

- **구현 위치**: `checker`는 불변식 검사기, `sim`은 PG 시뮬레이터, `adapter`는 payment-svc의 시뮬레이터 어댑터, `ledger`는 성능 장부 도구와 야간 축소 성능 잡, `local-obs`는 로컬 관측 최소(Prometheus·Grafana·템플릿 대시보드)다.
- **테스트 결과**: 손으로 적지 않는다. 시험 이름의 `[ASVS v5.0.0-x.y.z]` 태그를 CI 리포트가 읽어 갱신한다(docs/architecture.md §8.2 4). 지금은 '미실행'이다.
- **미적용 사유 분류**: 해당 없음, 나중 Phase로 미룸, 위험 수용(ADR 필수).
