# 품질 요구사항 명세

- **독자와 용도**: 비기능 요구사항을 세우거나 검증하는 아키텍트와 QA 담당자가, 품질 특성(ISO/IEC 25010)마다 측정량과 목표, 검증 방법을 확인할 때 참조한다.
- **품질 프레임워크**: ISO/IEC 25030:2019(소프트웨어 품질 요구사항 프레임워크). 요구사항을 세우는 절차는 `planning/02-requirements.md` §3.1(설계서 섹션 0 '품질 요구사항 정의·평가 절차')을 따른다.
- **품질 특성 분류**: ISO/IEC 25010:2023(제품 품질 특성 9가지).
- **품질 측정량 기준**: ISO/IEC 25023:2016(현재 제1판이며, ISO/IEC 25000-23으로 개정하는 작업이 진행 중이다).
- **목표치를 정하는 원칙**: `planning/02-requirements.md` §3.1의 'NFR 작성 원칙'(성능이나 보안 같은 품질 요구사항을 쓰는 원칙)을 따른다. 순서는 공신력 있는 표준 기준 → 실제 시스템 실측 → 인프라 비용과 사용자 가치 사이의 트레이드오프 분석이다.
- **작성 상태와 표준 검토 이력**: 초안 작성(2026-10-06), 개정 갱신(2026-10-09). ISO/IEC 25023 규격은 ISO 공식 OBP(Online Browsing Platform)의 미리보기 공개본으로 직접 검토를 마쳤다(이용 약관 동의, 익명 접속, 프로젝트 소유자 확인). 공식 미리보기는 서문, 제1장 적용 범위, 제3장 인용 표준, 제4장 용어 정의와 참고문헌을 공개한다. 구체적 측정량을 정의한 제8장은 전체 목차와 표 제목 체계만 보여 준다. 그래서 이 명세서는 각 품질 요구사항을 공개 목차에서 확인할 수 있는 측정량 표(부특성) 수준까지만 1:1로 맞춰 대응시킨다. 비공개인 측정량 고유 ID는 임의로 붙이지 않는다.

## 25010:2023과 25023:2016의 대응

ISO/IEC 25023:2016은 ISO/IEC 25010의 2011년 구판(8대 특성)을 기준으로 만들어졌다. ISO/IEC 25010:2023 개정판 서문에 따르면, 2023년 최신 규격은 '안전성(Safety)'을 새 독립 품질 특성으로 넣었다(세부 부특성: 운영 제약, 위험 식별, 페일 세이프, 위험 경고, 안전한 통합). 또 기존의 '사용성'과 '이식성'을 각각 '상호작용 능력(Interaction capability)'과 '유연성(Flexibility)'으로 바꿨다.

| 25010:2023 품질 특성 | 25023:2016 대응 특성 | 측정 지표 및 측정량 선정 원칙 |
| --- | --- | --- |
| 기능 적합성, 성능 효율성, 호환성, 신뢰성, 보안성, 유지보수성 | 이름이 같은 특성 | ISO/IEC 25023에 정의된 해당 측정량을 그대로 쓴다. |
| 상호작용 능력 (Interaction capability) | 사용성 (Usability) | ISO/IEC 25023의 사용성 측정량을 쓴다. 2023년 개정판에서 새로 생긴 부특성은 프로젝트 자체 지표로 보완한다. |
| 유연성 (Flexibility) | 이식성 (Portability) | ISO/IEC 25023의 이식성 측정량을 쓴다. 2023년에 새로 생긴 부특성은 자체 지표로 보완한다. |
| 안전성 (Safety) | 대응하는 특성이 없다 | PEAKET 자체 안전성 측정량을 분명히 정의해 쓴다. 앞으로 ISO/IEC 25000-23이 제정되면 그 표준으로 바꾼다. |

ISO OBP 공식 미리보기 목차에서 확인되는 ISO/IEC 25023의 측정량 표는 '표 1 기능 완전성'부터 '표 25 재사용성'까지 모두 25개다(2026-10-09 기준). 아래 요구사항 표의 대응 관계는 이 공식 표 제목을 기준으로 정했다. 본문에 실린 세부 측정량 이름과 내부 ID는 원문 비공개 정책에 따라 따로 적지 않는다.
