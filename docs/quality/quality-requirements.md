# 품질 요구사항 명세

- **품질 프레임워크**: ISO/IEC 25030:2019(소프트웨어 품질 요구사항 프레임워크). 수립 절차는 `planning/02-requirements.md` §3.1(설계서 섹션 0 '품질 요구사항 정의·평가 절차')을 준용한다.
- **품질 특성 분류**: ISO/IEC 25010:2023(9대 제품 품질 특성).
- **품질 측정량 기준**: ISO/IEC 25023:2016(현행 제1판, ISO/IEC 25000-23 개정 작업 진행 중).
- **목표치 수립 원칙**: `planning/02-requirements.md` §3.1 'NFR 작성 원칙'(공신력 있는 표준 기준 → 실제 시스템 실측 → 인프라 비용 및 사용자 가치 간 트레이드오프 분석).
- **작성 상태 및 표준 검토 이력**: 초안 작성(2026-10-06), 개정 갱신(2026-10-09). ISO/IEC 25023 규격은 ISO 공식 OBP(Online Browsing Platform) 미리보기 공개본을 통해 실측 검토를 완료했다(이용 약관 동의, 익명 접속, 프로젝트 소유자 확인). 공식 미리보기는 서문, 제1장 적용 범위, 제3장 인용 표준, 제4장 용어 정의 및 참고문헌을 공개하며, 구체적 측정량이 정의된 제8장은 전체 목차와 표 제목 체계만 노출한다. 이에 따라 본 명세서는 개별 품질 요구사항을 공개 목차에서 확인 가능한 측정량 표(부특성) 수준까지만 1:1로 정합 매핑하고, 비공개 상태인 측정량 고유 ID는 자의적으로 부여하지 않는다.

## 25010:2023과 25023:2016의 대응

ISO/IEC 25023:2016은 ISO/IEC 25010의 2011년 구판(8대 특성)을 기준으로 제정되었다. ISO/IEC 25010:2023 개정판 서문에 따르면, 2023년 최신 규격은 '안전성(Safety)'을 신규 독립 품질 특성으로 편입하였고(세부 부특성: 운영 제약, 위험 식별, 페일 세이프, 위험 경고, 안전한 통합), 기존의 '사용성'과 '이식성'을 각각 '상호작용 능력(Interaction capability)'과 '유연성(Flexibility)'으로 개편했다.

| 25010:2023 품질 특성 | 25023:2016 대응 특성 | 측정 지표 및 측정량 선정 원칙 |
| --- | --- | --- |
| 기능 적합성, 성능 효율성, 호환성, 신뢰성, 보안성, 유지보수성 | 동일 명칭의 특성 | ISO/IEC 25023에 정의된 해당 측정량을 직접 활용한다. |
| 상호작용 능력 (Interaction capability) | 사용성 (Usability) | ISO/IEC 25023의 사용성 측정량을 적용하되, 2023년 개정판에서 신설된 부특성은 프로젝트 자체 지표로 보완한다. |
| 유연성 (Flexibility) | 이식성 (Portability) | ISO/IEC 25023의 이식성 측정량을 적용하되, 2023년 신설 부특성은 자체 지표로 보완한다. |
| 안전성 (Safety) | 대응 특성 없음 | PEAKET 자체 안전성 측정량을 명확히 정의하여 적용하며, 향후 ISO/IEC 25000-23이 정식 제정되면 해당 표준으로 대체한다. |

ISO OBP 공식 미리보기 목차에서 확인되는 ISO/IEC 25023의 측정량 표는 '표 1 기능 완전성'부터 '표 25 재사용성'까지 총 25개 표로 구성된다(2026-10-09 기준). 아래 요구사항 매트릭스의 대응 관계는 해당 공식 표 제목을 기준으로 수립되었으며, 본문에 수록된 세부 측정량 명칭과 내부 ID는 원문 비공개 정책에 따라 별도 기재하지 않는다.
