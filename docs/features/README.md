# 기능별 상세 설계 목록

- **독자와 용도**: 어떤 도메인 기능에 상세 설계가 있는지, 구현 직전에 더 작성해야 할 대상이 무엇인지 알고 싶을 때 본다.
- **원문 출처**: 설계서 §6의 소절 구성을 기준으로 삼는다. 원문에 자세한 기술 내용이 정의된 핵심 기능만 따로 문서로 쓰고, 나머지는 아래 구현 직전 목록에 적는다(템플릿 작성 규칙을 따른다).
- **기준 기획 버전**: v1.0.
