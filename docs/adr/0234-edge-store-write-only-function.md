# ADR-0234: 엣지 저장소의 매진 표시·진입 모드는 쓰기 전용 작은 함수가 쓴다

- **상태**: 채택(2026-11-09, 소유자 결정 "추천대로". PROGRESS '미해결' OPEN[24]·OPEN[25]의 추천안이다). ADR-0053 결정 2에 예외 하나를 둔다. ADR-0219 결정 4를 정한다.
- **관련**: ADR-0053, ADR-0122, ADR-0219, ADR-0223, [docs/security/secrets-and-keys.md](../security/secrets-and-keys.md), [docs/security/threat-model.md](../security/threat-model.md), [docs/features/queue-admission.md](../features/queue-admission.md) §4, [docs/infra.md](../infra.md) §4.1
- **관련 ID**: POL-002, BUILD_ORDER HOT-011·HOT-012·HOT-020, ASVS v5.0.0-13.3.2

## 맥락

- 매진이면 queue-svc가 엣지 함수가 읽는 키·값 저장소(CloudFront KeyValueStore)의 값을 켜야 한다(ADR-0219). 엣지 함수는 사용자 가까이의 CDN(콘텐츠 전송망) 서버에서 도는 작은 함수다.
- AWS 제약이 둘 있다. 함수 하나에 저장소는 하나뿐이다. 저장소 권한은 키 이름으로 나눌 수 없다.
- 도착 시각 쿠키 서명 키가 그 저장소에 있다. 서명을 응답 단계 함수로 옮겨 저장소를 나누는 안은 쓸 수 없다(ADR-0223 결정 4).
- 그래서 queue-svc 역할에 저장소 권한을 바로 주면, 자격만 새도 서명 키를 읽고, 바꿔 쿠키를 꾸미고, 지워 진입 전체를 실패시킬 수 있다.
- 지금 AWS 계정이 없어 실제로 부를 곳이 없다.

## 결정

1. **쓰기 전용 작은 함수(Lambda, AWS의 작은 함수 실행 서비스)를 둔다.** 저장소에 쓰는 일은 그 함수의 역할(AWS 권한 묶음)만 한다. queue-svc 역할은 그 함수를 부르는 권한만 가지고, 저장소 권한은 없다.
2. **함수가 입력을 강제한다.** `sale:`·`mode:` 접두사 키만 받고, 값 꼴·판 번호 증가 폭·만료 시각을 확인한다. 서명 키(`arr:` 접두사)에는 닿지 못한다. 이것이 ADR-0053 결정 2('KeyValueStore를 읽고 쓰는 IAM 주체는 배포 역할뿐')의 유일한 예외다.
3. **감시를 더한다(CloudTrail 데이터 사건, 저장소 API 호출 기록).** 함수 역할이나 배포 역할이 그 밖의 키를 읽거나 쓰면 경보한다. 요금이 있어 켜는 일은 배포 단계에서 비용과 함께 소유자에게 다시 묻는다.
4. **만드는 때**: 함수·역할·패키지(AWS SDK KeyValueStore 클라이언트와 서명 모듈) 받기는 AWS 계정이 생겨 배포하는 단계(HOT-012)에서 다시 묻고 한다. 지금은 queue-svc의 포트와 시험 대역까지다. HOT-012는 그때까지 건너뛴다.
5. `mode:entry`(진입 Degraded 켜기)도 같은 함수로 쓴다 [가정]. 그 함수를 부를 주체와 권한은 OPS-310이 정한다.

## 결과

- 정본: secrets-and-keys.md, threat-model, asvs/queue-admission.md 13.3.2, queue-admission §4, infra §4.1, ADR-0053·0219, BUILD_ORDER HOT-012·OPS-310.
- 대가: 함수 하나를 더 만들어 배포·서명·시험한다. 호출 한 번의 지연이 쓰기 마감 2초 안에 든다. 함수 몫 0.25일 [가정]은 소유자가 승인한 추가 몫으로, wbs 합계에는 구간 마무리에서 넣는다.
- 남는 위험: 함수 역할이 털리면 `sale:`·`mode:` 값을 꾸밀 수 있다. 판 번호 증가 폭과 만료 시각 확인이 이를 좁힌다. 감시를 켜기 전에는 이상 호출이 드러나지 않는다.

## 다른 선택지

ADR-0219 '다른 선택지' 표의 결정 4 줄(바로 주기, 쓰기만 하는 역할, 저장소 나누기)을 본다. 저장소 나누기는 ADR-0223 결정 4에서 쓸 수 없다고 판단했다.
