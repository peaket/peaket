# ADR-0137: 기술 검토 낮음 항목의 문서 수정 묶음 5 — ADR 0001~0094의 낡은 문장과 상태 줄(2026-10-28)

- **상태**: 채택 (2026-10-28. 기술 검토(review/tech-review.md)의 낮음 항목(영역: ADR 0001~0040, ADR 0041~0060, ADR 0061~0077, ADR 0078~0094)에 소유자가 "나머지 건수들은 모두 추천안에 동의합니다. 그렇게 모두 수정해주세요."라고 정했다. 방향은 소유자 결정(추천안 승인)이고, 검토가 안을 고르지 않은 곳의 선택과 값 같은 세부는 추천 적용이다. 측정 전 값은 [가정]으로 표시했다)
- **관련**: review/tech-review.md(낮음-135·낮음-136·낮음-137·낮음-138·낮음-139·낮음-140·낮음-141·낮음-142·낮음-143·낮음-144·낮음-145·낮음-146·낮음-147·낮음-148·낮음-149·낮음-150·낮음-151·낮음-152·낮음-153·낮음-154·낮음-155·낮음-156·낮음-157·낮음-158·낮음-159·낮음-160·낮음-161·낮음-162·낮음-163·낮음-164·낮음-165·낮음-166·낮음-167·낮음-168·낮음-169·낮음-170·낮음-171·낮음-172·낮음-173), review/consistency-review.md R-155, 00-summary.md §6·질문 61, 같은 날 새 ADR-0100~0126(새 결정이 필요한 항목)

## 맥락

2026-10-27 기술 검토 2판은 설계의 모든 기술·기법을 시니어 개발자 관점에서 따져 높음·중간·낮음 항목으로 냈다. 2026-10-28 소유자가 남은 항목을 모두 추천안대로 고치라고 정했다. 새 결정이 필요한 항목은 따로 ADR(0100~0126)을 썼고, 이 ADR은 정본 문서를 고쳐 반영한 낮음 항목 39건의 문제와 결정을 한곳에 모은다. 검토 문서에서는 이 항목들의 본문을 지우고 이 ADR을 가리키는 한 줄만 남겼다(지운 본문은 git 이력에 있다).

## 결정

항목마다 검토의 추천 수정을 따랐다(소유자 승인). 검토가 안을 여럿 내고 고르지 않은 곳은 고른 안과 이유를 적었고 '추천 적용'으로 표시했다. 정본에는 `(추천 적용 2026-10-28, 기술 검토 <번호>)`로 표시했다.

#### 낮음-160 운영 설계의 느린 쿼리 분석에 Aurora 기본 기능(Database Insights 표준 모드)이 비교되지 않았다
- **문제**: 운영 설계의 느린 쿼리 분석에 Aurora 기본 기능(Database Insights 표준 모드)이 비교되지 않았다
- **결정**: 운영은 Database Insights 표준 모드 + CloudWatch Logs의 auto_explain, Grafana 제한 조직은 로컬·포트폴리오용, 콘솔 요약은 postgres_exporter 그대로(추천 적용).
- **바꾼 문서**: observability §8·§9, devops §10.1, infra-handover §8, ADR-0067·0078 상태 줄

#### 낮음-161 '경로 템플릿마다 초당 1건' 보존을 꼬리 표본 처리기의 `rate_limiting`·`composite`로 할 수 있다고 적었다
- **문제**: '경로 템플릿마다 초당 1건' 보존을 꼬리 표본 처리기의 `rate_limiting`·`composite`로 할 수 있다고 적었다
- **결정**: ADR-0069 결정 12의 '경로마다 초당 1건'을 드문 경로 목록마다 하위 정책과 초당 스팬 한도로 바꾼다(추천 적용).
- **바꾼 문서**: observability §6, ADR-0069 상태 줄

#### 낮음-162 문서 저장소의 실제 운영이 ADR-0074의 git flow 규칙(작업 가지, `develop` PR 필수)과 다르다
- **문제**: 문서 저장소의 실제 운영이 ADR-0074의 git flow 규칙(작업 가지, `develop` PR 필수)과 다르다
- **결정**: 원격 저장소를 만들기 전까지 문서 저장소는 `develop`에 스쿼시 형식 커밋을 바로 쌓고, 원격을 만들면 ADR-0074 결정 3·8을 건다(안 (가), 추천 적용).
- **바꾼 문서**: devops §2.2.5, architecture §8.5, ADR-0074 상태 줄


### ADR 0078~0094

#### 낮음-163 경보 위생 보고를 ops-svc가 GitHub Issues에 직접 올린다
- **문제**: 경보 위생 보고를 ops-svc가 GitHub Issues에 직접 올린다
- **결정**: ADR-0078 결정 5의 보고를 CronJob이 만들고 GitHub 쓰기 자격은 그 작업만 받는다. ops-svc는 GitHub 토큰을 갖지 않는다(추천 적용).
- **바꾼 문서**: observability §5, secrets-and-keys, ADR-0078 상태 줄

#### 낮음-164 VPC CNI 서브넷을 '피크 파드 수의 2배'로만 정하고 웜 IP 설정이 없다
- **문제**: VPC CNI 서브넷을 '피크 파드 수의 2배'로만 정하고 웜 IP 설정이 없다
- **결정**: ADR-0078 결정 7의 '피크 파드 2배'를 노드·웜 풀 식으로 바꾸고 접두사 위임을 기본안으로 둔다(추천 적용, 4.8.1에서 확정).
- **바꾼 문서**: infra §1, infra-handover §3, ADR-0078 상태 줄

#### 낮음-165 포렌식 데모의 '합성 정답 기준 정밀도·재현율'이 탐지 성능처럼 읽힐 수 있다
- **문제**: 포렌식 데모의 '합성 정답 기준 정밀도·재현율'이 탐지 성능처럼 읽힐 수 있다
- **결정**: 1단계 값 아래에 '합성 정답 기준, 실제 탐지 성능 아님' 고정 문구를 두고 문서·FX-T9에 같은 뜻을 적는다(추천 적용).
- **바꾼 문서**: forensic-replay §2.1·§5.3·FX-T9, d5 SCR-069, ADR-0080 상태 줄

#### 낮음-166 '앰비언트 L4 + 클라이언트 쪽 gRPC 분산' 대안의 기각 근거가 약하다
- **문제**: '앰비언트 L4 + 클라이언트 쪽 gRPC 분산' 대안의 기각 근거가 약하다
- **결정**: '앰비언트 L4 + 클라이언트 쪽 gRPC 분산'을 ADR-0010 재검토 때의 운영 비용 비교 항목으로 두고 판단 기준을 적는다(추천 적용).
- **바꾼 문서**: architecture §5, ADR-0082 상태 줄

#### 낮음-167 Graviton(arm64) 노드를 정했는데 다중 아키텍처 이미지와 승격 규칙이 없다
- **문제**: Graviton(arm64) 노드를 정했는데 다중 아키텍처 이미지와 승격 규칙이 없다
- **결정**: 이미지를 amd64·arm64 인덱스로 빌드·서명하고 운영 승격 조건에 arm64 스모크를 더한다(추천 적용).
- **바꾼 문서**: devops §3.1·§5.3, infra-handover §3.1, verification §6, ADR-0084 상태 줄

#### 낮음-168 섞인 줄바꿈을 그대로 두는 설정이 편집 함정을 남긴다
- **문제**: 섞인 줄바꿈을 그대로 두는 설정이 편집 함정을 남긴다
- **결정**: ADR-0084 결정 1의 `* -text`를 `* text=auto eol=lf`로 바꾸고 CRLF 파일을 정리 커밋 하나로 LF로 바꾼다(추천 적용).
- **바꾼 문서**: devops §2.1, ADR-0084 상태 줄, .gitattributes(메인 세션)

#### 낮음-169 계획 회귀 시험과 진단 도구의 실행 장소가 실제로 없다
- **문제**: 계획 회귀 시험과 진단 도구의 실행 장소가 실제로 없다
- **결정**: 전체 판은 로컬 야간, CI는 가벼운 인덱스 검사, 진단 확장은 로컬·스테이징(추천 적용).
- **바꾼 문서**: data §5.2, devops §3.3, ADR-0086 상태 줄

#### 낮음-170 배포 주석용 Grafana 주석 토큰이 ADR-0078의 '주석 쓰기 토큰을 만들지 않는다'와 맞지 않는다
- **문제**: 배포 주석용 Grafana 주석 토큰이 ADR-0078의 '주석 쓰기 토큰을 만들지 않는다'와 맞지 않는다
- **결정**: 배포 주석도 Loki 주석 조회(Argo CD 동기화 이벤트)로 그리고 Grafana 주석 토큰을 없앤다(추천 적용).
- **바꾼 문서**: observability §7, devops §10.4·§13, secrets-and-keys, asvs/delivery, ADR-0088 상태 줄

#### 낮음-171 EKS 공개 엔드포인트를 남기는 이유가 결정 본문과 어긋난다
- **문제**: EKS 공개 엔드포인트를 남기는 이유가 결정 본문과 어긋난다
- **결정**: ADR-0089 결정 4의 공개 엔드포인트를 끄고 사설만 둔다. 사람 접속은 VPN(VPC 라우팅)이나 SSM 포트 포워딩(추천 적용).
- **바꾼 문서**: devops §10.1, ADR-0089 상태 줄

#### 낮음-172 '새 판이 1년 넘게 없음'을 한 라이브러리 기각에만 쓰고 다른 의존성에는 쓰지 않는다
- **문제**: '새 판이 1년 넘게 없음'을 한 라이브러리 기각에만 쓰고 다른 의존성에는 쓰지 않는다

#### 낮음-173 0건 검색어 기록이 결정 2의 개인정보 근거와 맞지 않는다
