# ADR-0247: 공연 설명 편집기를 위저드에 붙이고 공연 상세는 구조 문서를 그린다

- **상태**: 채택(2026-11-09, 추천 적용). BUILD_ORDER HOT-185.
- **관련**: [docs/design/d2-design-system.md](../design/d2-design-system.md) CMP-070, [docs/design/d5-screen-blueprint.md](../design/d5-screen-blueprint.md) §6.4·§5.2, [docs/frontend.md](../frontend.md) §5.6·§5.14.3·FE-T41, [docs/security/asvs/catalog-review.md](../security/asvs/catalog-review.md) 1.3.1, ADR-0204, ADR-0244, ADR-0245
- **관련 ID**: FE-T41, CMP-070, SCR-021, SCR-002, FR-022, ASVS v5.0.0-1.3.1

## 맥락

- ADR-0204가 편집기를 Lexical로 고르고, PoC를 실제 위저드로 옮기는 일을 이 단계에 넘겼다. 서버 저장과 공개 응답은 ADR-0244에서 끝났다.
- 편집기는 위저드 임시저장(ADR-0245)과 함께 움직여야 하고, 다시 열 때 저장한 문서로 돌아와야 한다.
- 디자인 시스템의 `RichTextEditor`는 모양만 있고 도구 막대에 기울임·링크가 있어, 허용 서식 다섯과 맞지 않는다.

## 결정

1. **편집기는 파트너 콘솔에 둔다**(`features/rich-text`). 구조 문서 규칙과 Lexical 변환이 파트너 콘솔에만 필요하고(ADR-0204 결정 5), 늦게 싣는 덩어리가 공용 패키지로 번지지 않는다. 틀과 낱말은 CMP-070의 모양(도구 막대 + `prose` 입력 칸, 방향키로 도구를 옮기는 막대)을 따른다.
2. **도구 막대는 허용 서식만 둔다**: 굵게·제목·작은 제목·글머리 목록·번호 목록. 누른 상태는 커서 위치를 따라간다. 기울임·밑줄 단축키와 붙여넣은 다른 글자 모양은 편집기 안에서 지운다. 저장되지 않을 서식이 화면에만 보이지 않게 한다. 제목은 2·3단계로 맞춘다. 붙여넣을 때 안쪽 목록은 펼치고 번호 시작을 지우며 항목 안의 블록은 줄로 푼다. 끌어다 놓은 HTML도 붙여넣기와 같은 거름을 지나고, 거른 뒤 글자가 남지 않으면 글자판을 넣는다. 굵기는 Google 문서처럼 `style`로만 알리는 글이 있어 그 값만 남긴다.
3. **입력은 위저드 임시저장에 함께 둔다**: 임시저장 값의 `description`은 구조 문서이거나 비어 있으면 `null`이다. 글자가 없는 문서는 설명이 없는 것이다(ADR-0244 결정 5). 상한을 넘긴 글도 임시저장은 잃지 않고, 넘어갈 때 그 칸에서 알린다. 다시 열면 저장한 문서를 편집기 상태로 되돌린다.
4. **공연 상세는 구조 문서가 있으면 블록으로, 없으면 글자판으로 그린다**: 노드마다 React 요소로 그리고 HTML을 넣지 않는다(§5.14.3). 모르는 판이나 노드가 하나라도 있으면 구조 문서를 쓰지 않고 글자판으로 그린다. 빈 문단과 빈 목록 줄은 그리지 않고, 공백은 쓴 그대로 보인다. 페이지 제목 차례를 지키려고 문서의 제목은 `h3`부터 그린다(절 제목 '상세정보'가 `h2`다). 큰 제목 없이 작은 제목이 오면 차례를 건너뛰지 않게 `h3`로 그린다.
5. **FE-T41 시험은 실제 위저드에서 돈다**: 묶음 B CSP와 Trusted Types 보고 모드를 `proxy.ts`에서 `/events/new`에 건다. `connect-src`는 위저드가 부르는 API 주소(`NEXT_PUBLIC_PARTNER_API_ORIGIN`)와 같은 값을 쓴다. PoC 경로·PoC 화면·Tiptap 의존성을 걷고, 세 엔진 시험을 CI 잡으로 올린다. 나머지 파트너 화면의 보안 헤더는 그대로 OPS-340이 맡는다.

## 결과

- 파트너가 쓴 서식이 공연 상세에 그대로 보인다. 공개 응답의 `descriptionText`는 검색과 구조 문서를 못 읽는 경우의 대체다.
- 디자인 시스템 `RichTextEditor`의 도구 막대(기울임·링크)는 퍼블리싱 화면(`?state=`)에만 남는다. 시각 기준 이미지가 함께 바뀌므로 정리는 구간 끝 목록으로 넘긴다.

## 다른 선택지

| 길 | 고르지 않은 까닭 |
| --- | --- |
| 편집기를 `@peaket/ds`에 둔다 | 파트너 콘솔만 쓰는데 공용 패키지가 Lexical에 기댄다 |
| 저장되지 않는 서식도 편집기에서는 보이게 둔다 | 파트너가 본 모양과 팬이 보는 모양이 달라진다 |
| 모르는 노드만 빼고 구조 문서를 그린다 | 다음 판의 문서가 일부만 보여 글이 빠진 줄 모른다. 글자판은 빠짐없이 보인다 |
| CSP 시험을 OPS-340까지 미룬다 | Lexical을 올릴 때 붙여넣기 처리를 다시 볼 시험이 없어진다 |
